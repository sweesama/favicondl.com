無料ファビコン API

GET リクエスト 1 回で、URL からあらゆるサイトのファビコンを取得。API キー不要、登録不要。

クイックスタート

favicondl のファビコン API は、GET リクエスト 1 回であらゆるドメインや URL をそのファビコンに変換します。API キーもアカウントも SDK も不要です。size（16〜512。よく使う値は 16、32、64、128、256、512）を渡すと、ちょうどその一辺の正方形 PNG が返ります。

<img src="https://favicondl.com/api/extract?url=github.com&size=32" width="32" height="32" alt="GitHub のファビコン">

size を省略すると元のファイルです。元より小さいラスタは拡大され、ぼやけることがあります。SVG は指定サイズでラスタライズします。画像レスポンスの X-Favicon-Native-Size と X-Favicon-Upscaled で、拡大したかどうかが分かります。

JSON をリクエストすれば、どのファイルが見つかり、どこから取得したかを確認できます。

curl "https://favicondl.com/api/extract?url=github.com&format=json"

iconUrl はサイト上の元ファイルです。proxyUrl がダウンロードする画像です。size を省略すると元ファイル、size を付けると（例: &size=32）ちょうどその正方形 PNG です。Access-Control-Allow-Origin: * が付きます。

width と height は実測した元画像です（SVG は null）。size を指定すると outputWidth と outputHeight がそれと一致し、nativeWidth / nativeHeight は元のピクセル、upscaled はラスタを拡大したときだけ true です。その PNG はぼやけることがあります。candidates は検証済みの別アイコンを最大 8 個並べます。Google や DuckDuckGo にフォールバックした場合は空です。

API がアイコンを選ぶ仕組み

  1. トップページを通常のブラウザと同じようにリクエストし、リダイレクト（www ↔ 素のドメインを含む）を追跡します。アイコン関連の <link> をすべて読み取ります：icon、shortcut icon、apple-touch-icon、apple-touch-icon-precomposed、mask-icon。相対リンクやプロトコル相対リンク（//cdn…）は、最終的なページ URL またはその <base> タグを基準に解決します（source: "html"）。
  2. Web App Manifest：ページからリンクされた manifest を開いてアイコン一覧を読みます。192px や 512px のアイコンはここにあることが多いです（source: "manifest"）。
  3. 定番のパス /favicon.ico と /apple-touch-icon.png も試します（source: "direct"）。
  4. 候補はすべてダウンロードして確認します。中身が本当に画像（PNG、ICO、SVG、WebP、JPEG、GIF など）であることを確かめ、ファイル名を信じるのではなく実際のピクセルサイズを測ります。
  5. Google のファビコンサービス、次いで DuckDuckGo は、サイト上のアイコンがどれも使えなかったときだけ、リクエストした size で使用します（source: "google_s2" または "duckduckgo"）。

検証済みの候補は、最も鮮明なファイルが選ばれるように順位付けされます。フルカラーの SVG が最優先で、次に最も大きい正方形の PNG/ICO/WebP です。Safari の単色 mask-icon や、maskable とだけ指定された manifest アイコンは、通常のファビコンとは見た目が異なるため順位を下げています。選ばれた元画像は、リクエストされた size（16〜512。例: 32）にリサイズされます。size を省略すると元のファイルのままです。縮小は Lanczos、拡大は高品質な再サンプリング、正方形でない画像は透明で埋め、SVG は指定サイズでラスタライズします。拡大したラスタはぼやけることがあり、応答はそれを鮮明な原寸だとは言いません。

google_s2 が返ってきた場合、そのサイトには当社から取得できるアイコンがないか、リクエストがブロックされています（ボット確認ページが返された場合など）。1 サイトだけなら、トップページのファビコンダウンローダーがブラウザから直接いくつかの取得元も試し、見つかったすべてのサイズを表示するので、そこから選べます。

概要

Mzu favicondl は、コピーして使えるファビコン URL テンプレートとファビコン抽出 UI を提供しています。独自の抽出 API がサイトの公開している実際のアイコンを見つけ、画像プロキシによってブラウザのコードからもダウンロードできるようにします。

エンドポイント

GET FaviconDL Extract API

ドメインや URL から使えるファビコンを見つけてダウンロード

ベースURL：

https://favicondl.com/api/extract

完全な例：

https://favicondl.com/api/extract?url=example.com&size=128

パラメーター

パラメーター名 型 必須 デフォルト値 説明
url string はい - 対象のドメインまたは URL（例：example.com）
size number いいえ なし（元のファイル） 出力サイズ（16〜512。例: 16、32、64、128、256、512）。ちょうどその一辺の正方形 PNG を返します。範囲外は 16〜512 に収めます。size を省略すると元のファイルです。小さいラスタは拡大され、ぼやけることがあります。SVG は指定サイズでラスタライズします。
format string いいえ redirect メタデータが必要なら json を指定。省略するとダウンロード可能な画像へリダイレクトします

パラメーター詳細：

url

ドメインとサイトの完全な URL の両方に対応：

  • • example.com
  • • www.example.com
  • • https://example.com/docs
  • • sub.example.com
size

16〜512 ピクセルの正確な正方形 PNG。省略すると元のファイルです。よく使う値：

  • • 16 - 16x16
  • • 32 - 32x32
  • • 64 - 64x64
  • • 128 - 128x128
  • • 256 - 256x256
  • • 512 - 512x512

使用例

JavaScript (Fetch)

JavaScript 
async function getFavicon(url, size = 128) {
  const endpoint = new URL('https://favicondl.com/api/extract');
  endpoint.searchParams.set('url', url);
  endpoint.searchParams.set('size', String(size));
  const response = await fetch(endpoint);
  if (!response.ok) throw new Error(`Favicon request failed: ${response.status}`);
  return await response.blob();
}

const icon = await getFavicon('example.com', 128);
const imageUrl = URL.createObjectURL(icon);
document.querySelector('#favicon-preview').src = imageUrl;

Python (Requests)

Python 
import requests

def get_favicon(url: str, size: int = 128) -> bytes:
    response = requests.get(
        "https://favicondl.com/api/extract",
        params={"url": url, "size": size},
        timeout=15,
    )
    response.raise_for_status()
    return response.content

icon_bytes = get_favicon("example.com", 128)
with open("example-favicon", "wb") as output:
    output.write(icon_bytes)

PHP (cURL)

PHP 
<?php
function getFavicon(string $url, int $size = 128): string {
    $endpoint = 'https://favicondl.com/api/extract?url=' . urlencode($url) . '&size=' . $size;
    $context = stream_context_create(['http' => ['follow_location' => 1, 'timeout' => 15]]);
    $icon = file_get_contents($endpoint, false, $context);
    if ($icon === false) {
        throw new RuntimeException('Favicon request failed');
    }
    return $icon;
}

file_put_contents('example-favicon', getFavicon('example.com', 128));
?>

エラー

エラー時は HTTP ステータスコードと、ok が false でエラーメッセージを含む短い JSON を返します。

HTTPステータスコード エラーメッセージ 説明 解決策
400 Missing url url または domain パラメーターが送信されていません リクエストに ?url=example.com を追加してください
400 Invalid format format が json でも redirect でもありません format=json を指定するか、省略してリダイレクトを受け取ってください
400 Invalid domain 値をホスト名として解析できません example.com のようなドメインか、完全な https:// URL を送信してください
405 Method not allowed GET リクエストのみ対応しています GET リクエストを送信してください
502 Favicon extraction failed 抽出処理がアイコンを返せませんでした しばらくしてから再試行してください
415 Target is not an image /api/proxy のみ：その URL は実際の画像データを返しませんでした /api/extract が返した iconUrl または candidates[].url を使ってください

OpenAPI spec and MCP server

  • OpenAPI 3 spec: https://favicondl.com/openapi.yaml — import it into Postman, Insomnia or a client generator.
  • MCP server: favicondl MCP (registry name io.github.sweesama/favicondl) exposes an extract_favicon tool so Claude, Cursor and other MCP clients can fetch icons.

レート制限

無料

登録不要、すべての機能を完全無料で利用可能

フェアユース

  • • API キーはなく、公開された固定の上限もありません
  • • サイトで見つかったアイコンはエッジで 24 時間、Google/DuckDuckGo へのフォールバックは 10 分間キャッシュされます
  • • アイコンはご自身の側でキャッシュし、大量のクロールは避けてください

商用利用

有料プランや SLA はありません。大量利用や業務上重要な用途では、必要なアイコンをご自身のストレージに保存してください。
