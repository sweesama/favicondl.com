最もシンプルなファビコンダウンローダー＆エクストラクター

Mzu favicondlは、あらゆるウェブサイトのファビコンを即座に抽出・ダウンロードできる無料オンラインツールです。ドメイン名またはURLを入力し、お好みのアイコンサイズを選択するだけ。登録不要、インストール不要、制限なし。

リンクプレビューを作る Web 開発者でも、ブランド素材を集めるデザイナーでも、あるサイトのアイコンが気になっただけの方でも、このファビコン抽出ツールにお任せください。16×16 から 512×512 ピクセルまでのサイズに対応し、ダウンロードのたびにコピーして使える HTML スニペットと直接 URL が付くので、プロジェクトへの組み込みも簡単です。ファビコン（「favorite icon」の略）は、ブラウザのタブやブックマーク、検索結果に表示される小さなアイコンで、ブランドの認知やユーザー体験に大きく関わります。

ファビコンの仕様について詳しくは MDN Web Docs をご覧ください。

高品質なファビコンとは？

高品質なファビコンは、昔ながらの 16x16 の ICO 形式にとどまりません。最近のアプリ、SNS のリンクプレビュー、AI エージェントには 180px、256px、512px といった高解像度のアイコンが必要で、その多くは SVG ベクター、Web App Manifest、Apple touch icon から得られます。Mzu favicondl は、可能な限り旧来のファビコンよりもこうした高品質なソースを優先します。

AI エージェントと開発者向けの組み込みガイド

スクリプトやツール、ワークフローにファビコン取得を組み込むための、コピーして使えるサンプルです。

cURL 
curl -L "https://favicondl.com/api/favicon?domain=github.com&size=32&format=redirect"
JavaScript (Fetch) 
async function getFavicon(domain, size = 128) {
  const url = `https://favicondl.com/api/favicon?domain=${domain}&size=${size}`;
  const response = await fetch(url);
  const blob = await response.blob();
  return URL.createObjectURL(blob);
}
Python (Requests) 
import requests

url = "https://favicondl.com/api/favicon?domain=stripe.com&size=256"
response = requests.get(url, allow_redirects=True)
with open("icon.png", "wb") as f:
    f.write(response.content)

あらゆるサイトのファビコンをダウンロードする方法

  1. ドメインか URL を入力します。このページ上部の入力欄に github.com のようなドメインを入力するか、ページのアドレスをそのまま貼り付けます。https:// や www. は省略できます。
  2. サイズを選びます。16・32・48・64・128 px から選べます。プレビューには見つかった中で最も良いアイコンが表示され、その元のサイズも示されます。選択したサイズでエクスポートは初期状態でオンになっており、PNG を選んだサイズちょうどに変換します。オフにすると元の解像度のまま保存されます。選んだ 32 や 64 などがサイトのアイコンより大きい場合は、拡大されてぼやけることがあると短い注意が出ます。
  3. ダウンロードまたはコピーします。ダウンロードをクリックすると PNG で保存されます。そのまま使える <link> タグや、元ファイルの直接 URL をコピーすることもできます。

手順はこれだけです。アカウント登録もブラウザ拡張もアップロードも必要ありません。PNG ではなく元の .ico や .svg ファイルが欲しい場合は、結果に表示される直接 URL を開いて保存してください。

ファビコン ダウンロードで確認できること

ファビコン ダウンロードは、見ているサイトのアイコンファイルを手元に保存することです。このページの入力欄に URL を入れると、そのサイトが公開しているアイコンを探して、保存まで続けてできます。

  • アイコンの URL を知る。結果に出る直接 URL が、favicon.ico や PNG、SVG など、サイトが実際に配信しているファイルの場所です。
  • サイズと link タグを見る。rel="icon"、Apple touch icon、manifest のアイコンを、測ったピクセルサイズ付きで一覧できます。
  • ファイルを保存する。ダウンロードボタンは PNG です。元の ICO や SVG が必要なら、表示された直接 URL を開いて保存します。登録は要りません。

ブラウザのソースを開いて自分で探す手順は、ウェブサイトからファビコンをダウンロードする方法にまとめています。

ファビコン抽出ツールが探すもの

アイコンを 1 つしか置いていないサイトはほとんどありません。一般的なサイトには、昔ながらの favicon.ico、数枚の PNG、iPhone 用の Apple touch icon、Android 用の Web App Manifest があります。favicondl の抽出ツールは、通常のブラウザと同じようにトップページを読み込み（www から素のドメインへのリダイレクトなども追跡します）、ページ HTML 内のすべての <link rel="…icon…"> タグを読み取り、リンクされた manifest を開いて中のアイコンを集め、さらに定番のパス /favicon.ico と /apple-touch-icon.png も試します。各ファイルは実際にダウンロードして本当に画像かどうかを確認し、実際のピクセルサイズを測定します。

アイコンの種類指定される場所主なサイズ用途
ICO ファビコン/favicon.ico または rel="icon" / rel="shortcut icon"16×16、32×32、48×48（1 つのファイルに複数入っていることが多い）ブラウザのタブ、ブックマーク、古いブラウザ
PNG ファビコンrel="icon" type="image/png" sizes="32x32"16〜96 px最近のブラウザのタブや検索結果
SVG ファビコンrel="icon" type="image/svg+xml"拡大縮小できるベクターどのサイズでもくっきり。ダークモードにも対応可能
Apple touch iconrel="apple-touch-icon" または /apple-touch-icon.png180×180iPhone・iPad のホーム画面のショートカット
Manifest アイコンrel="manifest"（site.webmanifest、manifest.json）192×192、512×512Android のホーム画面やインストールされた Web アプリ
Safari ピン留めタブrel="mask-icon"単色 SVG古い Safari のピン留めタブ

これらがどれも見つからない場合（自動アクセスをブロックしている、JavaScript でしかアイコンを読み込まない、など）は、Google の公開ファビコンサービスにフォールバックするので、小さめでも使える画像は必ず手に入ります。どのサイズがどこで使われるかは、ファビコンのサイズガイドで詳しく解説しています。

最も高解像度のアイコンを手に入れるには

抽出ツールは見つかったアイコンをすべて順位付けし、最も鮮明なものを最初に返します。拡大しても劣化しないフルカラーの SVG が最優先です。次が実測で最も大きい正方形の画像で、たいていは 512 px や 192 px の manifest アイコン、または 180 px の Apple touch icon です。昔ながらの ICO ファイルは幅 16〜32 px しかないことが多いため、たいてい最後になります。Safari の単色 mask アイコンも低い順位です。見つかったほかのサイズも表示されるので、別のものを選ぶこともできます。

  • 元のサイズを保つ。選択したサイズでエクスポートをオフにすれば、ダウンロードした PNG は元ファイルの解像度のままです。
  • 拡大するとぼやけることがあります。16 px のアイコンを 32 px や 128 px にしても細部は増えません。書き出しサイズが元のアイコンより大きいときはプレビューが注意を出します。API の size はその一辺ちょうどの正方形（16、32、64、128、256、512）を返し、ラスタを拡大したときは upscaled が true になります。
  • アイコンの出どころを確認する。API の JSON の source は、サイト自体（html、manifest、direct）かフォールバック（google_s2 または duckduckgo）かを示します。nativeWidth と nativeHeight は元画像のピクセルです（SVG は null）。size を省略すると元のファイルです。
  • 欲しいのはアイコンではなくロゴ？ファビコンはもともと小さく表示するためのものです。印刷物や販促物には、その企業の公式プレスキットやブランドページの素材を使ってください。

ファビコン一括ダウンロード

1 行に 1 つずつ、最大 100 個のドメインを貼り付けるだけ。すべてのファビコンを ZIP でまとめて、または個別の画像としてダウンロードでき、ファイル名はドメイン名か番号を選べます。

無料ファビコン API

GET リクエスト 1 回で、URL からどのサイトのアイコンでも取得できます。API キーも登録も不要。画像へのリダイレクトか、アイコンの URL と取得元を含む JSON を返します。

よくある質問

サイトのファビコンをダウンロードしても問題ありませんか？

ファビコンは公開されているファイルで、サイトを開くたびにどのブラウザもダウンロードしています。保存すること自体は技術的にそれと変わりません。ただしアイコンは多くの場合、運営者のロゴや商標の一部です。リンク先がどのサイトかを示すため（ブックマーク、ダッシュボード、リンクプレビューなど）に使うのは一般的ですが、自分のブランドとして使うのは不適切です。迷ったときはその企業のブランドガイドラインを確認してください。これは一般的な情報であり、法的助言ではありません。

ダウンロードしたファビコンがぼやけるのはなぜですか？

多くの場合、サイトが小さいアイコンしか公開していないか、書き出し時に拡大されています。選択したサイズでエクスポートをオフにすると元の解像度のまま保存されます。16 px や 32 px の ICO しかない場合、どのツールでも失われたディテールは補えません。

ファビコンを一括でダウンロードできますか？

できます。ファビコン一括ダウンロードツールなら一度に最大 100 個のドメインを処理でき、結果を 1 つの ZIP ファイルか個別の画像としてダウンロードできます。

無料のファビコン API はありますか？

あります。https://favicondl.com/api/extract?url=github.com は見つかった最良のアイコンへ直接リダイレクトするので、<img> タグにそのまま使えます。&format=json を付けると、代わりにアイコンの URL と取得元が返ります。キーもアカウントも不要です。結果はそちら側でキャッシュしてください。詳しくは API ドキュメントをご覧ください。

favicon grabber、fetcher、extractor の違いは？

実質的な違いはありません。「favicon grabber」「favicon fetcher」「favicon finder」「favicon extractor」は同じ種類のツールの別名で、サイトを指定するとそのアイコンを探してダウンロードしてくれます。このファビコンダウンローダーはそのすべてに対応しています。

地球儀のような汎用アイコンが返ってきたり、アイコンが取れないサイトがあるのはなぜ？

自動アクセスをブロックしている、ログインやボット確認の向こうにある、ページ読み込み後に JavaScript でアイコンを追加している、そもそもファビコンがない、といったサイトがあるためです。その場合は Google のファビコンサービスにフォールバックするため、小さな画像や既定の地球儀アイコンが返ることがあります。

どの形式でダウンロードされますか？

ダウンロードボタンでは、どこでも使える PNG で保存されます。元の形式が必要な場合は、結果に表示される直接 URL がサイト上の元ファイル（ICO、PNG、SVG、WebP など）を指しています。

localhost や非公開のサイトでも使えますか？

使えません。抽出ツールは当社のサーバー上で動いているため、アクセスできるのは公開サイトだけです。localhost、社内ネットワーク、ログインが必要なページは見えず、画像プロキシもプライベートアドレスへのアクセスを拒否します。

自分の画像をファビコンにできますか？

できます。ツールページの画像→ファビコンを使うと、ロゴを複数サイズの PNG と ICO ファイルに変換し、Web Manifest とサイトに貼り付ける HTML タグと一緒に ZIP にまとめられます。画像はブラウザ内で処理され、アップロードされません。

自分のサイトにはどのサイズのファビコンが必要ですか？

ほとんどのサイトでは、ブラウザ用の SVG か 32×32 の PNG、180×180 の Apple touch icon、そして 192×192 と 512×512 の manifest アイコンがあれば十分です。それぞれについてはファビコンのサイズガイドで解説しています。

もっとツールが必要ですか？

画像からファビコンへの変換、一括処理、または PNG to ICO 変換。
