VitePress ファビコン設定：ステップバイステップガイド

VitePressサイトをデプロイしたのに、ブラウザのタブにまだデフォルトのVitePressロゴが表示されている――そんな経験はあなただけではありません。多くの開発者がpublicフォルダにfavicon.icoを置けば十分だと考えがちですが、VitePressでアイコンを正しくリンクするにはもう少し設定が必要です。このガイドでは、ファイルの配置から結果の確認まで、VitePressサイトにカスタムfaviconを設定する正確な手順を解説します。

前提条件

始める前に、以下を確認してください：

  • VitePressプロジェクトがセットアップ済みであること（バージョン1.x以降）。
  • faviconファイルが用意されていること。ICO、PNG、SVGのいずれかを使用できます。作成が必要な場合は、Mzu favicondlでマルチサイズのfaviconを生成してみてください。
  • VitePressプロジェクトのconfig.jsまたはconfig.tsファイルに関する基本的な知識があること。

ステップ1：faviconファイルをpublicディレクトリに配置する

VitePressは内部でViteを使用しているため、静的アセットはプロジェクトルートのpublicディレクトリに置く必要があります。public内のファイルはルートパスで配信され、ビルド出力にそのままコピーされます。たとえば、favicon.icoをpublicに置くと、ビルド後に/favicon.icoでアクセスできるようになります。

publicフォルダが存在しない場合は作成し、その中にfaviconファイルを配置してください。PNGやSVGファイルを使うこともできますが、ファイル名を覚えておきましょう。

your-project/
├── docs/
│   └── .vitepress/
│       └── config.js
├── public/
│   └── favicon.ico
└── package.json

注意：publicディレクトリはVitePressプロジェクトのルート（package.jsonがある場所）からの相対パスです。docsフォルダを使うデフォルト構造の場合、publicフォルダはdocsの中ではなく、プロジェクトルートに置く必要があります。

ステップ2：VitePress設定でfaviconを構成する

VitePressでは、設定ファイルのheadオプションを使ってサイトの<head>タグを定義できます。ここに<link rel="icon">タグを追加します。

.vitepress/config.js（または.ts）を開き、以下を追加してください：

import { defineConfig } from 'vitepress'

export default defineConfig({
  head: [
    ['link', { rel: 'icon', href: '/favicon.ico' }]
  ],
  // other config...
})

SVG faviconを使用する場合は、typeを指定できます：

head: [
  ['link', { rel: 'icon', type: 'image/svg+xml', href: '/favicon.svg' }]
]

これにより、VitePressはすべてのページの<head>にlinkタグを挿入します。hrefはルートから配信されるため、スラッシュ（/）で始める必要があります。

ステップ3：faviconを確認する

設定後、開発サーバー（npm run docs:devまたはyarn docs:dev）を実行し、ブラウザでサイトを開きます。タブを確認すると、faviconが表示されるはずです。表示されない場合は、キャッシュを回避するためにハードリフレッシュ（Ctrl+F5またはCmd+Shift+R）を試してください。

本番環境では、サイトをビルド（npm run docs:build）し、.vitepress/dist内の生成されたHTMLを検査します。<head>セクションに<link rel="icon">タグがあることを確認してください。

よくある落とし穴

  • ファイルパスの誤り：faviconをプロジェクトルートのpublicではなくdocs/publicに置くと、コピーされません。常にルートのpublicディレクトリを使用してください。
  • 先頭のスラッシュがない：href: 'favicon.ico'（スラッシュなし）を使用すると、ネストされたルートで問題が発生する可能性があります。常に/favicon.icoを使用してください。
  • ブラウザのキャッシュ：ブラウザはfaviconを積極的にキャッシュします。更新後はキャッシュをクリアするか、別のファイル名（例：favicon-v2.ico）を使用して強制的に更新してください。キャッシュの問題の詳細については、faviconが表示されない場合のチェックリストをご覧ください。
  • SVGサポート：SVG faviconは広くサポートされていますが、一部の古いブラウザでは表示されない場合があります。PNGまたはICOのフォールバックを提供することを検討してください。詳細はSVG faviconガイドをご覧ください。

まとめ

VitePressでfaviconを設定するのは、ファイルの置き場所とheadタグの設定方法さえ分かれば簡単です。以下の手順に従えば、ブラウザのタブやブックマーク、検索結果でプロフェッショナルな印象を与えることができます。変更時は異なるブラウザでのテストとキャッシュのクリアを忘れないようにしましょう。完全なfaviconソリューションが必要なら、Mzu favicondlを使って必要なサイズとフォーマットをすべて生成することを検討してください。
