Weebly faviconを追加・変更する7ステップガイド

Weebly サイトのブラウザのタブに一般的な地球儀アイコンや以前のロゴが表示されている場合、この Weebly favicon ガイドでは、アップロードした画像、公開後のページ、配信中のアイコンURLという、揃う必要がある3つの要素を扱います。テーマファイルを編集しなくても、通常の設定だけで追加できます。

前提条件

始める前に、次の3つを用意してください。

  • エディターへのアクセス：Weebly でサイトを開き、変更を公開できる必要があります。
  • 正方形の元画像：アップロードには 512 × 512 PNG が実用的な推奨サイズです。シンプルな形状と強いコントラストのほうが、正式なワードマーク全体より見やすくなります。
  • 公開サイトのURL：別のタブで開いておき、エディターのプレビューと訪問者に表示されるものを区別できるようにします。

Mzu favicondl を使うと、アートワークを切り抜いたり変換したりして、favicon 用のファイルにできます。ラスターサイズを選ぶ必要がある場合は、favicon size guide が各プラットフォームでの一般的な用途を説明しています。

7ステップで Weebly に favicon を追加する

1. すっきりした正方形のアイコンを用意する

ロゴを画像エディターまたは favicon converter で開き、マークが小さく見える原因になる余白を取り除いてください。背景を透明または単色にした正方形 PNG を書き出し、16 × 16 ピクセルで確認します。形が見えなくなったら、単純化してください。

元のアートワークも保存しておいてください。PNG はエディターへのアップロードに使えます。独自のアイコン構成が必要になった場合は、後から SVG や複数サイズの ICO ファイルを生成できます。

2. Weebly のサイト設定を開く

Weebly にサインインしてサイトのエディターを開き、Settings を選び、続いて Site Settings を選択します。Basic を開き、Favicon のアップロードコントロールを探します。エディター内の別の場所に表示されている場合は、ロゴやサムネイルのフィールドではなく、Favicon と表示されているコントロールを使用してください。

そのコントロールが見つからない場合は、続ける前にサイトオーナーにプランとエディター権限を確認するよう依頼してください。これにより、標準のアップローダーがまだ利用できる状態で、2つ目のアイコンシステムを追加するのを避けられます。

3. 画像をアップロードする

Upload を選択し、正方形 PNG を選んで、プレビューが表示されるまで待ちます。マークが大きな空白の枠内に収まっているのではなく、フレームを埋めていることを確認してから、サイト設定を保存します。実体は PNG を使用してください。別の画像形式を PNG にリネームしただけでは、形式は変換されません。

4. 変更を公開する

Weebly エディターで Publish をクリックし、サイトが公開されるまで待ってください。公開後のサイト URL を新しいタブで開いてください。エディター内の preview だけでは、訪問者が新しい icon を取得できることは確認できません。

5. 公開後の icon link を確認する

公開済みページで browser の developer tools を開き、document の <head> を確認します。次のような icon declaration を探してください。

<link rel='icon' type='image/png' href='https://example.com/favicon.png'>

example.com の path は placeholder です。native upload を使った場合、URL は Weebly が生成したものが使用されます。rel='icon' の link は外部 icon を参照するための標準的な HTML 手法であり、HTML Standard にも記載されています。これにより、browser にリクエスト可能な候補 URL が与えられます。

6. 必要な場合のみ advanced variants を追加する

通常の browser-tab icon には、native uploader があれば十分です。asset を個別に管理しており、Weebly のプランで advanced site settings 配下に Head Code field が提供されている場合は、より明示的な stack を追加できます。

<link rel='icon' href='/favicon.ico' sizes='16x16 32x32 48x48'>
<link rel='icon' type='image/png' href='/favicon-32.png' sizes='32x32'>
<link rel='icon' type='image/svg+xml' href='/favicon.svg'>
<link rel='apple-touch-icon' href='/apple-touch-icon.png'>

すべてのサンプル path を、公開アクセス可能な実際の URL に置き換えてください。native upload で既に要件を満たしている場合は、これらの tag を追加しないでください。また、新しい stack を追加する前に、古い custom stack を削除してください。

7. レスポンスと tab を確認する

公開済みページを再読み込みし、private window に切り替えて、browser の Network panel で icon request を確認してください。request では 404 Not Found ではなく image が返り、tab または bookmark にはアップロードした mark が表示されるはずです。

URL を確認しにくい場合は、icon の正確な URL を新しいタブに貼り付けてください。得られるのは HTML error page ではなく image file である必要があります。既存 icon を置き換えた後は、browser cache に留意するか、新しい private window で test してください。

よくある落とし穴

  • 変更はエディターに反映されていますが、サイトは公開されていません。もう一度公開してから、公開前のプレビューではなく公開後のサイトアドレスを読み込みます。
  • 古いアイコンがまだキャッシュされています。プライベートウィンドウでテストし、ページをハードリロードします。公開中のマークアップと画像が正しい場合は、faviconのトラブルシューティングチェックリストに従います。
  • アイコンのURLが404を返します。開発者ツールでhrefを確認し、直接開きます。/favicon.icoにファイルがあるとは仮定せず、公開中のページにある実際のURLを使用します。
  • 複数のアイコンタグがあると、設定のトラブルシューティングが難しくなります。古いカスタムコードまたは重複したアップロードを削除し、意図した一組の宣言だけを残します。
  • マークが細かすぎます。ロゴの主要なシンボルを使って作り直し、小さなテキストを削除して、16ピクセルでの描画を確認します。
  • Faviconフィールドがありません。サイト所有者がサイト設定にアクセスでき、自分のアカウントにサイトを変更する権限があることを確認します。

最終確認

Weeblyのfaviconは、エディターに意図したアイコンが表示され、サイトが公開され、公開中のheadに有効なアイコンリンクが含まれ、そのURLが画像ファイルを返す場合に完成です。次回の置き換えでサイズやパスの問題が再発しないように、正方形の元PNGと生成されたバリアントを一緒に保管してください。
