Google Sitesのfaviconを追加・確認する手順ガイド

Google Sites の favicon（サイトアイコン）が、ブラウザタブで 여전히genericな地球儀アイコンやページアイコンとして表示される場合、アップロードが下書きにだけ反映されたか、公開中のbooookで別のicon URLが配信されている可能性GREE高いです。theme XMLを編集しなくても、この問題は解消できます。

以下の手順では、Google Sitesのfaviconを追加して公開し、ブラウザでのアイコン表示とGoogle Searchでの掲載適格性を確認します。ブラウザでの確認とSearchでの確認は別々です。ブラウザでは正しく表示されても、Searchでは再クロールを待っていることがあります。

faviconとサイトへのアクセスを準備する

サイトを編集して公開できるブラウザでGoogle Sitesを開きます。作業を始める前に、ロゴマーク、モノグラム、シンボルなどを入れた正方形の画像を 준비してください。wordmark全体を配置すると、通常は16×16ピクセルでは判読困難になります。

  • アクセス権: サイトの編集権限と公開権限。
  • 元画像: simplestなアップロード候補は正方形のPNGです。実用的な素材としては、中央にシンプルなマークを配置した192×192ピクセルのPNGを使用してください。
  • 公開URL: 訪問者がfaviconを見る、sites.google.comのアドレスまたはカスタムドメイン。

Googleでは、Searchのfaviconは正方形で、少なくとも8×8ピクセルである必要があると説明しています。また、48×48ピクセルより大きい画像を推奨しています。faviconは表示対象として適格であれば、必ず表示されるとは限りません。そのURLは安定状態を保つべきです。詳しくはGoogleのfaviconドキュメントを参照してください。

素材がSVG、JPG、または別の形式の場合は、アップロード前に正方形のPNGへ変換してください。Mzu favicondlでこの変換 Conceivably行えます。エクスポート前に図形を簡略化しておくと、ブラウザタブに表示されるサイズでも輪郭を保ちやすくなります。

カスタムコードなしでGoogle Sitesのfaviconを追加する

  1. サイト設定を開きます。

    Google Sites のダッシュボードを開き、対象サイトを選択して「編集」をクリックします。編集画面の右上にある「公開」の横の「その他（More）」または三点メニューから「サイト設定」を選択します。「Favicon」コントロールを見つけ、ファイルピッカーを開きます。

  2. 画像をアップロードして確認します。

    準備した PNG を選択します。プレビューまたはクロップ領域を確認し、マーク全体が中心に表示されるよう調整してから、選択を保存します。アイコンが暗いブラウザタブ上で見失われないよう、背景に対して十分なコントラストのある単色を使ってください。

  3. 更新したサイトを公開します。

    「公開」をクリックし、サイトの URL を確認して、更新を公開します。「サイト設定」で画像を保存しても、新しいバージョンを公開するまで、訪問者に表示されるサイトは変更されません。

  4. 公開済みのホームページを確認します。

    編集画面のプレビューではなく、公開済みの URL を新しいタブで開きます。ブラウザーの DevTools でドキュメントの head を調べ、icon link を確認します。続いて、DevTools のコンソールで次の snippet を実行します。

    Array.from(document.querySelectorAll('link[rel~=icon]')).map(function (link) {
  return {
    href: link.href,
    type: link.type,
    sizes: link.getAttribute('sizes') || ''
  };
})

    結果には、少なくとも1つの favicon URL が含まれるはずです。HTML 標準では、rel='icon'はアイコンの外部リソースリンクとして定義されています。そのため、favicon.icoで終わるリンクと決めつけるのではなく、リンクの実際の URL を確認してください。

    「Network」パネルでページを再読み込みし、icon のリクエストを選択します。HTML の fallback や 404 レスポンスではなく、画像レスポンスが返るはずです。

  5. ブラウザーでの表示を確認します。

    公開済みのページを再読み込みし、タブ、ブックマーク、ショートカットを確認します。古いアイコンが残っている場合は、コンソールに新しい asset の URL が表示されているか確認してから、プライベートウィンドウで試してください。ブラウザーは、通常のページコンテンツとは別に favicon をキャッシュする場合があります。

  6. Google Search の再クロールを待ちます。

    Google のSearch favicon 要件を使って、正方形であるか、最小サイズ、安定した URL、クロールアクセスを確認してください。公開後、再クロールには数日から数週間かかる場合があるため、直ちに Search の結果に反映されなくても、アップロードが失敗した証拠にはなりません。

    検索結果でアイコンが表示されない問題を絞り込んで診断する場合は、Google Search favicon チェックリストを参照してください。

Google Sites の favicon でよくある落とし穴

  • 編集画面ではなく公開済みドメインを確認している：編集時のプレビューだけを確認するのではなく、公開済みのホームページに favicon が含まれていることを確認してください。
  • アセットを繰り返し変更している：置き換えるたびに新しいアイコン URL が生成される可能性があります。Google が認識した後は、公開済みの URL を安定させてください。
  • 細部の多いロゴを使用している：細い線や小さな文字は、16×16 のタブでは見えません。公開前にそのサイズでロゴを確認してください。
  • キャッシュの問題と Search の反映遅延を混同している：更新経路が異なるため、ブラウザには新しいアイコンが表示されても Google Search には古いアイコンが残る、逆にそのパターンになることもあります。
  • 競合する icon タグを追加している：Google Sites 標準のアップロード機能を使う場合、複数の rel='icon' の候補を追加和不必要な HTML の埋め込みは避け、トラブルシュートを複雑にしないようにしてください。

最終的な設定を確認する

確実に設定する手順はシンプルです。Site settings で正方形の PNG を 1 点アップロードし、公開して、公開済みのホームページを確認してから、Google Search に再クロールさせます。別の no-code プラットフォームを管理している場合も、より一般的な no-code website favicon ガイドと手順を比較してみてください。

公開済みのアイコン URL は変更せず、ブランドのアセットを変更した場合は canonical ホームページを再確認してください。これにより、ブラウザ利用者、ブックマーククライアント、Google のクローラーが参照する一貫したソースになります。
