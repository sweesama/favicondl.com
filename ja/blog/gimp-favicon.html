GIMP でマルチサイズ favicon ICO を作成

GIMPで48ピクセルにエクスポートした画像は、モニターではシャープに見えても、ブラウザーのタブではぼやけた正方形になってしまうことがあります。対策は、GIMPで16、32、48ピクセルの版を個別に用意し、それらを1つのマルチサイズfavicon.icoにパッケージ化することです。このGIMP favicon ICOのワークフローを 따르면、PNGのファイル名を変更する方式に頼るのではなく、予測可能なファイルを作成できます。

前提条件

  • GIMPのFile > New、Image > Scale Image、File > Export Asの各コマンドを使います。
  • 正方形のロゴまたはマークを用意します。512 × 512ピクセルのマスターを用意すると、縮小する前にアートワークを簡略化する余地が確保できます。
  • 必要に応じて、最終的なパッケージング工程にImageMagickをインストールします。代わりにMzu favicondlを使えば、ブラウザー内でPNGのエクスポートを変換することもできます。

favicon ICOの作成手順

  1. 透明なマスター画像を作成する

    File > New を選び、縦横を 512 × 512 に設定して、Fill with Transparency を選択します。ロゴを読み込むか、GIMP でマークを描いてください。小さいサイズでも余白が見えるよう、主要なシルエットは中央の正方形内に収めてください。

    favicon は縮小したロゴではありません。書き出す前に、小さな文字や細い線を減らし、グラデーションも控えてください。単一の太い形状のほうが、通常は鮮明に見えます。

  2. マスター画像から各サイズを作成する

    File > Duplicate でマスターの複製を作り、Image > Scale Image を選択します。幅と高さがリンクされた状態で、複製を1枚は 16 × 16、別の1枚は 32 × 32、3枚目を 48 × 48 に拡大縮小します。各複製は、必ず512 pxのオリジナルから縮小してください。16 px版を拡大しても、輪郭が柔らかくなるだけです。

  3. 16 px版を修正する

    16 pxの複製を開き、View > Show Pixel Grid を有効にします。拡大して、隣のpixelに溶け込むような細かい部分を削除したり、マークの位置を調整してください。32 px版でも同じ確認を行います。32 pxではより多くのディテールを残せますが、薄すぎる1 pxの線は依然として消えることがあります。

  4. alpha channelの透明性を保持する

    読み込んだlayerにalpha channelがない場合は、そのlayerを選択して Layer > Transparency > Add Alpha Channel を選びます。背景を白で塗るのではなく、透明なままにしてください。PNGへの書き出しではこの透明性が保持され、ICO encoderにノイズのない元画像が渡せます。

  5. 3つのPNGファイルを書き出す

    File > Export As を選び、icon-16.png と入力して、Export をクリックします。同じ手順で icon-32.png と icon-48.png を書き出し、同じfolderにまとめてください。PNG版は正確な寸法とalpha channelを保持しているため、パッケージング用の元データとして使えます。

  6. ICOを書き出す、またはパックする

    GIMPのICO exporterを使ってみる場合は、48 pxの複製を選択し、File > Export As を選んで favicon.ico と入力します。Export optionsを確認し、サイズのリストが表示される在其中、16、32、48 pxを選択します。リストが表示されない場合、書き出し結果に現在のキャンバスだけが含まれる可能性があるため、3つのPNGを明示的にパックしてください。

    PNGファイルと同じfolderで、次のcommandを実行します。

    magick -background none icon-16.png icon-32.png icon-48.png favicon.ico

    command名が convert になっているsystemでは、magick を convert に置き換えてください。結果は、3つの画像サイズを含む1つのICOになります。

  7. 埋め込みサイズを確認する

    ImageMagickをインストール済みの場合は、magick identify favicon.ico を実行し、出力に 16x16、32x32、48x48 のentryが表示されることを確認してください。サイズが欠けている場合は、該当するPNGをGIMPで確認し、パッキングのcommandを再実行します。また、各PNGを高倍率で開き、iconに白背景や新たにぼやけた輪郭がないことも確認してください。

  8. ICOを配置する

    favicon.ico をサイトのpublic rootにコピーし、ドキュメントの <head> からリンクします。

    <link rel='icon' href='/favicon.ico' sizes='16x16 32x32 48x48'>

    HTML標準は、icon resourceをリンクするための rel='icon' を定義しています。サイトがsubpathの下にある場合は、URLを調整してください。完全なmarkupとmobile icon variantsについては、ウェブサイトにfaviconを追加する方法を参照してください。

GIMPでfavicon ICOを作るときのよくある落とし穴

  • 解像度が1種類しかない。 ファイル名だけで判断せず、containerの中身をverifyしてください。16、32、48 pixelのセットは、ブラウザ向けの実用的なbaselineです。favicon size guideでは、他のフォーマットをどの場面で使うべきかも説明しています。
  • 小さいアイコンがぼやける。 単にサイズを縮小するのではなく、アートワークそのものも簡素化してください。48 pixelでは許容範囲に見える細かな文字や1 pixelのディテールでも、16 pixelでは潰れて判別できなくなります。
  • 透明情報が失われる。 exportする前にalpha channelを追加し、白やテーマ色の背景にflattenしないでください。
  • 公開中のSiteに古いアイコンが残る。 /favicon.icoがHTMLのエラーページではなくICOを返すことを確認してください。古いファイルがキャッシュされている場合は、/favicon.ico?v=2のようなversioned URLでdeployしてください。

作成結果をコントロールしやすくする

アートワークの準備とcontainerのパッケージングは分けて考えます。GIMPなら、小さいサイズごとの描画を細かく制御できます。一方、パッケージングの工程では、favicon.icoにどの解像度を収録するかを保証できます。
