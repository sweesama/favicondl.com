Inkscapeでfaviconを作成・書き出す方法

Inkscapeのアートワークはキャンバス上では問題なく見えるのに、ブラウザーのタブではトリミングされてぼやけてしまうなら、通常はエクスポート形式ではなくドキュメント側が原因です。Inkscapeのfaviconには、正方形の図案、移植可能なパス、Webでそのまま使える少数のファイルが必要です。

Prerequisites

Inkscapeと、既存のSVGロゴを用意します。アートワークが横長のページ上にある場合は、新しい正方形のドキュメントを作成し、シンボルをコピーして等比率でスケールし、そのファイルを編集可能なマスターとして保存してください。16×16ピクセルでも認識できるシンボルのほうが、ワードマーク全体よりも適しています。

たとえば、元のデータが1200×400のワードマークなら、その長方形をそのままfaviconに押し込まないでください。シンボルのみを選択して正方形のドキュメントに貼り付け、等比率でスケールします。这样すれば、元のアートワークを変更せずに何度もエクスポートできるコンパクトなマスターになります。

  • 実用的なデザインサイズとして、128×128ピクセルのアートボードを使用します。
  • マークを中央に置き、周囲に少し透明な余白を確保します。
  • 小さなサイズでも区別できないディテールは削除します。

1. 正方形のキャンバスとviewBoxを設定する

File → Document Propertiesを開き、単位をpixelsに設定して、ドキュメントの幅と高さを同じにします。128×128というサイズはブラウザーへの要件ではなく推奨値であり、64×64でも問題ありません。128×128のドキュメントでは、viewBoxが0 0 128 128になっていることを確認してください。

Object → Align and Distributeを開き、参照元としてPageを選び、アートワークを水平・垂直方向の中央に配置します。ページプレビューが正方形で、どの辺もトリミングされていないことを確認してください。

2. テキストと崩れやすいエフェクトをパスに変換する

各テキストオブジェクトを選択し、Path → Object to Pathを実行します。これにより、使用したフォントがないサーバー側で、別の形状に置き換えられるのを防げます。

设计上重要な破線やアウトライン化されたstrokeには、Path → Stroke to Pathを使用します。gradient、mask、filterは必要な場合に限って残してください。これらはSVGが異なる環境に配信された際の失敗要因になります。

3. 移植可能なSVGを保存する

File → Save Asを選択し、Plain SVGを指定して、favicon.svgという名前でコピーを保存します。

SVGの変換する前に、ドキュメントプロパティのviewBoxが正方形になっていること、アートワークがexternal font、linked bitmap、またはstylesheetに依存していないことを確認してください。logoにlinked imageが含まれている場合は、SVGの隣に配置して意図的にlinkし直すか、同等のvectorに置き換えてください。

4. 512×512のPNG fallbackをexportする

File → Export PNG Imageを開き、export areaにpageを指定して、幅と高さの両方を512 pixelsに設定します。backgroundはtransparentに保ったまま、favicon-512.pngとしてexportしてください。

この高解像度PNGなら、converterが小さなraster sizeを生成するために十分なpixelsがあり、browserに極小のsourceを拡大させる必要がありません。

exportをrepeatableにするには、次のcommandも実行できます。

inkscape favicon.svg --export-type=png --export-area-page --export-width=512 --export-height=512 --export-filename=favicon-512.png

このcommandは正方形のpage boundsを使用し、512-pixel PNGをcurrent working directoryに書き出します。

5. Inkscapeのfavicon packageを作成する

Mzu favicondlを開き、favicon.svgまたはfavicon-512.pngをuploadして、複数サイズのICOを生成し、ダウンロードしてください。16×16、32×32、48×48の画像を含むICOを推奨します。併せて、apple-touch-icon.pngという名前の180×180 PNGも作成依頼してください。

packaging processを詳しく確認したい場合は、SVG to ICO guideを参照してください。また、favicon size guideでは、追加のPNGとApple向けsizeを解説しています。

HTML Standardでは、rel='icon'を、user interface上でpageを表すexternal resourceへのリンクとして定義しています。この定義によって特定の1つのfile formatが必須になるわけではないため、compatibilityを考慮し、SVGとICO fallbackを併用することを推奨します。

6. fileを配置してHTMLを追加する

favicon.ico、favicon.svg、apple-touch-icon.pngを、siteが配信できるpathに配置してください。以下のlinksを<head>内に追加してください。

<link rel='icon' href='/favicon.ico'>
<link rel='icon' href='/favicon.svg' type='image/svg+xml'>
<link rel='apple-touch-icon' href='/apple-touch-icon.png' sizes='180x180'>

root-relative パスは、deployment root と一致する場合にのみ使ってください。subpath 配下で配信されるアプリケーションでは、パスを更新するか相対パスに変更してください。ICO は fallback として保持し、SVG はスケール可能な master として扱ってください。

7. 実際のレスポンスを確認する

サイトを開き、hard reload したうえで、各 icon URL について Network panel を確認してください。リクエストが 200 ステータスで image response を返し、サイトの HTML 404 page になっていないことを確認してください。

/favicon.svg に直接アクセスして、SVG が描画されることを確認してください。古い icon が表示され続ける場合は、deployment を変更する前に、まず browser が新しい URL を取得했かどうかを確認してください。

ICO の response は terminal からも確認できます。

curl -I https://example.com/favicon.ico

URL を自分のドメインに置き換え、SVG と PNG ファイルについても同じ確認を行ってください。

よくある落とし穴

  • Artwork がトリミングされます。 元の横長 canvas ではなく、正方形のページから export してください。
  • Text の形が変わります。 最終 SVG を保存する前に、text を path に変換してください。
  • リンクしたアセットが読み込めません。 リンクした bitmap は vector artwork に置き換えるか、安定した relative path にまとめて配置してください。external stylesheet への依存も取り除いてください。
  • アイコンが何も描かれていないように見えます。 16×16 で表示して確認し、silhouette、spacing、contrast を見やすく整理してください。
  • 古い icon が残ります。 cache のせいだと判断する前に、HTML source と Network panel を確認してください。
  • アイコンが引き伸ばされて見えます。 viewBox は正方形に保ち、正方形の PNG を export してください。sizes は artwork をリサイズしません。

毎回同じ結果を得られるワークフローを構築する

これで、Inkscape favicon の再現可能なワークフローが整いました。正方形の vector master が 1つ、text は outline 化済み、移植しやすい SVG、512ピクセルの PNG、ICO の fallback、明示的な HTML link が揃っています。今後の export が一貫するよう、master SVG は変更せずに保持してください。
