GoDaddy Website Builderのfavicon設定方法

GoDaddyのサイトでブラウザタブにデフォルトアイコンのまま表示されている場合、差し替え画像がプレビュー段階に留まっているか、ブラウザが古いfaviconを再利用している可能性があります。GoDaddy Website Builderのfaviconは、ページ内のセクションに配置する画像ではなく、サイト全体で使うブラウザアイコンです。エディターでアップロードしてサイトを公開し、公開中のHTMLが何を配信しているかを確認してください。

前提条件

GoDaddyのサイトを編集・公開するアクセス権と、正方形のソース画像が必要です。アップロードにはPNGが汎用的です。512×512 pxのソースを用意しておくと、書き出し前にアートワークを簡略化する余地になります。細い線や細かい文字は通常は判別できなくなるため、16×16 pxでもロゴマークが認識できる状態を保ってください。

  • GoDaddyのログイン情報とWebsite Builderサイトへのアクセス権
  • 背景が明確な正方形のPNGまたはSVGソース
  • 公開ドメインのURLと、Developer Toolsを備えたブラウザ

最終的なPNG、ICO、SVGの各形式はMzu favicondlで準備できます。GoDaddy標準のアップロード機能を使うのが最も simplicity な方法ですが、追加の形式が必要になるのは手動での代替作業を行う場合だけです。

GoDaddy Website Builderにfaviconを追加する手順

1. Website Builderでサイトを開く

GoDaddyにサインインし、Websites and Shopを開いて、Website Builderサイトに接続されているドメインを選択します。Edit Websiteを選んでエディターに入ります。すでにエディターが開いている場合は、次の手順に進んでください。

2. favicon設定を開く

エディターのサイト全体設定パネルを開き、Faviconを探します。現在のエディターレイアウトによっては、この設定がSettingsの下にあるか、Website iconとして表示されます。セクション内の画像ブロックや通常のロゴ設定ではなく、サイト全体に対する設定を選んでください。

3. 画像を準備して選択する

表示されているボタンに応じて、Upload、Replace、またはSelect imageを選択します。正方形のPNGを選び、縦横比を変えずにマークがフレームに収まるようにクロップしてください。ロゴ全体を端まで拡大するのではなく、記号の周囲に少し余白を残します。

実際のブラウザタブと同じサイズで結果を確認します。アートワークが細かすぎる場合は、ソースファイルに戻って簡略化してください。小さなラスター画像を拡大しても、ぼけが鮮明になるだけです。

4. faviconを適用する

プレビューを確認し、Apply、Save、または同等の確認ボタンを選択します。エディターのプレビューに、設定したsymbolが表示されていることを確認してください。一部のエディターではプレビューがすぐに更新されますが、変更が反映されるのは公開後だけの場合もあります。

5. 変更を公開する

エディター上部のツールバーでPublishを選択し、公開完了の確認を待ちます。新しいタブで、エディターのcanvasではなく、公開中のドメインを開いてください。未公開の変更は、エディターでは正しく見えても、訪問者には以前のサイトファイルが配信されることがあります。

6. 公開中のアイコンリクエストを確認する

公開中のページのソースを開き、ドキュメントの<head>にicon linkがあることを確認します。rel='icon'のHTML仕様は、ページを表すアイコンのリンク関係を定めています。標準機能による出力は、次のようになる場合があります。

<link rel='icon' href='/favicon.ico'>

ブラウザーのDeveloper ToolsでNetworkパネルを開き、公開中のページをリロードして、アイコンのリクエストを探します。成功したレスポンスが返り、アップロードしたファイルを指していることを確認してください。公開中のHTMLにicon linkがない場合は、重複タグを追加するのではなく、手順2に戻ります。

7. 必要な場合のみ手動のfallbackを使う

標準のコントロールが希望するICOまたはSVGを受け付けられない場合は、エディターにcustom HTMLまたはdocument-head fieldが用意されている場合にのみ、fallbackを追加します。各ファイルを安定した公開URLにアップロードし、head内でそのURLをそのまま指定してください。/favicon.icoのようなパスが実際に存在するとは、その場所にアップロードするまでは想定しないでください。

<link rel='icon' href='/favicon.ico'>
<link rel='icon' type='image/png' sizes='32x32' href='/favicon-32x32.png'>
<link rel='icon' type='image/svg+xml' href='/favicon.svg'>
<link rel='apple-touch-icon' sizes='180x180' href='/apple-touch-icon.png'>

各サンプルのパスを実際の公開URLに置き換え、Website Builderがすでに生成した重複するicon tagsを削除します。ご利用のプランまたはエディターにcustom-head controlがない場合は、代わりに標準のアップロード機能を使用します。

よくある落とし穴

プレビューは変わるが、公開中のサイトは変わらない

サイトを公開し、公開 URL で動作をテストします。ブラウザータブのアイコンはキャッシュが残っている場合があるため、画像を再度変更する前に、プライベートウィンドウを使うか、How to Clear Favicon Cache の手順でキャッシュを削除してください。

ブラウザーが存在しないファイルを要求している

公開中のページの <head> にあるアイコン URL と、Network パネルのリクエストを比較します。404 が返る場合は通常、ファイルが別のパスにアップロードされている、URL が古くなっている、または手書きのマークアップが存在しない場所を参照していることが原因です。標準の link タグは存在するのにアイコンが表示されない場合は、より包括的な Favicon Not Showing のチェックリストに従ってください。

アイコンが切れている、伸びている、または見えない

正方形の元画像をアップロードし、シンボルmark を中央の安全な領域内に収めてください。透過設定によってタブの背景に対してマークが判らなくなる場合は、背景を塗りつぶしたバージョンを書き出し、16×16 px で比較します。

タブに古い-DoDaddy ブランドが表示され続ける

GoDaddy が保存に失敗したと思い込む前に、公開中のマークアップを確認します。新しいファイルを指している場合は favicon キャッシュを削除してください。古いファイルを指している場合は、再公開し、古いテンプレートや重複したアイコン link がアップロードを上書きしていないかを確認します。

公開ページでの最終確認で仕上げる

公開済みページに正常なアイコンのリクエストが含まれ、ブラウザータブに意図したマークが表示されれば、設定は完了です。キャッシュやアイコンの選択挙動は環境によって異なるため、2 台目のブラウザーやデバイスで同じ確認を繰り返し行ってください。これにより、以降の GoDaddy でのブランド変更每一次に使える、再現可能な手順が得られます。
