Wix のファビコンが Google 検索結果に表示されない問題を解決

Wix の favicon がブラウザタブに表示されても、Google 検索結果に必ず表示されるわけではありません。公開ドメインに正しい設定が反映され、Google がページと画像をクロールできることを確認したうえで、表示の最終判断は Google に委ねられます。

まず Wix 標準の favicon 設定を使う

最初から Custom Code を追加する必要はありません。Wix 公式ガイドでは、カスタム favicon に Premium プラン、接続済みドメイン、公開済みサイトが必要だと説明されています。

  1. サイトの Dashboard で Settings を開きます。
  2. Website settings を選びます。
  3. Favicon の Upload Image からファイルを設定します。
  4. シークレットウィンドウで公開ドメインを開き、エディタ内だけでなく本番サイトに反映されたことを確認します。

Wix は SVG 以外について 48×48、96×96 など 48 ピクセルの倍数を案内しています。これは Wix のアップロード条件であり、Google 全体の最小要件ではありません。

Google が利用できる状態か確認する

Google Search の公式文書では、ホームページに対応する rel 値でアイコンを指定し、ホームページと favicon をクロール可能にする必要があります。Wix の設定を使うと通常はタグが生成されるため、本番 HTML にタグがないと確認できた場合を除き、重複するタグを手動追加しないでください。

Google の最小サイズは正方形の 8×8 ピクセルで、48×48 より大きい画像を推奨しています。URL は安定させる必要があり、条件を満たしても表示は保証されません。

公開ページを点検する

  1. 公開ホームページのソースで rel='icon' などを検索します。
  2. 参照先 URL を直接開き、ログイン不要で画像が返り、404 や HTML エラーではないことを確かめます。
  3. robots の設定が Googlebot と Googlebot-Image を遮断していないか確認します。
  4. 古いアイコンを参照している場合は Wix で再設定し、本番ドメインへの反映を確認します。

favicon チェックガイドも、リンクとファイルの確認に利用できます。

再クロールを依頼して待つ

本番ページが正しくなったら、Google Search Console の URL 検査でホームページのインデックス登録をリクエストします。これは即時更新ではありません。Google は処理に数日から数週間かかる場合があると説明しています。

  • エディタのプレビューだけで判断しない。
  • 48×48 を Google の最小要件と誤解しない。
  • 試すたびに URL を変更しない。
  • 表示までの固定時間を約束しない。
  • 確認せずに重複タグを追加しない。

正しい手順

Wix の Website settings で設定し、公開ページと画像 URL を確認し、Search Console で再クロールを依頼して通常の処理期間を待ちます。すべて正常なら、設定を繰り返し変更するより監視を続ける方が安全です。
