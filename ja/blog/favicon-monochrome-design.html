単色アイコンとは？作り方とファビコンでの使い方

単色アイコンとは、形を1色のシルエットで表すアイコンです。写真や多色ロゴを小さく縮めたものではなく、塗られていない部分は透明です。ブラウザのタブ、Safariの古いピン留めタブ、Androidのテーマアイコンでは、この「1色の形」が別々の仕組みで使われます。

多色のロゴは、印刷物やページの見出しでは見栄えがします。16×16ピクセルのタブに縮小すると、輪郭が潰れて読めなくなることがあります。色を1つに限ると、形だけで見分けがつくかを先に確認できます。

単色アイコンとは

見た目が1色でも、色を決める場所は仕組みごとに違います。次の3つは別物です。同じファイルを使い回さないでください。

Safariの mask-icon（ピン留めタブ）

ピン留めタブ用の単色アイコンは、通常のファビコンとは別のSVGです。Appleのピン留めタブの文書はアーカイブにあり、最終更新は2016年です。そこでは、背景を透明にし、図形は100%の黒、SVGは1レイヤー、viewBoxは"0 0 16 16"と定めています。SafariはSVGの中に書いた色を使わず、<link>のcolor属性の1色でその形を塗ります。

<link rel="mask-icon" href="/safari-pinned-tab.svg" color="#1d4ed8">

colorには16進数、rgb()、またはredのような色名を書けます。白、明るい黄、薄いグレーは見えにくい、とAppleは注意しています。

この仕組みは新しいSafariではレガシーです。Safari 12以降、タブには通常のファビコンを出せます。ピン留めタブ専用の mask-icon は、現行のSafariで必須ではありません。文書がアーカイブに残っているからといって、今も別ファイルを置かなければならないわけではありません。mask-iconを残すと、まだこの指定を読む版では通常のファビコンよりこちらが使われることがあります。新しく作るサイトでは、通常のファビコンを優先してください。手順の詳細はSafariピン留めタブアイコンにあります。

Androidのテーマアイコンと purpose: "monochrome"

W3CのWeb Application Manifestでは、アイコンのpurposeにmonochromeを書けます。これはmaskableとは別の値です。maskableは、円や角丸に切り取られてもロゴが残るセーフゾーン用です。monochromeは、バッジやピン留め、システムのテーマ色で塗る単色アイコン向けのヒントです。

Android 13以降のテーマアイコンは、透明なシルエットをシステムが選んだ1色で塗る表示です。purposeにmonochromeと書くのは、そのためのヒントです。仕様では、ユーザーエージェントは赤・緑・青をそのまま出してはならず、アルファ（透明度）だけを残して、自分で選んだ1色を塗ります。画素を黒にし、透明部分でシルエットを作る方法が案内されています。余白を足すことや、透明部分の背後に背景色を置くことも許されています。

{
  "src": "/icon-monochrome.png",
  "sizes": "512x512",
  "type": "image/png",
  "purpose": "monochrome"
}

これはヒントであって、表示の保証ではありません。Chromeがホーム画面に追加したアイコンが、この画像を必ずテーマアイコンとして使うとは限りません。対応はブラウザと、アプリとしてパッケージするかどうかで違います。宣言しただけで、すべての端末のアイコンが単色になるわけではありません。

"purpose": "any maskable"は切り抜き用であり、単色用ではありません。単色が必要ならmonochromeを別の画像に書きます。monochromeだけのアイコンは、対応しないユーザーエージェントでは通常の起動アイコンとして使われません。192と512の通常アイコンはファビコンサイズガイドの表にあります。

タブ用の1色SVGファビコン

タブ用のSVGは<link rel="icon" type="image/svg+xml" href="/favicon.svg" sizes="any">です。これはマスクではありません。ブラウザはSVGに書いたfillをそのまま描きます。塗りが1色なら、それが単色のSVGファビコンです。sizes="any"は、決まったピクセル数ではなく拡大縮小できる、というHTMLの印です。

ダークモードで色を変えるときは、SVGの中の@media (prefers-color-scheme: dark)で、同じ1つの塗りを切り替えます。その色はファイルの作者が決めた値です。Safariのmask-iconのcolor属性とも、マニフェストのmonochromeが選ぶ色とも別です。

Google検索が受け付ける形式はICO、PNG、GIF、JPEG、BMP、TIFF、PPMです。SVGはこの一覧にありません。検索結果用には正方形のICOかPNGも残します。現行の案内は一辺8px以上で、48pxより大きい画像を推奨しています。「48pxの倍数で、最低48×48」という説明は現行の文書にはありません。

単色アイコンの作り方

用途でファイルの中身が違います。タブ用SVG、mask-icon、マニフェストの monochrome は、別々に用意します。

SVGは1色にする

タブ用なら、塗りの色は1色にします。次の例は、明るい画面では濃いグレー、暗い画面では薄いグレーに切り替えるSVGです。#111111と#eeeeeeは見やすさのための選択であり、仕様が決めた必須値ではありません。

<svg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 100 100'>
  <style>
    path { fill: #111111; }
    @media (prefers-color-scheme: dark) {
      path { fill: #eeeeee; }
    }
  </style>
  <path d='M50 10 L90 90 L10 90 Z' />
</svg>

純黒（#000000）は明るいグレーのタブで強く見え、純白（#ffffff）は暗いタブで滲むことがあります。これはタブ用SVGの話です。mask-iconの図形は、Appleの文書どおり100%の黒にします。表示色はcolor属性で指定します。

背景は透明にする

色を塗らない部分は透明にします。白や写真の背景を残すと、暗いタブでは白い四角になります。mask-iconも monochrome も、形以外は透明です。

形は単純にする

重なった色や細かい紋章は、1色にすると塊になります。文字は入れません。一番太いシルエットだけを残します。内部の線は、16pxまで縮めても残る太さ（目安として2px以上）にします。形を削る手順は一般的なFaviconデザインのヒントも参照してください。

コントラストを確認する

タブ用SVGは、白背景と黒背景の両方に置いて、形が消えないかを見ます。マニフェストの monochrome は別です。仕様上、赤・緑・青は捨てられ、アルファだけが残ります。不透明なグレーで濃淡を描いても、そのグレーは色として残りません。薄い部分が必要なら、グレーの塗りではなく透明度で抜きます。

公開中のページが今どのURLを返しているかは、ファビコン取得ツールで確認できます。自分の画像から各サイズのPNGやICOを書き出す場合は、ツールの画像→ファビコンを使います。単色のSVGそのものを自動で描く機能ではありません。

2026年に単色アイコンが勝つ理由

GitHubを見てみましょう。彼らのOctocatロゴは非常に詳細ですが、Faviconは純粋な単色のシルエットです。OSをダークモードに切り替えると、アイコンは黒から白へ反転します。背景の四角形に頼らず、失われる細部も少なくなります。

使える色が1つしかない場合、陰影やグラデーションで形を定義できません。幾何学とネガティブスペース（余白）に頼る必要があります。タブが細くなっても、太い形の方が残りやすい、というのがこの選択の理由です。

OSやブラウザがタブの色を変えると、フルカラーのロゴは背景とぶつかりやすくなります。タブ用の単色SVGは、作者が決めた1色を暗い画面用に切り替えられます。ただし、その切り替えは mask-icon のcolor属性や、マニフェストの monochrome が選ぶ色とは別の仕組みです。

モノクロFaviconデザインのコア原則

詳細よりシルエット

アイコンは、単一の形状として認識できる必要があります。ロゴが重なり合う色に依存している場合は、特定のモノクロバリアントを描く必要があります。テキストを外し、一番太く、一番わかりやすい形に絞ります。

ネガティブスペースの習得

色が1つしかないため、透明度が2番目の色になります。内部の形は、太く意図的な切り抜きで作ります。細い線は、低解像度ではアンチエイリアスがかかり灰色の塊になります。

厳密なピクセルグリッドの配置

単色では、にじんだ縁が目立ちます。ベクターの点は16×16または32×32のグリッドに載せます。2つのピクセルの間に置いた直線は、鋭い線ではなく、ぼやけた灰色として描かれることがあります。

入れる前の確認

新しい単色アイコンを置く前に、この3点を見ます。

  • 16pxで見る：画面上で16×16ピクセルになるまで縮小します。まだ形がわかりますか。
  • 白と黒の両方：純白と純黒の背景に置きます。タブ用SVGのメディアクエリが、意図した1色に切り替わっているかを確認します。
  • PNGの予備：SVGのスタイルを読まない環境用に、静止した32×32のPNGも残します。検索結果用のICOまたはPNGも別です。

単色アイコンのよくある質問

単色アイコンとは何ですか？

形を1色のシルエットで表すアイコンです。タブ用の単色SVG、Safariのmask-icon、マニフェストの purpose "monochrome" は、見た目が似ていても色の決め方が違います。

Safariのmask-iconは今も必要ですか？

新しいSafariでは必須ではありません。mask-iconはピン留めタブ用の古い仕組みで、Appleの案内はアーカイブにあります。通常のファビコンがあれば、現行のタブ表示には足ります。

単色アイコンはどうやって作りますか？

背景を透明にし、単純な形を1色で描きます。タブ用SVGは fill を1色にします。mask-iconの図形は100%黒のSVGです。マニフェストでは黒く不透明な形と透明な背景にし、purpose を "monochrome" と書きます。細い線は16pxで潰れやすいので避けます。
