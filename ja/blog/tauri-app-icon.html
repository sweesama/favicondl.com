Tauri アプリアイコン：Windows・macOS・Linux の設定方法

Tauriアプリを構築したものの、タスクバーにはまだデフォルトのアイコンが表示されている。あるいは、リリース間近になってドックのアイコンが汎用のプレースホルダーだと気づいたかもしれません。適切なTauriアプリのアイコンを設定するのは、ファイルの配置場所と設定での参照方法さえ分かれば簡単です。このガイドでは、Tauri内蔵のアイコジェネレーターとtauri.conf.jsonの設定を使い、Windows、macOS、Linux向けの正確な手順を説明します。

前提条件

始める前に、以下を確認してください：

  • Tauriプロジェクト（v1またはv2）がすでにセットアップされていること。
  • Node.jsとnpmがインストールされていること（またはお好みのパッケージマネージャー）。
  • 正方形のソース画像。理想的には透明度付きの1024×1024 PNGです。SVGも動作しますが、ジェネレーターにはPNGの方が安全です。

高品質なソースアイコンが必要な場合は、既存のロゴやfaviconからMzu favicondlを使って作成できます。複数のサイズでクリーンなPNGをエクスポートします。

ステップ1：アイコンセットを生成する

Tauriは、単一のソース画像からプラットフォーム固有の形式をすべて生成するCLIコマンドを提供しています。Windows用の.ico、macOS用の.icns、そしてLinuxやモバイル用のさまざまなPNGです。プロジェクトのルートから以下を実行します：

npm run tauri icon path/to/your-icon.png

Tauri v1を使用している場合もコマンドはnpm run tauri iconですが、package.jsonのスクリプトを確認してください。ジェネレーターはデフォルトでsrc-tauri/icons/にファイルを書き込みます。32x32.png、128x128.png、icon.icns、icon.icoなどのファイルが生成されます。

ヒント：ソース画像は透明な背景と明確なシルエットを持つようにしてください。テキストや細かいディテールは避けましょう。16×16や32×32では維持されません。デザインのガイダンスについては、faviconデザインのヒントをご覧ください（同じ原則がアプリアイコンにも当てはまります）。

ステップ2：tauri.conf.jsonを設定する

src-tauri/tauri.conf.jsonを開き、bundleセクションを見つけます。iconの下に、生成されたアイコンへのパスをリストします。Tauri v2はv1とは少し異なる構造を使用しますが、概念は同じです。

Tauri v2の場合：

{
  "bundle": {
    "icon": [
      "icons/32x32.png",
      "icons/128x128.png",
      "icons/128x128@2x.png",
      "icons/icon.icns",
      "icons/icon.ico"
    ]
  }
}

Tauri v1の場合、icon配列はtauri.bundleの下に配置します：

{
  "tauri": {
    "bundle": {
      "icon": [
        "icons/32x32.png",
        "icons/128x128.png",
        "icons/icon.icns",
        "icons/icon.ico"
      ]
    }
  }
}

パスはsrc-tauri/からの相対パスであることを確認してください。アイコンを別の場所に移動した場合は、パスを適切に更新してください。

ステップ3：プラットフォーム固有の動作を確認する

各OSはリスト内の異なるファイルを使用します。重要なポイントは以下の通りです：

  • Windows：実行ファイル、タスクバー、スタートメニューにはicon.icoを使用します。ICOには複数のサイズ（16、32、48、256）を含める必要があります。Tauriのジェネレーターがこれを処理します。
  • macOS：DockとFinderにはicon.icnsを使用します。ICNS形式には最大1024×1024までの複数の解像度が含まれます。
  • Linux：アプリランチャーとウィンドウマネージャーにはPNG（通常32x32、128x128、128x128@2x）を使用します。一部のデスクトップ環境では、バンドルからicon.pngも読み取ります。

モバイル（iOS/Android）向けにビルドする場合、ジェネレーターは適切なアセットも作成しますが、それらはこのガイドの範囲外です。

ステップ4：再ビルドとテスト

設定を更新した後、アプリを再ビルドします：

npm run tauri build

その後、ビルドされた実行ファイルをインストールまたは実行します。タスクバー（Windows）、Dock（macOS）、またはアプリケーションメニュー（Linux）でアイコンが表示されることを確認してください。Windowsでは、古いアイコンが残る場合、アイコンキャッシュをクリアする必要があるかもしれません — これは既知の癖です。macOSでは、Dockがアイコンをキャッシュすることがあり、ログアウトして再ログインすると解決します。

よくある落とし穴

  • 設定のパスが間違っている：アイコンファイルが存在しない場合、Tauriはバンドルに失敗します。相対パスを再確認してください。
  • ICOのサイズが不足している：手動でICOを作成する場合は、16、32、48、256ピクセルのレイヤーが含まれていることを確認してください。Tauriのジェネレーターはこれを正しく行います。
  • 透明背景の問題：Windowsでは、完全に透明な領域が状況によって黒く表示されることがあります。アーティファクトが見られる場合は、不透明な背景を使用してください。
  • 再ビルドを忘れる：アイコンを変更するには完全な再ビルドが必要です。ホットリロードではネイティブアイコンは更新されません。
  • macOSのICNS形式：ICNSの代わりにPNGを提供すると、macOSがそれを無視する可能性があります。必ず生成されたicon.icnsを使用してください。

結論

Tauriアプリのアイコン設定は3ステップのプロセスです。tauri iconでアイコンセットを生成し、tauri.conf.jsonでファイルを参照し、再ビルドします。組み込みのジェネレーターを使えば、ICOやICNSファイルを手動で作成する手間が省けます。ソース画像はシンプルで正方形に保ち、各ターゲットプラットフォームでアイコンを確認してください。アイコン形式とベストプラクティスの詳細については、faviconのベストプラクティスをご覧ください。多くの原則がアプリアイコンにも当てはまります。
