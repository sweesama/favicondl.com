Bloggerのfaviconを5ステップで設定するガイド

ロゴをアップロードしてもBlogspotのタブに標準のBloggerアイコンが表示され続ける場合、通常はアップロードと公開ページへの反映との間にずれがあります。このガイドでは、blogger faviconを設定する、ブラウザが実際に取得するファイルを確認する、Layoutパネルだけでは対応できない場合にtheme HTMLを使う方法を説明します。

最も quickestな方法はBloggerのLayout画面を使うもので、わずか数クリックで設定できます。SVGを使いたい、icon URLそのものを指定したい、theme内の既存の宣言と競合する箇所を置き換えたい場合は、HTMLで編集する方法を使ってください。

前提条件：始めるために必要なもの

Bloggerブログへの管理者権限、正方形の画像、公開ページを調べる手段が必要です。HTMLで編集する方法を使う場合は、各アイコンファイルについて、公開アクセス可能なHTTPS URLを用意してください。

  • 管理者権限：Bloggerダッシュボードにサインインして、管理対象のブログを開きます。LayoutまたはThemesのコントロールにアクセスするにはeditor権限が必要です。
  • 正方形のPNG：512 × 512の元画像（master）を用意すると、小さなサイズのファイルも書き出せます。ただし、16 × 16で表示したマークも確認してください。プラットフォーム別サイズガイドでは、各配信先で重要なサイズを説明しています。
  • シンプルなマーク：明快なシルエットと最小限のディテール favoringしたマークが有効です。wordmark全体を縮小した miniatureは、タブが密集した画面では読み取りやすさが保たれないことがほとんどです。
  • 公開アセットURL：theme HTMLを使う場合、SVG、PNG、ICOの各ファイルを、HTTPS経由で直接返すserviceにホストしてください。

Blogger faviconを5ステップで追加する

  1. Bloggerの「Layout」画面を開きます。 サインインして対象のブログを選択し、ダッシュボードのナビゲーションで「Layout」を選択して、「Favicon」セクションまでスクロールします。その横の「Edit」をクリックします。セクションが表示されない場合は、後述のテーマHTML方式を使用してください。
  2. アイコンをアップロードして保存します。 ファイル選択画面でPNGを選び、プレビューを確認してから保存してください。タブ内に小さく表示されたときに重要な辺が欠けないよう、アートワークは正方形にしてください。
  3. 公開中のブログを開きます。 保存後、公開中のホームページを新しいタブで開きます。確認には管理者のプレビューではなく公開ドメインを使ってください。管理者のプレビューは、訪問者が受け取る内容を表しません。
  4. iconのリクエストを確認します。 ブラウザーのdeveloper toolsを開き、「Network」を選択してページを再読み込みします。検索条件に「favicon」またはアップロードしたファイル名を入力し、一致するリクエストを開きます。リクエストが成功し、HTMLエラーページではなく画像ファイルが返されていることを確認してください。
  5. iconの宣言を一覧表示します。 「Console」タブを開いて、次のコードを実行します。
document.querySelectorAll(`link[rel~='icon']`).forEach((link) => {
  console.log(link.href, link.type, link.sizes.value);
});

出力には、公開中のページが提示している各icon候補が表示されます。各URLを開いて、アップロードしたアートワークを指していることを確認してください。

テーマHTMLに明示的なiconリンクを追加する

「Layout」パネルが利用できない場合、自前のアセットをホストする場合、またはSVGに加えてraster fallbackも指定したい場合は、この方法を使用します。Bloggerで「Themes」を開き、「Customize」の横にある矢印をクリックして「Edit HTML」を選択し、閉じる&lt;/head&gt;タグの前にリンクを貼り付けます。

操作する前に、現在のテーママークアップのローカルコピーを保存してください。HTML Standardでは、rel='icon'によってiconとの関連付けが定義されています。そのため、各宣言はブラウザーが取得できるリソースを指す必要があります。

&lt;link rel='icon' type='image/svg+xml' href='https://assets.example.com/favicon.svg'&gt;
&lt;link rel='icon' type='image/png' sizes='32x32' href='https://assets.example.com/favicon-32.png'&gt;
&lt;link rel='icon' href='https://assets.example.com/favicon.ico'&gt;

サンプルの URL を、直接アクセス可能で一般公開されている HTTPS アドレスに置き換えます。存在しないファイルを指す行は削除し、異なる artwork を指す古いカスタムアイコン宣言も削除してください。テーマを保存し、公開ドメインを再読み込みしてから、Console のチェックをもう一度実行します。

Blogger favicon のよくある落とし穴

  • Favicon パネルがない場合： image widget を追加するのではなく、テーマエディターで明示的な link タグを使います。asset URL は、HTML ページではなくアイコンファイルを直接返す必要があります。
  • 古いアイコンが残る場合： ファイルを再度変更する前に、公開中のページをプライベートウィンドウでテストします。markup と response が正しい場合は、残りの cache と routing を確認するため、favicon のトラブルシューティングチェックリストを使ってください。
  • 404 または HTML response が返る場合： 正確なパス、文字の大文字・小文字、ホスト設定を確認します。投稿ページを指す favicon link は画像を返しません。
  • 宣言が競合する場合： 古い link によって訪問者が別のファイルを参照する可能性があります。Console snippet を再実行し、意図した1つの icon stack を維持してください。
  • 読みにくい artwork の場合： マークを簡略化し、鮮明で小さな PNG として書き出します。SVG が表示されない場合は、その隣に PNG または ICO の fallback を置いてください。

結果を確認して公開する

信頼できる Blogger favicon には、2つのチェックがあります。公開中の head で意図したアイコンが明示されていること、その URL が実際の画像を返すことです。両方を確認できれば、アップロードは訪問者が受け取るページに正しく接続されています。

新しい artwork には、Mzu favicondl を使うと、用意された正方形のロゴを PNG、ICO、SVG の各形式に変換できます。最も読みやすいシンプルなマークを選び、一度アップロードして、テーマの宣言を実際に配信しているファイルに合わせてください。
