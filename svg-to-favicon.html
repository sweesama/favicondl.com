SVG to Favicon Generator

Upload an SVG. Your browser draws it and downloads real favicon files. Nothing is sent to a server, and you do not need an account.

The preview below is a PNG, not the SVG markup. A wide or tall graphic stays in proportion, with transparent bars filling the square.

Files this generator writes

  • favicon.ico with three PNG images: 16×16, 32×32 and 48×48.
  • favicon-16x16.png, favicon-32x32.png and favicon-48x48.png.
  • apple-touch-icon.png at 180×180.
  • android-chrome-192x192.png and android-chrome-512x512.png.
  • site.webmanifest and favicon-links.html inside favicon-package.zip.

Those are the only outputs. There is no JPG, no 64/128/256 ICO layer, and no favicon.svg. Where each size is used is the favicon size guide. The pixel table is the favicon dimensions chart.

What the SVG may contain

Paths, shapes, groups, local gradients, local clip paths, and <use href="#id"> are rasterized. The root canvas is capped at 512px on the long side before it is fitted into each favicon square. A missing viewBox uses the numeric width and height, or a 512×512 square when neither is set.

The file is rejected, with an error on this page, when it is not SVG, is over 1 MB, has more than 5000 elements or 40 <use> references, declares a root width or height above 8192, uses a non-UTF-8 encoding, or contains any of the following:

  • A DOCTYPE, or a named entity other than amp, lt, gt, quot and apos. Numeric character references are allowed unless they decode into one of the items below.
  • A script, event handler, foreignObject, frame, or embedded <image>.
  • SMIL animation (animate, set), which could change a link after the check.
  • An external href / xlink:href, a stylesheet processing instruction, @import, or a CSS url() that is not a local fragment such as url(#gradient).
  • javascript: or data: URLs.

Text is drawn with a fallback font already on the system. Embedded fonts and external images are not supported. Filters that reference an id in the same file are drawn. The uploaded markup is never inserted into this page.

Frequently asked questions

What does the SVG to favicon generator download?

A ZIP named favicon-package.zip, plus individual downloads. favicon.ico contains PNG layers at 16×16, 32×32 and 48×48. Separate PNGs are favicon-16x16.png, favicon-32x32.png, favicon-48x48.png, apple-touch-icon.png at 180×180, android-chrome-192x192.png and android-chrome-512x512.png. The ZIP also includes site.webmanifest and favicon-links.html. It does not include a favicon.svg file, a JPG, or ICO sizes above 48.

Is my SVG uploaded?

No. The file is read in your browser, checked, drawn to a canvas, and turned into PNG and ICO bytes on that device. There is no account and no server conversion. Close the tab and the file is gone.

Why was my SVG rejected?

The generator rejects files that are not SVG, files over 1 MB, more than 5000 elements, root width or height above 8192, a non-UTF-8 encoding, a DOCTYPE or custom entity, scripts, event handlers, foreignObject, animation elements, embedded images, and any external link, stylesheet, or CSS url() that is not a local fragment such as url(#gradient).

How are transparent backgrounds and wide icons handled?

The graphic is fitted inside each square from its viewBox, or from its width and height when there is no viewBox. Empty space stays transparent. A wide mark gets transparent bars above and below. A tall mark gets transparent bars on the sides. The preview is the PNG that will be downloaded, shown on a checkerboard.

Does this create an SVG favicon file?

No. This page rasterizes the icon. The download is ICO and PNG only, because an uploaded SVG can contain active content and is not republished. Local gradients and filters that point at an id in the same file are drawn. Text uses a browser fallback font. Embedded fonts, external images, and SMIL animation are not supported.
