Quick start

The favicondl favicon API turns any domain or URL into its favicon with a single GET request. There is no API key, no account and no SDK. Use it straight in an <img> tag:

<img src="https://favicondl.com/api/extract?url=github.com" width="32" height="32" alt="GitHub favicon">

Or ask for JSON to see which file was found and where it came from:

curl "https://favicondl.com/api/extract?url=github.com&format=json"
{
  "ok": true,
  "domain": "github.com",
  "size": 128,
  "iconUrl": "https://github.com/favicon.svg",
  "proxyUrl": "https://icy-glade-6d04favicon.sweeyeah.workers.dev/api/proxy?url=https%3A%2F%2Fgithub.com%2Ffavicon.svg",
  "source": "direct"
}

iconUrl is the original file on the website. proxyUrl serves the same image through our proxy with Access-Control-Allow-Origin: *, so you can draw it on a canvas or fetch it from browser code.

How the API picks an icon

  1. Well-known paths such as /favicon.svg, /apple-touch-icon.png, /android-chrome-512x512.png and /favicon.ico are checked first (source: "direct").
  2. The page HTML is read for every <link rel="…icon…"> tag, and linked web app manifests are opened for their icon lists (source: "html").
  3. Google's favicon service is used as a last resort, at the size you request (source: "google_s2").

Within each step, candidates are ranked so the sharpest file wins: SVG first, then Apple touch and Android icons, then larger pixel sizes (512, 256, 192, 180 …), with ICO files last. Icons found on the website are returned at their original size; the size parameter only affects the Google fallback.

If you get google_s2, the site either has no icon at the usual locations or blocked our automated request. For a single site, the favicon downloader on our homepage also tries a few extra sources directly from your browser.

Overview

Mzu favicondl provides copy-ready favicon URL templates and a favicon extractor UI. By default, it uses a Cloudflare Worker to discover real icons and proxy images for downloads.

Endpoints

GET FaviconDL Extract API

Find and download a usable favicon for a domain or URL

Base URL:

https://favicondl.com/api/extract

Full Example:

https://favicondl.com/api/extract?url=example.com&size=128

Parameters

Parameter Name Type Required Default Value Description
url string Yes - The target domain or URL, e.g. example.com
size number No 128 Fallback size in pixels (16–512). Only used when we fall back to Google's favicon service; icons found on the site itself are returned at their original size.
format string No redirect Use json for metadata; omit it for a downloadable image redirect

Parameter Details:

url

Supports domains and full website URLs:

  • • example.com
  • • www.example.com
  • • https://example.com/docs
  • • sub.example.com
size

Fallback size for the Google favicon service, from 16 to 512 pixels:

  • • 16 - 16x16
  • • 32 - 32x32
  • • 128 - 128x128
  • • 512 - 512x512

Responses

Successful Response (JSON format)

JSON Response 
{
  "ok": true,

  "size": 128,
  "iconUrl": "https://example.com/favicon.svg",

}

Error Response

Error Response 
{
  "ok": false,
  "error": "Missing url"
}

Note: When using format=redirect, the API will directly redirect to the favicon URL without returning a JSON response.

Examples

JavaScript (Fetch)

JavaScript 
async function getFavicon(url, size = 128) {
  const endpoint = new URL('https://favicondl.com/api/extract');
  endpoint.searchParams.set('url', url);
  endpoint.searchParams.set('size', String(size));
  const response = await fetch(endpoint);
  if (!response.ok) throw new Error(`Favicon request failed: ${response.status}`);
  return await response.blob();
}

const icon = await getFavicon('example.com', 128);
const imageUrl = URL.createObjectURL(icon);
document.querySelector('#favicon-preview').src = imageUrl;

Python (Requests)

Python 
import requests

def get_favicon(url: str, size: int = 128) -> bytes:
    response = requests.get(
        "https://favicondl.com/api/extract",
        params={"url": url, "size": size},
        timeout=15,
    )
    response.raise_for_status()
    return response.content

icon_bytes = get_favicon("example.com", 128)
with open("example-favicon", "wb") as output:
    output.write(icon_bytes)

PHP (cURL)

PHP 
<?php
function getFavicon(string $url, int $size = 128): string {
    $endpoint = 'https://favicondl.com/api/extract?url=' . urlencode($url) . '&size=' . $size;
    $context = stream_context_create(['http' => ['follow_location' => 1, 'timeout' => 15]]);
    $icon = file_get_contents($endpoint, false, $context);
    if ($icon === false) {
        throw new RuntimeException('Favicon request failed');
    }
    return $icon;
}

file_put_contents('example-favicon', getFavicon('example.com', 128));
?>

Errors

Errors return an HTTP status code and a small JSON body with ok set to false and an error message.

HTTP Status Code Error message Description Solution
400 Missing url No url or domain parameter was sent Add ?url=example.com to the request
400 Invalid format format is neither json nor redirect Use format=json, or omit it for a redirect
400 Invalid domain The value could not be read as a hostname Send a domain such as example.com or a full https:// URL
405 Method not allowed Only GET requests are supported Send a GET request
502 Favicon extraction failed The extractor could not return an icon Retry later
504 Favicon extraction timed out The lookup took longer than about 9 seconds Retry; slow sites often succeed on a second attempt

Rate Limits

Free

No registration required, completely free to use all features

Fair use

  • • There is no API key and no fixed published quota
  • • Successful responses are cached at the edge for 5 minutes
  • • Please cache icons on your side and avoid bulk crawling

Commercial Use

There is no paid tier or SLA. For high-volume or business-critical use, store the icons you need in your own storage.
