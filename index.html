The Simplest Favicon Downloader & Extractor

Mzu favicondl is a free online favicon downloader that lets you extract and download any website's favicon instantly. Simply enter a domain name or URL, choose your preferred icon size, and get the favicon — no sign-up, no installation, no limits.

Whether you're a web developer building a link preview, a designer collecting brand assets, or just curious about a site's icon, our favicon extractor handles it all. We support sizes from 16×16 to 512×512 pixels, and every download comes with copy-ready HTML snippets and direct URLs for easy integration into your project. Favicons (short for "favorite icons") are the small icons displayed in browser tabs, bookmarks, and search results. They play a key role in brand recognition and user experience.

Learn more about the favicon standard from the MDN Web Docs.

What is a High-Quality Favicon?

A high-quality favicon goes beyond the legacy 16x16 ICO format. Modern applications, social media link previews, and AI agents require high-resolution assets such as 180px, 256px, and 512px icons, often derived from SVG vectors, web app manifests, and Apple touch icons. Mzu favicondl prioritizes these richer sources over deprecated standard favicons whenever possible.

JavaScript (Fetch) 
async function getFavicon(domain, size = 128) {
  const url = `https://favicondl.com/api/favicon?domain=${domain}&size=${size}`;
  const response = await fetch(url);
  const blob = await response.blob();
  return URL.createObjectURL(blob);
}

    f.write(response.content)

What the favicon extractor looks for

Websites rarely publish just one icon. A typical site has a classic favicon.ico, a few PNGs, an Apple touch icon for iPhones and a web app manifest for Android. Our favicon extractor checks the well-known file paths (such as /favicon.ico, /favicon.svg, /apple-touch-icon.png and /android-chrome-512x512.png), reads every <link rel="…icon…"> tag in the page HTML, and opens any linked manifest to collect the icons listed inside it.

How to get the highest-resolution icon

The extractor ranks every icon it finds and returns the sharpest one first. SVG files win because they scale without losing detail. After that come Apple touch icons and Android/manifest icons, ordered by size (512, 256, 192, 180 px and down). The classic ICO file is used last, because it is usually only 16 or 32 pixels wide.

  • Keep the original size. Leave Export at selected size switched off, and the PNG you download keeps the full resolution of the source file.
  • Do not upscale tiny icons. Enlarging a 16 px ICO to 128 px only makes it blurrier. If a site publishes nothing bigger, that small file is genuinely the best version available.
  • Check where the icon came from. In the API's JSON response, source tells you whether the icon came from the site itself (direct or html) or from the Google fallback (google_s2), which is usually lower resolution.
  • Need a logo, not an icon? A favicon is designed to be tiny. For print or marketing work, use the company's official press kit or brand page instead.

Frequently asked questions

Is it legal to download a website's favicon?

A favicon is a public file that every browser downloads when it opens the site, so saving it is technically no different. The icon is usually part of the owner's logo or trademark, though. Using it to show which site a link points to (in bookmarks, dashboards or link previews) is common practice; using it as your own branding is not. When in doubt, check the company's brand guidelines. This is general information, not legal advice.

Why does my downloaded favicon look blurry?

Usually the site only publishes a small icon, or the image was enlarged on export. Turn off Export at selected size to keep the original resolution. If only a 16 px or 32 px ICO exists, no tool can add the missing detail.

Can I download favicons in bulk?

Yes. The batch tool on the Tools page accepts up to 100 domains at once and lets you download the results as one ZIP file or as separate images.

Is there a free favicon API?

Yes. https://favicondl.com/api/extract?url=github.com redirects straight to the best icon we found, so you can use it in an <img> tag. Add &format=json to get the icon URL and where it came from instead. No key or account is needed; please cache results on your side. Details are in the API documentation.

What is the difference between a favicon grabber, fetcher and extractor?

Nothing important. "Favicon grabber", "favicon fetcher", "favicon finder" and "favicon extractor" are different names for the same kind of tool: you give it a website and it finds and downloads the site's icon. This favicon downloader does all of them.

Why do some websites return a generic globe or no favicon?

Some sites block automated requests, sit behind a login or bot check, add their icon with JavaScript after the page loads, or simply have no favicon. In those cases we fall back to Google's favicon service, which may return a small image or a default globe icon.

Which file format will I get?

The Download button always saves a PNG, which works everywhere. The direct URL in the result points to the original file on the website, which may be ICO, PNG, SVG or WebP, if you need that exact format.

Does it work with localhost or private sites?

No. The extractor runs on our servers, so it can only reach public websites. It cannot see localhost, your private network or pages behind a login, and our image proxy refuses private addresses.

Can I turn my own image into a favicon?

Yes. The Image to Favicon tool on the Tools page converts a logo into multiple PNG sizes and an ICO file, and packs them into a ZIP together with a web manifest and the HTML tags to paste into your site. The image is processed in your browser and is not uploaded.

Which favicon sizes does my own site need?

For most sites, an SVG or 32×32 PNG for browsers, a 180×180 Apple touch icon and 192×192 plus 512×512 manifest icons cover everything. Our favicon sizes guide explains each one.
