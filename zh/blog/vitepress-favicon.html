VitePress Favicon 设置：分步指南

如果你部署过 VitePress 站点，发现浏览器标签页上还是默认的 VitePress 图标，那你不是一个人。很多开发者以为把 favicon.ico 丢进 public 文件夹就完事了，但 VitePress 需要额外配置才能正确链接你的图标。这篇指南会一步步带你为 VitePress 站点设置自定义 favicon，从文件放置到验证结果都涵盖。

准备工作

开始之前，请确保你有：

  • 一个已经搭建好的 VitePress 项目（1.x 或更高版本）。
  • 一个准备好的 favicon 文件。可以用 ICO、PNG 或 SVG。如果需要生成，可以试试 Mzu favicondl 来制作多尺寸 favicon。
  • 对 VitePress 项目中的 config.js 或 config.ts 文件有基本了解。

第一步：把 favicon 文件放到 public 目录

VitePress 底层用的是 Vite，所以静态资源应该放在项目根目录的 public 文件夹里。public 中的文件会以根路径提供服务，并在构建时原样复制到输出目录。比如，你把 favicon.ico 放在 public 里，构建后就能通过 /favicon.ico 访问到。

如果 public 文件夹不存在就创建一个，然后把 favicon 文件放进去。你也可以用 PNG 或 SVG 文件，只要记住文件名就行。

your-project/
├── docs/
│   └── .vitepress/
│       └── config.js
├── public/
│   └── favicon.ico
└── package.json

注意：public 目录是相对于 VitePress 项目根目录（也就是 package.json 所在位置）的。如果你用的是默认的 docs 文件夹结构，public 文件夹应该放在项目根目录，而不是 docs 里面。

第二步：在 VitePress 配置中设置 favicon

VitePress 允许你通过配置文件中的 head 选项来定义站点的 <head> 标签。这里就是添加 <link rel="icon"> 标签的地方。

打开你的 .vitepress/config.js（或 .ts），添加以下内容：

import { defineConfig } from 'vitepress'

export default defineConfig({
  head: [
    ['link', { rel: 'icon', href: '/favicon.ico' }]
  ],
  // other config...
})

如果使用 SVG 格式的 favicon，可以指定 type：

head: [
  ['link', { rel: 'icon', type: 'image/svg+xml', href: '/favicon.svg' }]
]

这样 VitePress 就会把 link 标签注入到每个页面的 <head> 中。注意 href 要以斜杠（/）开头，因为文件是从根目录提供的。

第 3 步：验证 favicon 是否生效

配置完成后，运行开发服务器（npm run docs:dev 或 yarn docs:dev），在浏览器中打开站点。查看标签页——favicon 应该显示出来了。如果没有，试试强制刷新（Ctrl+F5 或 Cmd+Shift+R）来绕过缓存。

对于生产环境，先构建站点（npm run docs:build），然后检查 .vitepress/dist 中生成的 HTML。在 <head> 部分查找你的 <link rel="icon"> 标签。

常见坑

  • 文件路径错误：如果把 favicon 放在 docs/public 而不是项目根目录的 public，它不会被复制。一定要用根目录下的 public 目录。
  • 缺少前导斜杠：使用 href: 'favicon.ico'（没有斜杠）在嵌套路由下可能出问题。始终用 /favicon.ico。
  • 浏览器缓存：浏览器会激进地缓存 favicon。更新后，清除缓存或换个文件名（比如 favicon-v2.ico）来强制刷新。更多缓存问题，参见我们的 favicon 不显示排查清单。
  • SVG 支持：虽然 SVG favicon 已被广泛支持，但一些旧版浏览器可能无法显示。考虑提供 PNG 或 ICO 作为回退。了解更多请参阅我们的 SVG favicon 指南。

总结

在 VitePress 中设置 favicon 其实很简单，只要知道文件该放在哪里、head 标签该怎么配置就行。按下面的步骤操作，你的网站就能在浏览器标签页、书签和搜索结果中显得更专业。记得在不同浏览器里测试，修改后也要清理缓存。如果需要完整的 favicon 方案，可以考虑用 Mzu favicondl 来生成所有需要的尺寸和格式。
