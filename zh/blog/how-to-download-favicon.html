如何从任何网站下载 Favicon

需要获取网站的 Favicon 用于项目、演示或竞品分析？以下是 3 种可靠的方法，从简单到强大排列。

方法一：浏览器地址栏技巧

最简单的方法 — 直接在浏览器中输入以下 URL：

https://www.google.com/s2/favicons?domain=example.com&sz=64

这使用 Google 的公开 Favicon 服务来获取图标。你可以修改 sz 参数来获取不同尺寸（16、32、64、128、256）。

优点：无需工具，任何浏览器都能用。
缺点：尺寸有限，有时返回低质量或默认图标。不支持批量下载。

方法二：查看网站 HTML 源码

每个网站都在 HTML 的 <head> 中声明了 Favicon。查找方法：

  1. 在浏览器中打开目标网站。
  2. 右键点击选择"查看页面源代码"（或按 Ctrl+U）。
  3. 搜索 rel="icon" 或 rel="shortcut icon"。
  4. 复制 href 的值 — 这就是 Favicon 的 URL。
  5. 在新标签页中打开该 URL，然后保存图片。

你可能会找到多个指向不同尺寸和格式的 Favicon 声明。常见模式：

<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">

优点：获取的是网站实际使用的图标。
缺点：手动操作，耗时。有些网站使用复杂的路径或 CDN 链接，难以找到。

方法四（额外）：使用命令行

对于喜欢终端的开发者，可以使用 curl：

# 通过 Google 的 Favicon API 下载
curl -o favicon.png "https://www.google.com/s2/favicons?domain=github.com&sz=128"

# 或直接从网站下载
curl -o favicon.ico "https://github.com/favicon.ico"

常见问题

下载 Favicon 合法吗？

Favicon 是网站公开提供的，本身就是给浏览器展示的。为了个人使用、研究或参考而下载通常没有问题。但是，将别人的 Favicon 作为自己的品牌图标可能会涉及商标问题。

为什么下载的 Favicon 模糊？

很多网站只提供 16×16 或 32×32 像素的 Favicon。试试找 Apple Touch Icon（180×180）或 Android Chrome 图标（192×192 或 512×512）来获得更高质量。Mzu favicondl 会自动获取多种尺寸，让你选择最佳的。
