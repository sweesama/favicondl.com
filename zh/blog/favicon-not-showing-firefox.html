Firefox 中 favicon 不显示？几分钟内修复

你已经给网站加了 favicon，但 Firefox 的标签页里仍然显示一个空白页面图标。这问题很常见，原因通常是以下三种之一：缓存机制、严格的解析规则，或路径写错。先把图标找回来。

快速修复：强制 Firefox 重新获取 favicon

在动手改代码之前，先试试最快的办法。Firefox 会 aggressively 地缓存 favicon，有时甚至持续数天。可以专门清除 favicon 缓存：

  1. 打开一个新标签页，访问 about:cache。
  2. 在“Disk cache”（磁盘缓存）下，点击“List Cache Entries”（列出缓存条目）。
  3. 搜索“favicon”，删除与你的站点有关的条目。
  4. 重启 Firefox，然后重新加载页面。

如果这样仍然无效，可以在 HTML 中给 favicon URL 追加 query string，例如 favicon.ico?v=2，彻底绕过缓存。这样会让 Firefox 将它视为一个新资源。

为什么偏偏是 Firefox 无法显示 favicon

相比某些浏览器，Firefox 的规则更严格。以下是最常见的原因：

  • SVG 解析错误：Firefox 要求 SVG 是有效的 XML。如果缺少 namespace，或者某个标签没有闭合，Firefox 就会直接忽略这个 SVG favicon。
  • MIME type 不正确：如果服务器为 PNG 文件返回 image/x-icon，Firefox 可能拒绝加载。请确保 type 属性与文件的实际格式一致。
  • 相对路径问题：./favicon.ico 这样的路径在嵌套路由中可能失效。请改用绝对路径或根相对路径（/favicon.ico）。
  • 缺少 link tag：只有页面中完全没有 link tag 时，Firefox 才会回退到 /favicon.ico。如果 link tag 指向的文件不存在，Firefox 就不会继续回退。

想进一步了解 Firefox 的具体行为，可以查看我们的 Firefox favicon 指南。

检查 HTML 和服务器响应

先确认 HTML head 中的 link tag，正确的写法应该如下：

<link rel='icon' type='image/svg+xml' href='/favicon.svg'>
<link rel='icon' type='image/png' href='/favicon-32x32.png'>

根据 HTML 规范，rel='icon' 属性是定义 favicon 的标准方式。Firefox 支持这一属性，但也会检查文件的完整性。

接下来，打开 Firefox 的 Developer Tools（F12），切换到 Network 面板并重新加载页面。查找 favicon 请求。如果返回 404，说明路径有误；如果返回 200 但图标仍未显示，文件可能已损坏，或者格式不受支持。

预防建议

为避免以后再遇到这个问题，可以将多尺寸 ICO 文件作为备用资源提供，并始终包含带有正确 XML 头信息的 SVG。使用绝对路径；更新图标时，还可以考虑添加版本查询字符串。关于完整检查清单，请参阅我们的 favicon 不显示指南。

结论

Firefox 的 favicon 问题通常与缓存有关，或者源于严格的解析规则。清除缓存、验证 SVG，并再次检查路径。按照这些步骤操作，图标应该很快就会显示出来。
