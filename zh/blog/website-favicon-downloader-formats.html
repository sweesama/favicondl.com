网站 Favicon 下载器到底能干嘛

拿 GitHub 来说，他们同时提供了好几种 favicon 格式。打开页面源码，你会看到 <link rel='icon' type='image/svg+xml' href='...'> 给现代浏览器用，<link rel='icon' type='image/png' sizes='32x32' href='...'> 给高分屏，还有一个老掉牙的 /favicon.ico 给旧系统。三个文件干同一件事。

一个好的下载器会扫描所有这些声明，找到网站暴露的所有图标文件，然后让你直接下载原始格式。不用猜，不用手动拼 URL，拿到文件直接用。

为什么格式很重要

不是所有 favicon 都一样。如果你在开发一个现代 web 应用，SVG 是首选——它无限缩放，还能通过 CSS media queries 支持暗黑模式。如果你要兼容 Internet Explorer，或者需要一个文件包含多个尺寸，那 ICO 是唯一的选择。PNG 则介于两者之间：高分屏表现不错，但一个文件不支持多分辨率。

大多数网站会混合提供。比如 GitHub，SVG 是主图标，32x32 的 PNG 是备选，ICO 给老浏览器。一个好的下载器会给你全部三种，而不是只给你浏览器默认请求的那个。

关键功能要这样挑

市面上的 favicon 下载器良莠不齐。下面这些功能，才是一个好工具该有的：

  • 多格式提取：必须能同时找到 ICO、PNG 和 SVG 文件。很多工具只抓 ICO，对现代项目来说根本没用。
  • Manifest 扫描：PWA 的图标声明在 site.webmanifest 里。好的下载器会读取这个文件，把里面的图标也列出来。
  • Apple Touch Icon 支持：iOS 设备用的是 apple-touch-icon 链接。这些图标通常更大（180x180 或 152x152），用途也不同。你的下载器应该能找到它们。
  • 无文件大小限制：有些在线工具会限制下载大小，比如超过 100KB 就不让下。Favicon 文件可能很大，尤其是多分辨率的 ICO。别用那些会截断你下载的工具。

使用 Favicon 下载器的小技巧

用了这么多年这类工具，我总结了一些省时的小窍门：

先看 Manifest

如果一个网站是 PWA（比如 Twitter 或 Spotify），它的图标大多在 site.webmanifest 文件里，而不是 HTML 的 <head> 中。不扫描 manifest 的下载器会漏掉最好的图标。一定要确认你的工具会读这个文件。

别信第一个图标

浏览器默认会请求 /favicon.ico，但这个文件可能只是个低分辨率的占位符。真正的图标可能是 manifest 里声明的 512x512 PNG。把所有格式都下载下来，选最适合你用途的那个。

自己的项目就用 SVG

当你发现一个网站有干净的 SVG favicon（比如 Stripe 或 Vercel），果断下载。SVG 文件小、可缩放、还容易编辑。改颜色、去背景、调大小，都不损失质量。ICO 文件编辑起来是噩梦，SVG 用起来是享受。

什么时候还得用 ICO

说实话，ICO 是个老掉牙的格式。它诞生于 Windows 95 时代。但它有一个超能力：一个文件能存多张图片。一个 favicon.ico 可以同时包含 16x16、32x32 和 48x48 三种尺寸。浏览器会自动选合适的那个。

SVG 做不到这一点。PNG 也做不到（除非用 hack）。所以，如果你需要一个文件通吃所有场景——包括老浏览器、RSS 阅读器和书签管理器——ICO 仍然是最稳妥的选择。一个好的下载器会给你这个选项。

但其他情况呢？用 SVG 吧。都 2026 年了，你的浏览器支持它，用户的设备也支持它。别再给用户看模糊的像素了。
