Inkscape favicon：导出清晰的网站图标

如果你的 Inkscape 作品在画布上看起来没问题，到了浏览器标签页里却变成被裁切的模糊图像，问题通常出在文档本身，而不在导出格式。制作一个 Inkscape favicon，需要方形构图、可移植的路径，以及一小组可直接用于网页的文件。

准备工作

你需要 Inkscape，以及一个现成的 SVG logo。如果作品位于宽幅页面上，请新建一个方形文档，把标志复制过去并等比缩放，再将这个文件保留为可编辑的主文件。相比完整的文字标志（wordmark），辨识度更高的符号在 16×16 像素下效果更好。

例如，如果源文件是 1200×400 的 wordmark，不要把这个矩形硬塞进 favicon。只选中符号本身，将它粘贴到方形文档中，再按比例缩放。这样就会得到一个紧凑的主文件，可以反复导出，而不必改动原始作品。

  • 以 128×128 像素画板作为实用的设计尺寸。
  • 让标志保持居中，四周留出一点透明空间。
  • 删除在小尺寸下无法保持清晰可辨的细节。

1. 设置方形画布和 viewBox

打开 File → Document Properties，将单位设为 pixels，并把文档的宽度和高度设为相同。128×128 是推荐尺寸，并非浏览器的硬性要求；64×64 也可以。对于 128×128 的文档，确认 viewBox 显示为 0 0 128 128。

使用 Object → Align and Distribute，选择 Page 作为参考，将作品在水平方向和垂直方向上居中。确认页面预览为正方形，并且各边都没有被裁切。

2. 将文字和易失效的效果转换为路径

选中每个文字对象，然后选择 Path → Object to Path。这样可以避免服务器缺少你所使用的字体时，用另一种形状替换文字。

对于关键的虚线或轮廓描边，使用 Path → Stroke to Path。渐变、蒙版和滤镜只在必要时保留，因为 SVG 在不同环境中加载时，它们会增加可能出错的环节。

3. 保存可移植的 SVG

选择 File → Save As，选中 Plain SVG，将副本保存为 favicon.svg。

在转换 SVG 之前，先检查文档属性中的 viewBox 是否为正方形，并确认图形不依赖外部字体、外链位图或样式表。如果标志中包含外链图像，请将图像文件放在 SVG 旁边并明确重新建立链接，或者将其替换为等效的矢量图。

4. 导出 512×512 PNG 回退文件

使用 File → Export PNG Image，将 Page 设为导出区域，并把宽、高都设为 512 像素。背景保持透明，然后导出 favicon-512.png。

这张高分辨率 PNG 提供了足够的像素，转换器可以直接生成小尺寸位图，而不必让浏览器去放大小尺寸源图。

需要重复导出时，也可以运行：

inkscape favicon.svg --export-type=png --export-area-page --export-width=512 --export-height=512 --export-filename=favicon-512.png

该命令以正方形页面边界为导出范围，并在当前工作目录中写入一张 512×512 PNG。

5. 打包 Inkscape favicon

打开 Mzu favicondl，上传 favicon.svg 或 favicon-512.png，生成包含多种尺寸的 ICO，然后下载。我们建议 ICO 内含 16×16、32×32 和 48×48 三种图像。同时再生成一张 180×180 的 PNG，命名为 apple-touch-icon.png。

如果需要了解具体的打包流程，请参阅 SVG 转 ICO 指南；favicon 尺寸指南还介绍了其他 PNG 尺寸和 Apple 相关的尺寸。

HTML Standard 将 rel='icon' 定义为一种链接：它指向外部资源，该资源在用户界面中代表当前页面。这一定义并未要求必须采用某一种文件格式，因此，为兼顾兼容性，我们建议使用 SVG，并提供 ICO 作为回退方案。

6. 部署文件和 HTML

将 favicon.ico、favicon.svg 和 apple-touch-icon.png 放在站点能够正常提供这些文件的路径下。在 <head> 中添加以下链接：

<link rel='icon' href='/favicon.ico'>
<link rel='icon' href='/favicon.svg' type='image/svg+xml'>
<link rel='apple-touch-icon' href='/apple-touch-icon.png' sizes='180x180'>

只有在路径与部署根目录一致时，才使用根相对路径（root-relative path）。如果应用部署在子路径下，请修改这些路径，或将其改为相对路径。保留 ICO 作为 fallback，并以 SVG 作为 scalable master。

7. 验证线上响应

打开网站并强制刷新，在 Network 面板中逐一检查每个 icon URL。确认请求返回 200，且响应是图片，而不是网站的 HTML 404 页面。

直接打开 /favicon.svg，确认 SVG 能正常渲染。如果仍然显示旧图标，先确认浏览器已经获取了新的 URL，再考虑调整部署。

也可以在 terminal 中检查 ICO 响应：

curl -I https://example.com/favicon.ico

将 URL 替换为你自己的域名，然后对 SVG 和 PNG 文件重复上述检查。

常见问题

  • 图形被裁切。 从正方形页面导出，不要沿用原始的宽幅画布。
  • 文字形状发生变化。 保存最终 SVG 前，先将文字转换为 path。
  • 链接资源加载失败。 将外部链接的 bitmap 替换为 vector artwork，或把这些资源打包到位置稳定的相对路径中，并移除对外部 stylesheet 的依赖。
  • 图标看起来是空的。 在 16×16 尺寸下检查，并简化轮廓、间距和对比度。
  • 旧图标仍未更新。 先检查 HTML source 和 Network 面板，不要直接把问题归咎于 cache。
  • 图标看起来被拉伸。 保持 viewBox 为正方形，并导出正方形 PNG；sizes 不会调整 artwork 的尺寸。

建立可重复执行的工作流

现在，你已经有了一套可重复执行的 Inkscape favicon 工作流：一个正方形 vector master（文字已 outlined）、一个 portable SVG、一个 512-pixel PNG、一个 ICO fallback，以及明确的 HTML links。保持 master SVG 不变，后续导出才能保持一致。
