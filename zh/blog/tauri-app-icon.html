Tauri 应用图标：为 Windows、macOS、Linux 设置图标

你已经用 Tauri 构建了一个应用，但任务栏里显示的仍然是默认图标。或者你正准备发布，却发现 Dock 图标是个通用占位符。只要搞清楚文件该放哪儿、配置怎么引用，设置一个像样的 Tauri 应用图标其实并不复杂。本文会带你走完 Windows、macOS 和 Linux 上的具体步骤，用的是 Tauri 自带的图标生成器和 tauri.conf.json 配置。

准备工作

开始之前，请确认你已具备：

  • 一个已经搭建好的 Tauri 项目（v1 或 v2）。
  • 已安装 Node.js 和 npm（或你惯用的包管理器）。
  • 一张正方形的源图，理想情况是带透明通道的 1024×1024 PNG。SVG 也可以用，但对生成器来说 PNG 更稳妥。

如果你需要一张高质量的源图标，可以用 Mzu favicondl 从现有的 logo 或 favicon 生成——它能导出多种尺寸的干净 PNG。

第一步：生成图标集

Tauri 提供了一个 CLI 命令，输入一张源图，就能产出所有平台专用的格式：Windows 用的 .ico、macOS 用的 .icns，以及 Linux 和移动端用的各种 PNG。在项目根目录下运行：

npm run tauri icon path/to/your-icon.png

如果你用的是 Tauri v1，命令同样是 npm run tauri icon，但建议先检查一下 package.json 里的 scripts。生成器默认把文件写入 src-tauri/icons/。你会看到 32x32.png、128x128.png、icon.icns 和 icon.ico 这类文件。

提示：源图应当背景透明、轮廓清晰。避免文字或过于精细的细节——它们在 16×16 或 32×32 下根本看不清。设计方面的建议可以参考我们的 favicon 设计技巧（同样的原则也适用于应用图标）。

第二步：配置 tauri.conf.json

打开 src-tauri/tauri.conf.json，找到 bundle 部分。在 icon 下，列出生成图标的路径。Tauri v2 的结构与 v1 略有不同，但思路是一样的。

对于 Tauri v2：

{
  "bundle": {
    "icon": [
      "icons/32x32.png",
      "icons/128x128.png",
      "icons/128x128@2x.png",
      "icons/icon.icns",
      "icons/icon.ico"
    ]
  }
}

对于 Tauri v1，icon 数组位于 tauri.bundle 下：

{
  "tauri": {
    "bundle": {
      "icon": [
        "icons/32x32.png",
        "icons/128x128.png",
        "icons/icon.icns",
        "icons/icon.ico"
      ]
    }
  }
}

确保路径是相对于 src-tauri/ 的。如果你把图标移到了别处，记得相应更新路径。

第 3 步：验证各平台的具体行为

每个操作系统会使用列表中的不同文件。以下是关键点：

  • Windows： 使用 icon.ico 作为可执行文件、任务栏和开始菜单的图标。ICO 应包含多个尺寸（16、32、48、256）。Tauri 生成器会处理这一点。
  • macOS： 使用 icon.icns 作为 Dock 和 Finder 中的图标。ICNS 格式包含多种分辨率，最高可达 1024×1024。
  • Linux： 使用 PNG 文件（通常是 32x32、128x128、128x128@2x）作为应用启动器和窗口管理器的图标。某些桌面环境还会读取 bundle 中的 icon.png。

如果你要为移动端（iOS/Android）构建，生成器也会创建相应的资源，但这超出了本指南的范围。

第 4 步：重新构建并测试

更新配置后，重新构建你的应用：

npm run tauri build

然后安装或运行构建出的可执行文件。检查任务栏（Windows）、Dock（macOS）或应用程序菜单（Linux）以确认图标出现。在 Windows 上，如果旧图标仍然存在，你可能需要清除图标缓存——这是一个已知的怪癖。对于 macOS，有时 Dock 会缓存图标；注销再重新登录即可解决。

常见陷阱

  • 配置中的路径错误：如果图标文件不存在，Tauri 打包会失败。请仔细检查相对路径。
  • 缺少 ICO 尺寸：如果手动创建 ICO，请确保包含 16、32、48 和 256 像素的图层。Tauri 生成器会正确处理这一点。
  • 透明背景问题：在 Windows 上，完全透明的区域在某些上下文中可能显示为黑色。如果看到异常，请使用纯色背景。
  • 忘记重新构建：更改图标需要完全重新构建；热重载不会更新原生图标。
  • macOS ICNS 格式：如果提供的是 PNG 而不是 ICNS，macOS 可能会忽略它。始终使用生成的 icon.icns。

结论

设置 Tauri 应用图标分为三步：使用 tauri icon 生成图标集，在 tauri.conf.json 中引用这些文件，然后重新构建。内置生成器让你无需手动创建 ICO 和 ICNS 文件。保持源图像简单且为正方形，并在每个目标平台上验证图标。有关图标格式和最佳实践的更多信息，请参阅我们的 favicon 最佳实践——许多原则同样适用于应用图标。
