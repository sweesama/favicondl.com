2026年如何从任意网站提取SVG图标

你一定遇到过这种情况。看到竞品网站上那个 favicon 清晰锐利，16x16 不模糊，支持深色模式，在 Retina 屏上还特别精致。你打开 DevTools，翻遍 <head>，结果只找到一堆 PNG 和 ICO 文件，SVG 的影子都没有。

这就是问题所在。大多数 favicon 提取教程只教你如何拿到 PNG 或 ICO 文件。但在 2026 年，真正的宝藏是 SVG favicon —— 它无限缩放，通过 prefers-color-scheme 支持深色模式，体积还只有位图的零头。下面教你如何真正提取一个。

为什么 SVG Favicon 值得你费心

在开始提取之前，先说说为什么这事值得。GitHub 用 SVG favicon，Stripe 和 Apple 也是。这些公司选 SVG 不是因为时髦 —— 而是因为一个 SVG 文件能替代六个 PNG、一个 ICO 和一个 Web Manifest 条目。

SVG favicon 在深色模式下也不会变成鬼影。你可以在 SVG 里直接嵌入 @media (prefers-color-scheme: dark)，让图标自动变色或反转。PNG 能做到吗？

手动提取流程

第一步：检查页面源码

在 Chrome 或 Firefox 里打开任意网站。右键点击任意位置，选择「检查」（或按 Ctrl+Shift+I）。切换到「Elements」标签，在 <head> 里搜索 rel='icon'。找 SVG 链接：

<link rel='icon' type='image/svg+xml' href='/favicon.svg'>

如果看到这个，你就赚了。直接点击 href 的值在新标签页打开 SVG，然后保存。但注意 —— 很多网站把 SVG favicon 藏在 sizes 属性后面，或者用 Safari 的 rel='mask-icon'。别看到第一个链接就停手。

第二步：检查 Web Manifest

现代 PWA 通常把 SVG favicon 声明在 site.webmanifest 文件里。在 <head> 里搜索 rel='manifest'：

<link rel='manifest' href='/site.webmanifest'>

在新标签页打开那个 JSON 文件。找一个叫 icons 的属性 —— 它是一个对象数组。找到 type 等于 'image/svg+xml' 的条目，那就是你的 SVG favicon URL。复制并下载文件。

第三步：用 Favicon API 兜底

有些网站根本不把 SVG favicon 暴露在 HTML 里，而是依赖浏览器自动请求 /favicon.ico。这时你需要猜路径。常见位置包括：

  • /favicon.svg
  • /assets/favicon.svg
  • /static/favicon.svg

直接在域名后面输入这些路径。如果服务器返回 404，那这个网站大概率没用 SVG favicon —— 或者藏得太深了。

SVG Favicon 提取技巧

注意相对路径

很多网站用相对路径，比如 /assets/favicon.svg。从 DevTools 复制 href 值后，需要加上域名。Mzu favicondl 会自动处理，但如果你手动操作，别忘了基础 URL。

检查深色模式变体

有些网站会根据用户的配色方案提供不同的 SVG favicon。找 <link> 标签上有没有 media='(prefers-color-scheme: dark)' 属性。如果有，你需要同时提取亮色和深色两个版本。

验证 SVG

不是所有 SVG 文件都能当 favicon。有些包含外部引用、JavaScript 或巨大的 viewBox 值。使用提取的 SVG favicon 之前，用文本编辑器打开检查是否自包含。删除所有 <script> 标签 —— 浏览器在 favicon 里本来就会忽略它们，但好习惯总没错。
