如何从任何网站提取Apple Touch图标（2026）

不知道你有没有遇到过这种情况：在 iPhone 上打开某个网站，然后把它添加到主屏幕，Safari 自动生成一个漂亮的品牌图标。轮到你自己的网站？只有一个页面截图，丑得不行。这就是 Apple Touch Icon 的差距——如果你正在开发新项目，大概率想从做得好的网站偷师一下。

但找到这个图标文件并不总是那么简单。跟常规的 favicon 放在 /favicon.ico 不同，Apple Touch Icon 藏在 <link> 标签或者 manifest.json 文件里。下面教你如何从任意网站提取 Apple Touch Icon——不用瞎猜 URL。

为什么 Apple Touch Icon 更难找

大部分开发者都知道标准 favicon 的 URL 规则。但苹果偏要搞点花样。这个图标可能叫 apple-touch-icon.png，也可能叫 apple-touch-icon-precomposed.png，甚至藏在 Web App Manifest 里。没有统一规范。

拿 GitHub 来说。它的 Apple Touch Icon 并不在根目录下，而是放在 https://github.githubassets.com/assets/apple-touch-icon-... 这种带 hash 的路径。如果你瞎猜 /apple-touch-icon.png，只会得到一个 404。

Apple Touch Icon 藏身的三个地方

动手之前，先搞清楚去哪找：

  • HTML <link> 标签——最常见的位置。找 rel='apple-touch-icon' 或 rel='apple-touch-icon-precomposed'。
  • Web App Manifest——有些网站在 manifest.json 的 icons 数组里定义图标，sizes 可能是 180x180。
  • 根目录——少数网站还在用老掉牙的 /apple-touch-icon.png 路径，但越来越少了。

方法一：用浏览器 DevTools 手动提取

这是最快的方法，适合快速看一眼。打开任意网站，右键点击选择“检查”（或者按 F12）。切换到“Elements”标签页，用 Ctrl+F（Mac 上 Cmd+F）搜索“apple-touch-icon”。

你会看到类似这样的代码：

<link rel='apple-touch-icon' sizes='180x180' href='/path/to/icon-180.png'>

复制 href 的值。如果是相对路径（比如 /path/to/icon-180.png），前面加上网站的域名。在新标签页打开这个 URL，图标就到手了。

如果找不到 Link 标签怎么办？

有些网站，特别是现代 PWA，完全省略了 HTML 标签，直接依赖 manifest。这时候找这个：

<link rel='manifest' href='/manifest.json'>

打开那个 JSON 文件，搜索 sizes: '180x180' 或 sizes: '192x192' 的对象。那就是你要的 Apple Touch Icon。

小技巧：检查 Precomposed 变体

旧版 iOS（iOS 7 之前）用 apple-touch-icon-precomposed，会去掉光泽效果。现代 iOS 忽略这个属性，但有些老网站还在用。如果你从老网站提取图标，记得检查两种 rel 值。Mzu favicondl 自动处理这个，但如果你手动操作，别漏了 precomposed 标签。

方法三：控制台一行代码搞定

如果你喜欢命令行，这里有个 JavaScript 片段，可以在 DevTools 控制台里运行：

const links = document.querySelectorAll('link[rel*="apple-touch-icon\)]');
links.forEach(link => console.log(link.href));

这会把页面上所有 Apple Touch Icon URL 打印出来。如果什么都没出现，说明网站可能用了 manifest。运行这个：

fetch('/manifest.json')
  .then(r => r.json())
  .then(m => m.icons.filter(i => i.sizes.includes('180'))
  .forEach(i => console.log(i.src)));

这会获取 manifest 并筛选出 180x180 的图标——这是 Apple Touch 的标准尺寸。

提取到图标后怎么用

拿到图标文件后，你可以用它作为自己设计的参考。但别直接复制——要分析它。注意大品牌是如何在 180x180 像素下把 logo 简化成单一可识别的形状。苹果用它的轮廓。Google 用 'G' 标记。Stripe 用 'S'。
