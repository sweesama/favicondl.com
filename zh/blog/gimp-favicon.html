用 GIMP 制作多尺寸 favicon ICO 图标

从 GIMP 导出的 48 像素图像，在显示器上可能依然清晰，但放到浏览器标签页里却会变成一团模糊的色块。解决方法是在 GIMP 中分别制作 16、32 和 48 像素版本，再将它们打包成一个包含多种尺寸的 favicon.ico。这套 GIMP favicon ICO 工作流能稳定生成所需文件，不必再靠改扩展名把 PNG 冒充成 ICO。

前置准备

  • 使用 GIMP，并确保可以使用 File > New、Image > Scale Image 和 File > Export As 命令。
  • 准备一个正方形的 logo 或标志。512 × 512 像素的母版能让你在缩小之前，有足够的空间简化图形。
  • 可选：安装 ImageMagick，用于最后的打包步骤。你也可以改用 Mzu favicondl，在浏览器中转换导出的 PNG 文件。

分步创建 favicon ICO

  1. 创建透明主图

    选择 File > New，将宽度和高度都设置为 512 × 512，并选择 Fill with Transparency。导入 logo，或在 GIMP 中绘制标志。将主体轮廓保持在中央正方形范围内，这样缩到较小尺寸时，留白仍然清晰可见。

    favicon 并不是缩小后的 logo。导出前先删减细小的文字、纤细的笔画和渐变；通常，单一而粗壮的形状会更清晰。

  2. 从主图创建各个尺寸

    使用 File > Duplicate 复制主图，然后选择 Image > Scale Image。保持宽度与高度联动，将一个副本缩放到 16 × 16，另一个缩放到 32 × 32，第三个缩放到 48 × 48。每个副本都要从 512 像素的原始主图缩放；放大 16 像素版本只会让边缘更柔和。

  3. 修整 16 像素版本

    打开 16 像素副本，启用 View > Show Pixel Grid。放大后，移除会与相邻像素混在一起的细节，或调整标志的对齐方式。还要在 32 像素尺寸下重复检查：此时可以保留更多细节，但较弱的单像素笔画仍可能消失。

  4. 保留 alpha 透明度

    如果导入的图层没有 alpha 通道，选中该图层，然后选择 Layer > Transparency > Add Alpha Channel。保持背景透明，不要填充为白色。PNG 导出会保留这种透明度，为 ICO 编码器提供干净的源图像。

  5. 导出三个 PNG 文件

    选择 File > Export As，输入 icon-16.png，然后点击 Export。对 icon-32.png 和 icon-48.png 重复上述操作，并将它们放在同一个文件夹中。使用 PNG 版本作为打包源文件，因为它们能保留精确的尺寸和 alpha 通道。

  6. 导出或打包 ICO

    要试用 GIMP 的 ICO 导出器，请选中 48 像素副本，选择 File > Export As，输入 favicon.ico，然后检查导出选项。如果出现尺寸列表，选择 16、32 和 48 像素。如果没有出现列表，导出结果可能只包含当前画布，因此应显式打包这三个 PNG。

    在包含这些 PNG 文件的文件夹中运行以下命令：

    magick -background none icon-16.png icon-32.png icon-48.png favicon.ico

    在命令名称为 convert 的系统上，用 convert 替换 magick。最终得到一个包含三种图像尺寸的 ICO。

  7. 检查内嵌尺寸

    如果已经安装 ImageMagick，请运行 magick identify favicon.ico，检查输出中是否列出了 16x16、32x32 和 48x48 条目。如果缺少某个尺寸，在 GIMP 中检查对应的 PNG，然后重新运行打包命令。还要在较高缩放下打开每个 PNG，确认图标没有白色背景，也没有新出现的模糊边缘。

  8. 部署 ICO

    将 favicon.ico 复制到网站的 public 根目录，然后在文档的 <head> 中链接它：

    <link rel='icon' href='/favicon.ico' sizes='16x16 32x32 48x48'>

    HTML 标准定义了 rel='icon'，用于链接图标资源。如果网站位于某个子路径下，请相应调整 URL。有关完整标记和移动端图标变体，请参阅如何为网站添加 favicon。

用 GIMP 制作 favicon ICO 时的常见问题

  • 文件里只有一种分辨率。 别只看文件名，要直接检查容器内容。16、32 和 48 像素这一组是实用的浏览器基准尺寸；favicon 尺寸指南 会说明其他格式分别适合用在哪里。
  • 小尺寸图标模糊不清。 不要只缩放图像，还要简化图形本身。细小文字和一像素细节在 48 像素下可能看着还行，缩到 16 像素就会挤成一团。
  • 透明通道丢失。 导出前添加 alpha 通道，不要将图像合成为白色或主题色背景。
  • 线上站点仍显示旧图标。 先确认 /favicon.ico 返回的是 ICO 文件，而不是 HTML 错误页面；如果旧文件仍被缓存，部署时可以改用带版本号的 URL，例如 /favicon.ico?v=2。

让最终结果更可控

将图形素材的准备工作与容器打包分开处理。GIMP 让你控制每个小尺寸下的渲染效果，而打包步骤则能确保 favicon.ico 中包含指定的分辨率。
