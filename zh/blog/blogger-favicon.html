Blogger Favicon：5 步添加博客网站图标

如果上传 logo 后，Blogspot 标签页仍然显示默认的 Blogger 图标，问题通常出在上传完成与线上页面生效之间。本指南将介绍如何设置 blogger favicon、确认浏览器实际收到的文件，以及在 Layout 面板不够用时改用主题 HTML。

最快的方法是使用 Blogger 的 Layout 页面，只需点击几次即可完成。如果需要使用 SVG、精确控制 icon URL，或者替换主题中已有的冲突声明，则应采用 HTML 方式。

开始前的准备工作

你需要具备 Blogger 博客的管理员访问权限、准备一张正方形图片，并设法检查公开访问的页面。如果采用手动 HTML 方式，每个 icon 文件都应使用可公开访问的 HTTPS URL。

  • 管理员权限：登录 Blogger 控制面板并打开你管理的博客。要进入 Layout 或 Themes 控件，需要具备 editor 权限。
  • 正方形 PNG：以 512 × 512 的主文件为基准，可以留出导出较小尺寸文件的余量，但仍要检查标识在 16 × 16 尺寸下是否清晰。平台尺寸指南会说明不同目标各自需要关注哪些尺寸。
  • 简洁的标识：优先选择轮廓鲜明、细节有限的图形；在拥挤的标签页中，缩小后的完整字标很少还能保持清晰易读。
  • 公开的资源 URL：如果使用主题 HTML，应将 SVG、PNG 或 ICO 文件托管在能够通过 HTTPS 直接返回这些文件的服务上。

用五个步骤添加 Blogger favicon

  1. 打开 Blogger 的 Layout 页面。 登录后选择目标博客，在 dashboard 导航中选择 Layout，向下滚动到 Favicon 区域，点击旁边的 Edit。如果看不到这个区域，请使用下文的主题 HTML 方法。
  2. 上传并保存图标。 在文件选择器中选择 PNG 文件，查看预览，然后保存。让图标保持正方形，这样缩放到标签页的小尺寸版本时，重要边缘也不会丢失。
  3. 打开公开博客。 保存后，在新标签页中加载线上首页。验证时请使用公开域名，而不是后台预览，因为后台预览并不代表访客实际看到的内容。
  4. 检查图标请求。 打开浏览器开发者工具，选择 Network，重新加载页面，并按 favicon 或你上传的文件名筛选请求。打开匹配的请求，确认请求成功，并返回图片文件，而不是 HTML 错误页面。
  5. 列出图标声明。 打开 Console 标签页，运行以下代码片段：
document.querySelectorAll(`link[rel~='icon']`).forEach((link) => {
  console.log(link.href, link.type, link.sizes.value);
});

输出会显示线上页面公开的每个图标候选项。打开其 URL，确认它指向你上传的图像。

在主题 HTML 中添加显式图标链接

如果 Layout 面板不可用、你要自行托管资源，或者想同时使用 SVG 和 raster fallback，可以采用这种方法。在 Blogger 中打开 Themes，点击 Customize 旁边的箭头，选择 Edit HTML，然后把这些链接粘贴到闭合的 &lt;/head&gt; 标签之前。

先保存当前主题 HTML 标记的本地副本。HTML Standard 通过 rel='icon' 定义图标关系，因此每条声明都必须指向浏览器可以获取的资源。

&lt;link rel='icon' type='image/svg+xml' href='https://assets.example.com/favicon.svg'&gt;
&lt;link rel='icon' type='image/png' sizes='32x32' href='https://assets.example.com/favicon-32.png'&gt;
&lt;link rel='icon' href='https://assets.example.com/favicon.ico'&gt;

将示例 URL 替换为可直接访问的 HTTPS 地址。删除任何指向不存在文件的代码行，并移除指向其他图稿的旧版自定义图标声明。保存主题，重新加载对外公开的域名页面，然后再次运行 Console 检查。

Blogger favicon 常见问题

  • 没有 Favicon 面板：使用主题编辑器并显式添加 link 标签，不要添加图片 widget。资源 URL 必须直接返回图标文件，不能返回 HTML 页面。
  • 旧图标仍然显示：再次修改文件前，先在隐私窗口中测试线上页面。如果页面标记和响应均正确，请使用favicon 故障排查清单完成其余缓存与路由检查。
  • 返回 404 或 HTML 响应：检查准确路径、字母大小写和主机配置。指向文章页面的 favicon 链接无法提供图像。
  • 声明冲突：旧链接可能会把访客引向另一个文件。重新运行 Console 代码片段，并只保留一套有意设置的图标声明。
  • 图稿难以辨认：简化标志，并导出清晰锐利的小尺寸 PNG。如果 SVG 无法渲染，请同时保留 PNG 或 ICO 作为 fallback。

确认结果并上线

可靠的 Blogger favicon 需要通过两项检查：线上页面的 head 中应出现你指定的图标，并且图标 URL 应返回实际图像。两项检查都通过后，上传的图标才算真正接入访客看到的页面。
