从网站URL下载Favicon：2026开发者工作流

我已经数不清有多少次需要从线上站点抓 favicon 了。也许你正在搭建一个展示合作伙伴 Logo 的 Dashboard，也许你在审计竞品的品牌素材，又或者你只是想拿 GitHub 的 Octocat 图标做个小项目。不管什么原因，从网站 URL 下载 favicon 应该是个 10 秒就能搞定的事——而不是在 DOM 里翻箱倒柜。

但大多数开发者还在用笨办法：右键、另存为，最后得到一个 16x16 的模糊图。或者直接猜 URL（/favicon.ico），结果返回 404。让我告诉你真正的流程——我 2026 年每天都在用的方法。

为什么老方法行不通了

默认的 /favicon.ico 路径从 2015 年起就不可靠了。现代网站把 favicon 放在 CDN 上，用 SVG 文件，或者嵌入 Web Manifest 里。比如 GitHub，它的 favicon 在 https://github.githubassets.com/favicons/favicon.svg——根本不在根目录。如果你直接访问 github.com/favicon.ico，只会得到一个重定向或者通用占位图。

这还只是开始。很多站点为了不同场景准备了多个图标：暗色模式、固定标签页、Apple Touch Icon、PWA Manifest。抓错一个，你的项目看起来就不专业。

专业流程：从网站 URL 下载 Favicon

下面是我用的精确步骤，适用于任何站点、任何框架、任何浏览器。

第一步：打开 DevTools 检查 Head

在页面上右键，选择检查。切换到Elements标签页，搜索 rel='icon' 或 rel='apple-touch-icon'。你会看到类似这样的内容：

<link rel='icon' type='image/svg+xml' href='/favicon.svg'>
<link rel='icon' type='image/png' sizes='32x32' href='/favicon-32x32.png'>
<link rel='apple-touch-icon' href='/apple-touch-icon.png'>

这直接告诉你站点用了哪些文件。复制 href 的值——但注意，它通常是相对路径。加上域名才能得到完整 URL。

第二步：检查 Web Manifest

很多现代站点（尤其是 PWA）在 site.webmanifest 文件里定义图标。在 head 中搜索 rel='manifest'。Manifest JSON 会列出各种尺寸的图标：

{
  'name': 'GitHub',
  'icons': [
    {'src': '/android-chrome-192x192.png', 'sizes': '192x192', 'type': 'image/png'},
    {'src': '/android-chrome-512x512.png', 'sizes': '512x512', 'type': 'image/png'}
  ]
}

这里能找到高分辨率图标——完美适合你自己的项目。

下载 Favicon 的常见坑

就算用对了工具，也可能踩坑。下面是我最常见的错误：

  • 抓错尺寸：默认的 /favicon.ico 通常是 16x16。对于 Dashboard 或应用图标，至少需要 Manifest 里的 192x192。
  • 忽略暗色模式变体：有些站点用 media='(prefers-color-scheme: dark)' 提供不同的暗色模式 favicon。如果下载了亮色版本，在暗色背景上就会消失。
  • 忘了 SVG：SVG favicon 在任何尺寸下都清晰。如果站点提供，就抓它。这是最面向未来的格式。

让我展示一下专业配置是什么样的。Stripe 从 CDN 提供 favicon，有多个变体。我检查他们站点时发现了：

  • 一个 180x180 的 Apple Touch Icon
  • 一个包含 192x192 和 512x512 图标的 Web Manifest

他们还用了缓存破坏查询字符串（?v=123）来强制更新。如果你在搭建一个注重品牌一致性的站点（你应该这样），这就是要遵循的模式。

2026 年的专业技巧

下面是我多年经验总结的几点：

  • 优先下载 SVG。它文件最小，缩放完美。只有在需要支持旧浏览器时才回退到 PNG。
  • 单独检查 Apple Touch Icon。这些通常比标准 favicon 分辨率更高，作为应用图标很好用。
  • 用 Manifest 获取 PWA 图标。如果站点是 Progressive Web App，Manifest 里会有最高质量的图标。
