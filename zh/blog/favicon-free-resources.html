完美标签页的进阶技巧

将 CSS 注入 SVG

既然现代浏览器原生支持 SVG favicon，你完全可以把 CSS 写在图标文件里。这就是防止深色 Logo 在暗色标签页上消失的终极秘籍。

<svg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 24 24'>
  <style>
    path { fill: #000; }
    @media (prefers-color-scheme: dark) {
      path { fill: #fff; }
    }
  </style>
  <path d='M12 2L2 22h20L12 2z'/>
</svg>

这一个文件就能自动处理浅色和深色主题。不需要写 JavaScript，也不需要服务器提供多套图片文件。
