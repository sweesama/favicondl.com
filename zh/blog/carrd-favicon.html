Carrd Favicon 设置教程：一步步添加自定义图标

如果你发布过 Carrd 网站，后来才发现浏览器标签页里显示的是通用地球图标或空白方块，你并不孤单。Carrd 默认不会添加 favicon，因此标签页只会显示浏览器自动使用的回退图标。知道设置藏在哪里后，解决起来并不复杂。

下面将一步步演示如何为 Carrd 添加自定义 favicon、如何验证显示结果，以及 favicon 没有出现时最常见的原因。全程以实操为主，不需要任何图片处理经验。

开始前需要准备什么

Carrd 的站点图标只接受一个图片文件。想要清晰的效果，建议准备一张透明背景的正方形 PNG，理想尺寸为 512×512 像素或更大。平台会自动调整图片尺寸以适应标签页，但以高分辨率正方形图片作为起点，可以避免模糊。

如果手头只有带文字的 logo，或图片的宽高比较大，请先裁出核心标志。大多数标签页中的 favicon 只有 16×16 像素，细小内容很快就看不出来了。关于这一设计限制，可参阅我们的指南：为什么 favicon 不能只是缩小后的 logo。

分步骤添加 Carrd favicon

  1. 打开 Carrd dashboard。 登录后，选择要编辑的网站。
  2. 进入 Settings。 在编辑器中，点击齿轮图标，或点击左侧边栏中的 Settings 标签。
  3. 找到 Favicon 区域。 滚动至 Favicon 设置区，你会看到上传按钮和预览框。
  4. 上传正方形 PNG。 点击 Upload，选择文件，然后等待预览更新。Carrd 会保存这张图片，并通过其 CDN 提供服务。
  5. 发布网站。 只有点击 Publish 后，修改才会应用到线上网站。如果你使用免费套餐，favicon 可能只会出现在已发布的 URL 上，而不会显示在编辑器预览中。
  6. 在浏览器标签页中验证。 在新标签页中打开线上网站。图标应该在几秒内出现；如果没有显示，可以尝试强制刷新（Ctrl+F5 或 Cmd+Shift+R）。

Carrd 原生的操作流程就这么简单。它没有提供设置多种图标尺寸或 Apple Touch Icon 的字段，因此通过 UI 能做的只有这一次上传。

Carrd 实际会输出什么

上传 favicon 后，Carrd 会在页面 head 中生成一个 <link rel='icon'> 标签，指向你上传的图片。具体标签代码由平台处理，无需手动编辑 HTML。HTML 规范将 rel=icon 定义为页面关联图标的标准方式，浏览器也会遵循这一惯例。

由于 Carrd 会从自己的域名提供图标，因此无法通过标准编辑器轻松添加 180×180 的 Apple Touch Icon 等其他尺寸，也无法添加 web app manifest。如果需要这些配置，就得使用 Carrd 的 embed 功能，或配置 custom domain 并注入额外的 HTML（部分套餐支持）。

常见问题及解决方法

  • 图标看起来模糊。 你上传的可能是尺寸较小或非正方形的图片。请将其替换为 512×512 的 PNG，然后重新发布。
  • 仍然显示旧图标。 浏览器会 aggressively cache favicon。清除缓存，或在隐私窗口中测试。如果要彻底解决，请参阅我们的 favicon 未显示排查清单。
  • 完全没有显示图标。 确认上传后是否点击了 Publish。Carrd 不会自动将 favicon 保存并发布到线上站点。
  • Google Search 显示通用图标。 Google 需要时间重新抓取你的站点。相关要求已有文档说明：图标必须为正方形且至少为 8×8 像素，URL 必须保持稳定，首页还必须包含 rel=icon 链接。Carrd 的上传方式已经满足基本要求，但重新抓取可能需要数天甚至数周。

需要超出 Carrd 默认配置时

Carrd 的单图标方案适用于大多数个人站点和 landing page。如果你在开发 progressive web app，或者需要为 iOS 打造更精致的主屏幕图标，就应该准备一套完整的图标。你可以使用 Mzu favicondl 生成图标，然后再决定如何注入额外的标签，通常可以通过 custom domain 或 embed block 实现。

想了解各平台分别需要哪些尺寸，可以阅读我们的按平台区分的 favicon 尺寸指南。其中介绍了 ICO 的 16、32 和 48 px 图层、180×180 的 Apple Touch Icon，以及 192 和 512 px 的 manifest 图标。

结语

给 Carrd 添加 favicon 不到两分钟：在 Settings 中上传一张正方形 PNG，发布后再打开一个新标签页确认效果。真正容易卡住的环节是缓存，以及平台仅支持单文件的限制。先准备一个简洁、对比度高的图标，你的标签页就会显得像是经过特意设计，而不是千篇一律的默认样式。
