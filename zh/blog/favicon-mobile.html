2026年移动端 Favicon 适配完全指南

如果你曾用 iPhone 把网页“添加到主屏幕”，然后无奈地发现保存下来的图标只是一个模糊得无法阅读的网页截图——这说明你的移动端 Favicon 设置完全不合格。移动端浏览器根本不在乎你那些老旧的桌面端图标，它们需要一套特定的高分辨率资源，才能让你的网站看起来像个原生 App。

看看 GitHub 的移动端网页体验吧。当你在 Safari 的标签页网格中查看他们的网站时，你会看到一个清晰、边距完美的图标。把它保存到 Android 设备上，它又能完美适应系统的任何图标形状。这绝非偶然，这是因为他们对移动端 Favicon 采取了精准的适配策略。

别再试图塞进15种不同尺寸的图标了。在2026年，你只需要几个特定的文件，就能覆盖 99% 的移动设备。接下来我将手把手教你如何设置。

移动端图标的准备工作

在写代码之前，你需要一张合适的源图片。千万别用 32x32 像素的文件。你需要一个高分辨率、正方形的 Logo。我建议从 512x512 像素的 PNG 或清晰的 SVG 开始。如果你的 Logo 带有文字，请去掉它，只保留纯图形标志，这样在小屏幕手机上才能保持可读性。

移动端 Favicon 适配步骤

第1步：用 Apple Touch Icon 征服 iOS

苹果在这方面出了名的固执。iOS 上的 Safari 在保存到主屏幕或在多标签预览时，会完全忽略标准的 favicon 声明。它强制要求一个名为 Apple Touch Icon 的特定文件。

你只需要一张 180x180 像素的 PNG。这里不要用 SVG，iOS 会忽略它。此外，iOS 会将所有透明背景填充为黑色。如果你的深色 Logo 放在透明背景上，最后就会变成一个看不见的黑方块。因此，这个特定文件必须使用纯色背景。

你可以在我们的 Apple Touch Icon 指南 中了解更多细节，但落实到代码其实只有一行 HTML。

第2步：用 Web App Manifest 搞定 Android

Android 上的 Chrome 处理图标的方式完全不同。它不找特定的 HTML 标签，而是寻找一个名为 web app manifest 的 JSON 文件。这个文件告诉 Android 你的网站在安装后或在任务切换器中应该如何表现。

对于 Android，你需要两种尺寸的 PNG：192x192 和 512x512。你需要在根目录下的 site.webmanifest 文件中定义它们。

第3步：实现 Maskable Icons（自适应图标）

Android 手机厂商喜欢各种奇怪的图标形状。三星可能是圆角矩形，Pixel 可能是圆形，其他品牌可能是水滴形。如果你不提供 maskable icon，Android 就会把你的方形 Logo 缩小，然后强行塞进一个白圈里，非常难看。

通过在 manifest 中添加 purpose: 'maskable' 属性，你就允许 Android 根据系统的原生形状裁剪你的图标。只需确保你 Logo 的主体图形安全地处于中心的“安全区”（图像内部的 80% 区域）即可。

第4步：最终代码集成

以下是将你的移动端 Favicon 整合在一起所需的完整代码。首先，将这段代码添加到你的 HTML <head> 中：

<!-- iOS Safari -->
<link rel='apple-touch-icon' sizes='180x180' href='/apple-touch-icon.png'>

<!-- Android / Chrome -->
<link rel='manifest' href='/site.webmanifest'>

<!-- 现代移动端浏览器 (SVG 降级方案) -->
<link rel='icon' type='image/svg+xml' href='/icon.svg'>

接下来，创建你的 site.webmanifest 文件，JSON 结构如下：

{
  'name': '你的应用名称',
  'short_name': 'App',
  'icons': [
    {
      'src': '/icon-192x192.png',
      'sizes': '192x192',
      'type': 'image/png'
    },
    {
      'src': '/icon-512x512.png',
      'sizes': '512x512',
      'type': 'image/png',
      'purpose': 'any maskable'
    }
  ],
  'theme_color': '#ffffff',
  'background_color': '#ffffff',
  'display': 'standalone'
}

常见避坑指南

  • 无视 iOS 透明度规则： 如前所述，透明 PNG 在 iPhone 上会变成黑块。一定要给 apple-touch-icon.png 加上纯色背景。
  • 头部标签臃肿： 你不再需要 57x57、72x72 或 114x114 的图标了。现代 iOS 设备能完美缩放 180x180 的图片。删掉那些历史遗留的垃圾代码。
  • 忘记 manifest 主题色： manifest 中的 theme_color 决定了当你的网站从主屏幕启动时，Android 状态栏的颜色。千万别留空。
