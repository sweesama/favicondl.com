快速开始

favicondl 的 favicon API 只需一个 GET 请求，就能把任意域名或网址转换成它的 favicon。不需要 API key，不需要账号，也不需要 SDK。可以直接写进 <img> 标签：

<img src="https://favicondl.com/api/extract?url=github.com" width="32" height="32" alt="GitHub 的 favicon">

也可以请求 JSON，查看找到了哪个文件、来自哪里：

curl "https://favicondl.com/api/extract?url=github.com&format=json"

  "proxyUrl": "https://favicondl.com/api/proxy?url=https%3A%2F%2Fgithub.githubassets.com%2Ffavicons%2Ffavicon.svg",
  "source": "html",
  "rel": "icon",
  "format": "svg",
  "width": null,

  "candidates": [
    { "url": "https://github.githubassets.com/favicons/favicon.svg", "format": "svg", "vector": true, "source": "html", "rel": "icon", "proxyUrl": "…" },

    { "url": "https://github.com/favicon.ico", "format": "ico", "width": 32, "height": 32, "source": "direct", "rel": "favicon.ico", "proxyUrl": "…" }

iconUrl 是网站上的原始文件。proxyUrl 通过我们的代理返回同一张图片，并带有 Access-Control-Allow-Origin: *，所以你可以把它画到 canvas 上，或在浏览器端代码里直接 fetch。

format、width 和 height 描述的是我们实测的所选文件（SVG 的 width/height 为 null）。candidates 列出同一网站最多 8 个其他经过验证的图标（不同尺寸和格式），方便你换一个用；上面的示例做了删减。如果最终退回到了 Google 或 DuckDuckGo，这个列表为空。

API 如何选出图标

  1. 首页会像普通浏览器一样被请求，并跟随重定向（包括 www ↔ 裸域名）。页面里所有图标相关的 <link> 都会被读取：icon、shortcut icon、apple-touch-icon、apple-touch-icon-precomposed 和 mask-icon。相对链接和协议相对链接（//cdn…）会按最终页面地址或页面的 <base> 标签解析（source: "html"）。
  2. Web App Manifest：打开页面引用的 manifest，读取其中的图标列表，192px 和 512px 的图标通常就在这里（source: "manifest"）。
  3. 常见路径 /favicon.ico 和 /apple-touch-icon.png 也会尝试（source: "direct"）。
  4. 每个候选都会被下载并检查：内容必须真的是图片（PNG、ICO、SVG、WebP、JPEG、GIF 等），并且会测量它的真实像素尺寸，而不是相信文件名。
  5. Google 的 favicon 服务，其次是 DuckDuckGo，只有在网站本身的图标都不可用时才会使用，并按你请求的 size 获取（source: "google_s2" 或 "duckduckgo"）。

通过验证的候选会按清晰度排序：全彩 SVG 优先，其次是尺寸最大的正方形 PNG/ICO/WebP。Safari 的单色 mask-icon 和只标注为 maskable 的 manifest 图标排位较低，因为它们看起来和普通的 favicon 不一样。从网站上找到的图标按原始尺寸返回；size 参数只影响备用来源。

如果拿到的是 google_s2，说明这个网站要么没有我们能访问到的图标，要么拦截了我们的请求（比如返回了人机验证页面）。如果只查一个网站，首页上的 favicon 下载器还会直接从你的浏览器尝试几个额外来源，并列出找到的所有尺寸供你选择。

接口端点

GET FaviconDL Extract API

查找并下载指定域名或网址的可用 favicon

基础URL：

https://favicondl.com/api/extract

完整示例：

https://favicondl.com/api/extract?url=example.com&size=128

参数说明

参数名 类型 必需 默认值 描述
url string 是 - 目标域名或网址，如：example.com
size number 否 128 回退尺寸（16–512 像素）。仅在回退到 Google favicon 服务时使用；从网站本身找到的图标按原始尺寸返回。
format string 否 redirect 使用 json 获取元数据；省略时直接跳转到可下载图片

参数详情：

网址

支持域名和完整网址：

  • • example.com
  • • www.example.com
  • • https://example.com/docs
  • • sub.example.com
尺寸

Google favicon 服务的回退尺寸，范围 16 到 512 像素：

  • • 16 - 16x16
  • • 32 - 32x32
  • • 128 - 128x128
  • • 512 - 512x512

使用示例

JavaScript (Fetch)

JavaScript 
async function getFavicon(url, size = 128) {
  const endpoint = new URL('https://favicondl.com/api/extract');
  endpoint.searchParams.set('url', url);
  endpoint.searchParams.set('size', String(size));
  const response = await fetch(endpoint);
  if (!response.ok) throw new Error(`Favicon request failed: ${response.status}`);
  return await response.blob();
}

const icon = await getFavicon('example.com', 128);
const imageUrl = URL.createObjectURL(icon);
document.querySelector('#favicon-preview').src = imageUrl;

Python (Requests)

Python 
import requests

def get_favicon(url: str, size: int = 128) -> bytes:
    response = requests.get(
        "https://favicondl.com/api/extract",
        params={"url": url, "size": size},
        timeout=15,
    )
    response.raise_for_status()
    return response.content

icon_bytes = get_favicon("example.com", 128)
with open("example-favicon", "wb") as output:
    output.write(icon_bytes)

PHP (cURL)

PHP 
<?php
function getFavicon(string $url, int $size = 128): string {
    $endpoint = 'https://favicondl.com/api/extract?url=' . urlencode($url) . '&size=' . $size;
    $context = stream_context_create(['http' => ['follow_location' => 1, 'timeout' => 15]]);
    $icon = file_get_contents($endpoint, false, $context);
    if ($icon === false) {
        throw new RuntimeException('Favicon request failed');
    }
    return $icon;
}

file_put_contents('example-favicon', getFavicon('example.com', 128));
?>

错误处理

出错时会返回 HTTP 状态码和一段简短的 JSON，其中 ok 为 false，并附带错误信息。

HTTP状态码 错误信息 描述 解决方法
400 Missing url 未传入 url 或 domain 参数 在请求中加上 ?url=example.com
400 Invalid format format 既不是 json 也不是 redirect 使用 format=json，或省略该参数以获得重定向
400 Invalid domain 无法将该值解析为主机名 传入 example.com 这样的域名或完整的 https:// 网址
405 Method not allowed 仅支持 GET 请求 改用 GET 请求
502 Favicon extraction failed 提取器未能返回图标 稍后重试
415 Target is not an image 仅 /api/proxy 返回：该地址返回的不是真正的图片数据 改用 /api/extract 返回的 iconUrl 或 candidates[].url
