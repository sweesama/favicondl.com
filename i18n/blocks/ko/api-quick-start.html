빠른 시작

favicondl 파비콘 API는 GET 요청 한 번으로 어떤 도메인이나 URL이든 그 사이트의 파비콘으로 바꿔 줍니다. API 키, 계정, SDK가 모두 필요 없습니다. size(16–512, 흔히 16, 32, 64, 128, 256, 512)를 넘기면 정확히 그 한 변의 정사각형 PNG가 옵니다.

<img src="https://favicondl.com/api/extract?url=github.com&size=32" width="32" height="32" alt="GitHub 파비콘">

size를 생략하면 원본 파일입니다. 더 작은 래스터는 확대되어 흐려 보일 수 있습니다. SVG는 요청한 크기로 래스터화합니다. 이미지 응답의 X-Favicon-Native-Size와 X-Favicon-Upscaled가 확대 여부를 알려 줍니다.

JSON을 요청하면 어떤 파일을 찾았고 어디서 가져왔는지 확인할 수 있습니다.

curl "https://favicondl.com/api/extract?url=github.com&format=json"
curl "https://favicondl.com/api/extract?url=github.com&size=32&format=json"

iconUrl은 웹사이트의 원본 파일입니다. 받는 이미지는 proxyUrl입니다. size를 생략하면 원본이고, size를 주면(예: &size=32) 정확히 그 크기의 정사각형 PNG입니다. Access-Control-Allow-Origin: *가 붙습니다.

width와 height는 측정한 원본입니다(SVG는 null). size가 있으면 outputWidth와 outputHeight가 그 값과 같고, nativeWidth / nativeHeight는 원본 픽셀이며, 래스터를 키운 경우에만 upscaled가 true입니다. 그때 PNG는 흐려 보일 수 있습니다. candidates는 검증된 다른 아이콘을 최대 8개 담습니다. Google이나 DuckDuckGo로 대체되면 비어 있습니다.
