クイックスタート

favicondl のファビコン API は、GET リクエスト 1 回であらゆるドメインや URL をそのファビコンに変換します。API キーもアカウントも SDK も不要です。<img> タグにそのまま書けます。

<img src="https://favicondl.com/api/extract?url=github.com" width="32" height="32" alt="GitHub のファビコン">

JSON をリクエストすれば、どのファイルが見つかり、どこから取得したかを確認できます。

curl "https://favicondl.com/api/extract?url=github.com&format=json"
{
  "ok": true,
  "domain": "github.com",
  "size": 128,
  "iconUrl": "https://github.githubassets.com/favicons/favicon.svg",
  "proxyUrl": "https://favicondl.com/api/proxy?url=https%3A%2F%2Fgithub.githubassets.com%2Ffavicons%2Ffavicon.svg",
  "source": "html",
  "rel": "icon",
  "format": "svg",
  "width": null,
  "height": null,
  "pageUrl": "https://github.com/",
  "candidates": [
    { "url": "https://github.githubassets.com/favicons/favicon.svg", "format": "svg", "vector": true, "source": "html", "rel": "icon", "proxyUrl": "…" },
    { "url": "https://github.githubassets.com/assets/app-icon-512-7f9c4ff2e960.png", "format": "png", "width": 512, "height": 512, "source": "manifest", "rel": "manifest", "proxyUrl": "…" },
    { "url": "https://github.com/favicon.ico", "format": "ico", "width": 32, "height": 32, "source": "direct", "rel": "favicon.ico", "proxyUrl": "…" }
  ]
}

iconUrl はサイト上の元ファイルです。proxyUrl は同じ画像を当社のプロキシ経由で Access-Control-Allow-Origin: * 付きで返すので、canvas に描画したりブラウザのコードから fetch したりできます。

format、width、height は、選ばれたファイルを当社で実測した値です（SVG の場合 width/height は null）。candidates には、同じサイトで検証済みのほかのアイコン（サイズや形式が異なるもの）が最大 8 個並ぶので、別のものを選べます。上の例は一部を省略しています。Google や DuckDuckGo にフォールバックした場合は空になります。
