クイックスタート

favicondl のファビコン API は、GET リクエスト 1 回であらゆるドメインや URL をそのファビコンに変換します。API キーもアカウントも SDK も不要です。size（16〜512。よく使う値は 16、32、64、128、256、512）を渡すと、ちょうどその一辺の正方形 PNG が返ります。

<img src="https://favicondl.com/api/extract?url=github.com&size=32" width="32" height="32" alt="GitHub のファビコン">

size を省略すると元のファイルです。元より小さいラスタは拡大され、ぼやけることがあります。SVG は指定サイズでラスタライズします。画像レスポンスの X-Favicon-Native-Size と X-Favicon-Upscaled で、拡大したかどうかが分かります。

JSON をリクエストすれば、どのファイルが見つかり、どこから取得したかを確認できます。

curl "https://favicondl.com/api/extract?url=github.com&format=json"
curl "https://favicondl.com/api/extract?url=github.com&size=32&format=json"

iconUrl はサイト上の元ファイルです。proxyUrl がダウンロードする画像です。size を省略すると元ファイル、size を付けると（例: &size=32）ちょうどその正方形 PNG です。Access-Control-Allow-Origin: * が付きます。

width と height は実測した元画像です（SVG は null）。size を指定すると outputWidth と outputHeight がそれと一致し、nativeWidth / nativeHeight は元のピクセル、upscaled はラスタを拡大したときだけ true です。その PNG はぼやけることがあります。candidates は検証済みの別アイコンを最大 8 個並べます。Google や DuckDuckGo にフォールバックした場合は空です。
