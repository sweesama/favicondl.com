Favicon API 对比：favicondl、Google S2、DuckDuckGo 与 Icon Horse

这四个服务都可以免费开始用，也都不需要 API key。区别在于它们返回的内容：

favicondlGoogle S2DuckDuckGoIcon Horse
接口地址/api/extract?url=example.comgoogle.com/s2/favicons?domain=example.com&sz=64icons.duckduckgo.com/ip3/example.com.icoicon.horse/icon/example.com
API key不需要不需要不需要不需要（免费套餐）
公开的免费额度无（合理使用）未公开未公开免费套餐每月 1,000 个图标
尺寸参数size 16–512（例如 16、32、64、256、512）。省略则返回原始文件。sz无文档未说明
返回内容设置 size 时为恰好该尺寸的正方形 PNG；否则为原始文件（SVG、PNG、ICO 等）PNG 或 JPEG（实测）ICO（实测）PNG（实测）
JSON 元数据有（format=json：图标地址、来源、格式、实测像素尺寸，以及最多 8 个备选图标）无无无
我们测试 github.com 的结果favicon.svg（矢量图）sz=16 时为 16×16 PNG，sz=256 时为 180×180含 16×16 和 32×32 的 ICO256×256 PNG

以上结果来自我们在 2026 年 10 月 12 日的实际请求；Icon Horse 的额度取自其价格说明。第三方服务随时可能变化，在生产环境中依赖它们之前，请先查看各服务商的条款。
