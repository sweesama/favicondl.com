快速开始

favicondl 的 favicon API 只需一个 GET 请求，就能把任意域名或网址转换成它的 favicon。不需要 API key，不需要账号，也不需要 SDK。传入 size（16–512，常用 16、32、64、128、256、512）会得到恰好该边长的正方形 PNG：

<img src="https://favicondl.com/api/extract?url=github.com&size=32" width="32" height="32" alt="GitHub 的 favicon">

省略 size 则返回原始文件。比请求更小的位图会被放大，可能发虚。SVG 会按请求尺寸栅格化。图片响应上的 X-Favicon-Native-Size 和 X-Favicon-Upscaled 会说明是否放大过。

也可以请求 JSON，查看找到了哪个文件、来自哪里：

curl "https://favicondl.com/api/extract?url=github.com&format=json"
curl "https://favicondl.com/api/extract?url=github.com&size=32&format=json"

    { "url": "https://github.com/favicon.ico", "format": "ico", "width": 32, "height": 32, "source": "direct", "rel": "favicon.ico", "proxyUrl": "…" }

}

iconUrl 是网站上的原始文件。proxyUrl 才是要下载的图片：省略 size 时是原始文件，设置了 size（例如 &size=32）时是恰好该尺寸的正方形 PNG。响应带有 Access-Control-Allow-Origin: *。

width 和 height 是实测的源图（SVG 为 null）。设置了 size 时，outputWidth 与 outputHeight 等于该值，nativeWidth / nativeHeight 是源图像素，只有位图被放大时 upscaled 才为 true，这时 PNG 可能发虚。candidates 最多列出 8 个其他已验证图标。退回到 Google 或 DuckDuckGo 时列表为空。
