如何下载任意网站的 Favicon 图标

  1. 输入域名或网址。在本页顶部的输入框里输入 github.com 这样的域名，或者直接粘贴完整的网页地址。https:// 和 www. 都可以省略。
  2. 选择尺寸。可选 16、32、48、64 或 128 px。预览区始终显示我们能找到的最佳图标，并注明它的原始尺寸。按所选尺寸导出默认是打开的，会把 PNG 缩放到你选的尺寸；关掉它，文件就会保持原始分辨率。如果所选的 32、64 或其他尺寸大于网站发布的图标，预览下方会提示导出会放大、可能发虚。
  3. 下载或复制。点击下载把图标保存为 PNG，或者复制现成的 <link> HTML 标签，以及原始文件的直链。

就这么简单：无需注册账号，无需安装浏览器扩展，也不用上传任何文件。如果你需要原始的 .ico 或 .svg 文件而不是 PNG，打开结果里显示的直链另存即可。

Favicon 提取器会查找哪些图标

网站很少只放一个图标。一个典型的网站通常有传统的 favicon.ico、几张 PNG、给 iPhone 用的 Apple touch icon，以及给 Android 用的 Web App Manifest。我们的 favicon 提取器会像普通浏览器一样加载首页（并跟随 www 跳转到裸域名之类的重定向），读取页面 HTML 中所有 <link rel="…icon…"> 标签，打开页面引用的 manifest 收集其中列出的图标，同时尝试 /favicon.ico 和 /apple-touch-icon.png 这两个常见路径。每个文件都会被真正下载下来，确认确实是图片，并测量它的实际像素尺寸。

图标类型声明位置常见尺寸用途
ICO 图标/favicon.ico 或 rel="icon" / rel="shortcut icon"16×16、32×32、48×48（一个文件里常含多个尺寸）浏览器标签页、书签、旧版浏览器

如果一个网站以上这些都没有提供（比如它拦截自动化请求，或者只用 JavaScript 加载图标），我们会退回到 Google 的公开 favicon 服务，这样你仍然能拿到一张可用的图标，只是尺寸可能偏小。想深入了解各个尺寸分别用在哪里，可以看我们的 Favicon 尺寸指南。

如何获取最高清的图标

提取器会给找到的每个图标排序，把最清晰的那个放在第一位。全彩 SVG 优先，因为它放大也不会丢失细节；其次是实测尺寸最大的正方形图片，通常是 512 或 192 px 的 manifest 图标，或 180 px 的 Apple touch icon；传统的 ICO 文件往往只有 16 或 32 像素宽，所以通常排在最后。Safari 的单色 mask 图标排位也很靠后。下载器还会列出找到的其他尺寸，你可以换一个来用。

  • 保留原始尺寸。关闭按所选尺寸导出，下载的 PNG 就会保留源文件的完整分辨率。
  • 放大会发虚。把 16 px 的图标要成 32 px 或 128 px 并不会增加细节。当导出尺寸大于原始图标时，预览会提示。API 的 size 仍会返回恰好该尺寸的正方形（16、32、64、128、256 或 512），位图被放大时 upscaled 为 true。
  • 看清图标来源。在 API 的 JSON 里，source 会说明图标来自网站本身（html、manifest 或 direct），还是备用服务（google_s2 或 duckduckgo）。nativeWidth 和 nativeHeight 是原图像素（SVG 为 null）。省略 size 则拿到原始文件。
  • 需要的是 Logo 而不是图标？Favicon 本来就是为小尺寸设计的。印刷或营销用途，请使用该公司官方的媒体资料包或品牌页面。

批量下载 Favicon

每行一个域名，一次最多粘贴 100 个，把所有图标打包成 ZIP 下载，或者逐个保存为图片，可按域名或序号命名。

免费 Favicon API

一个 GET 请求就能按网址获取任意网站的图标。不需要 API key，也不用注册；可以直接跳转到图片，也可以返回包含图标地址和来源的 JSON。

常见问题

下载网站的 favicon 合法吗？

Favicon 是公开文件，每个浏览器打开网站时都会下载它，所以把它保存下来在技术上没有区别。不过图标通常是网站所有者 Logo 或商标的一部分。用它来标示链接指向哪个网站（比如书签、仪表盘、链接预览）是常见做法；把它当作你自己的品牌标识则不行。拿不准时，请查看该公司的品牌使用规范。以上只是一般信息，不构成法律意见。

为什么下载的 favicon 看起来很模糊？

通常是因为网站只发布了很小的图标，或者导出时被放大了。关闭按所选尺寸导出即可保留原始分辨率。如果网站只有 16 px 或 32 px 的 ICO，任何工具都补不回缺失的细节。

可以批量下载 favicon 吗？

可以。批量 Favicon 下载工具一次最多支持 100 个域名，结果可以打包成一个 ZIP 下载，也可以逐个保存为图片。

有免费的 favicon API 吗？

有。https://favicondl.com/api/extract?url=github.com 会直接跳转到我们找到的最佳图标，所以可以直接写进 <img> 标签。加上 &format=json 则会返回图标地址和它的来源。不需要 key，也不需要账号；请在你自己那边做好缓存。详见 API 文档。

favicon grabber、fetcher 和 extractor 有什么区别？

没有本质区别。“favicon grabber”“favicon fetcher”“favicon finder”和“favicon extractor”是同一类工具的不同叫法：输入一个网站，它帮你找到并下载这个网站的图标。这个 favicon 下载器都能做到。

为什么有些网站返回的是一个通用地球图标，或者没有图标？

有些网站会拦截自动化请求、需要登录或人机验证、在页面加载后才用 JavaScript 添加图标，或者根本没有 favicon。这些情况下我们会退回到 Google 的 favicon 服务，它可能返回一张很小的图，或者一个默认的地球图标。

下载到的是什么格式？

下载按钮始终保存为 PNG，哪里都能用。如果你需要原始格式，结果里的直链指向网站上的原始文件，可能是 ICO、PNG、SVG 或 WebP。

能用在 localhost 或内网网站上吗？

不能。提取器运行在我们的服务器上，只能访问公开网站。它看不到 localhost、你的内网或需要登录的页面，我们的图片代理也会拒绝私有地址。

可以把我自己的图片做成 favicon 吗？

可以。工具页里的图片转 Favicon 工具能把 Logo 转成多种尺寸的 PNG 和一个 ICO 文件，并连同 Web Manifest 和要粘贴到网站里的 HTML 标签一起打包成 ZIP。图片在你的浏览器里处理，不会上传。

我自己的网站需要哪些 favicon 尺寸？

对大多数网站来说，一个给浏览器用的 SVG 或 32×32 PNG、一个 180×180 的 Apple touch icon，再加 192×192 和 512×512 两个 manifest 图标就够了。我们的 Favicon 尺寸指南逐一做了说明。
