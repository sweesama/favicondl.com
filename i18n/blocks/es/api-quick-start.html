Inicio rápido

La API de favicons de favicondl convierte cualquier dominio o URL en su favicon con una sola petición GET. Sin clave de API, sin cuenta y sin SDK. Pasa size (16–512; lo habitual es 16, 32, 64, 128, 256 y 512) para obtener un PNG cuadrado de exactamente ese tamaño:

<img src="https://favicondl.com/api/extract?url=github.com&size=32" width="32" height="32" alt="Favicon de GitHub">

Omite size para recibir el archivo original. Un raster más pequeño se amplía y puede verse borroso. Un SVG se rasteriza al tamaño pedido. Las cabeceras X-Favicon-Native-Size y X-Favicon-Upscaled de la imagen indican cuándo ocurrió.

O pide JSON para ver qué archivo se encontró y de dónde procede:

curl "https://favicondl.com/api/extract?url=github.com&format=json"
curl "https://favicondl.com/api/extract?url=github.com&size=32&format=json"

iconUrl es el archivo original del sitio. proxyUrl es la imagen que hay que descargar: el archivo original si omites size, o un PNG cuadrado exacto (por ejemplo &size=32) si lo indicas. Incluye Access-Control-Allow-Origin: *.

width y height son el origen medido (null en SVG). Con size, outputWidth y outputHeight coinciden con él, nativeWidth / nativeHeight son los píxeles de origen, y upscaled es true solo cuando un raster se amplió: ese PNG puede verse borroso. candidates lista hasta 8 iconos verificados más.
