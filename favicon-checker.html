    How the favicon checker works

    The form sends one request to the existing /api/extract endpoint. The query uses only url and format=json. https://www.GitHub.com/ and github.com become the same cache key: lowercase host, no leading www, no trailing slash, and no scheme in the parameter, for example /api/extract?url=github.com&format=json. The browser then reads the JSON. When an ICO is returned, the page fetches that file through /api/proxy and reads the 16, 32 and 48 layers locally. Nothing new runs on the server for the checklist.

    The list is the icons the extractor verified. A site can publish additional files that were not in the response. Use the snippets for anything the checklist marks missing, then publish the matching file.

    Frequently asked questions

    What does this favicon checker look for?

    A favicon checker takes a domain and lists the icons that site actually publishes. This page calls /api/extract, then marks favicon.ico, PNG sizes 16, 32 and 48, a 180×180 apple-touch icon, web manifest icons at 192 and 512, and an SVG. Each missing item includes HTML you can paste into the page head.

    Why is a size marked missing when the site has a large icon?

    A 512×512 manifest icon does not count as 16×16 or 32×32. Browsers and Google look for those smaller files, or for those layers inside favicon.ico. An SVG covers the SVG row only. It is not a substitute for the PNG sizes in the checklist.

    How do I fix a missing favicon?

    Copy the snippet next to the missing row into the site head, and put the matching file at that path. The Image to Favicon tool builds the ICO, the PNGs, the apple-touch icon and the manifest from one logo. The size guide explains where each size is used.

    Does the checker change my website?

    No. It only reads public icon files. Nothing is uploaded, and the page does not edit the site you check. The HTML snippets are for you to paste yourself.

    Why does the result only show a Google or DuckDuckGo icon?

    The extractor uses those services only when the site itself returns no usable image. The checklist then shows every standard size as missing, because a fallback image is not a file on that site. Common causes are a bot check, a login wall, or an icon added only with JavaScript.

    Can I check more than one site?

    Yes. The bulk favicon downloader accepts up to 100 domains. This page checks one site and tells you which sizes are missing. Saved copies of well-known site icons are on the site favicon pages.
