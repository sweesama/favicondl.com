Favicon embed code and badge

Need the icon of another website in a link list, bookmark page, dashboard or Notion-style doc? The FaviconDL API returns the best icon it can find for any domain, so a single <img> tag is enough. It is free and needs no API key.

1. Show any site's favicon with one img tag

<img src="https://favicondl.com/api/extract?url=github.com&amp;size=32"
     width="16" height="16" alt="" loading="lazy">

Live example: github.com · wikipedia.org

  • url: a domain or full URL.
  • size: the size you prefer in pixels; the API picks the closest icon the site offers. Request 2× the displayed size (for example 32 for a 16 px icon) so it stays sharp on Retina screens.
  • Add format=json to get the icon URL and metadata instead of the image. All options are in the API documentation.

Tip: keep alt="" when the site name is already written next to the icon, so screen readers do not read it twice, and keep width/height so the layout does not jump while icons load.

2. Markdown (README, docs, wikis)

![](https://favicondl.com/api/extract?url=github.com&size=32) [GitHub](https://github.com)

GitHub and most Markdown renderers will show the icon inline. GitHub proxies images through its own cache, so a changed favicon may take a while to update.

Fair use

  • The icons belong to their websites. Show them to identify the site, not as your own logo.
  • For high-traffic pages, cache icons on your side (or use the API once and store the result) instead of requesting the same icon on every page view.
  • Need the right sizes for your own site's favicon? See the favicon sizes guide or generate them with the free tools.
