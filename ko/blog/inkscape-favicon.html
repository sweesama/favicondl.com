Inkscape로 favicon 제작하고 내보내는 방법

Inkscape에서 만든 그래픽이 canvas에서는 잘 보이지만 browser tab에서는 잘려 흐릿해 보인다면, 문제는 export format이 아니라 document에 있는 경우가 많습니다. Inkscape favicon을 만들려면 정사각형으로 구성된 drawing, 이식성 높은 path, 그리고 웹에 바로 사용할 수 있는 file이 필요합니다.

준비 사항

Inkscape와 기존 SVG logo가 필요합니다. artwork가 넓은 페이지에 놓여 있다면 새로운 정사각형 document를 만들고, symbol을 복사해 비율을 유지한 채 크기를 조정한 다음 그 file을 editable master로 보관합니다. 식별하기 쉬운 symbol은 full wordmark보다 16×16 pixels에서 더 잘 표현됩니다.

예를 들어 source가 1200×400 wordmark라면 그 rectangle를 favicon 안에 억지로 늘이거나 줄여 넣지 않습니다. symbol만 선택해 정사각형 document에 붙여 넣고 비율을 유지한 채 크기를 조정합니다. 이렇게 하면 원본 artwork를 변경하지 않고도 반복해서 export할 수 있는 compact master가 만들어집니다.

  • 실용적인 design size로 128×128-pixel artboard를 사용합니다.
  • mark을 중앙에 두고 주변에 약간의 transparent space를 남겨 둡니다.
  • 작은 크기에서도 구분하기 어려운 detail은 제거합니다.

1. 정사각형 canvas와 viewBox 설정

File → Document Properties를 열고, units를 pixels로 설정한 뒤 document의 너비와 높이를 같게 설정합니다. 128×128은 브라우저에서 요구하는 크기가 아니라 권장 크기이며, 64×64로 만들어도 됩니다. 128×128 document를 사용한다면 viewBox가 0 0 128 128로 표시되는지 확인합니다.

Object → Align and Distribute를 열고 Page를 reference로 선택한 뒤, artwork를 가로와 세로 방향의 중앙에 정렬합니다. 페이지 미리보기가 정사각형이고 가장자리가 잘리지 않았는지 확인합니다.

2. 텍스트와 취약한 effects를 path로 변환

각 text object를 선택하고 Path → Object to Path를 실행합니다. 이렇게 하면 사용 중인 font가 없는 server가 다른 shape로 대체하는 일을 막을 수 있습니다.

반드시 유지해야 하는 dashed stroke나 outlined stroke에는 Path → Stroke to Path를 사용합니다. gradient, mask, filter는 꼭 필요한 경우에만 유지합니다. SVG가 서로 다른 환경에서 제공될 때 오류 발생 지점을 늘리기 때문입니다.

3. 이식성 높은 SVG 저장

File → Save As를 선택하고 Plain SVG를 고른 뒤 복사본을 favicon.svg로 저장합니다.

SVG를 변환하기 전에 문서 속성에 정사각형 viewBox가 설정되어 있는지, 아트워크가 외부 font, 연결된 bitmap 또는 stylesheet에 의존하지 않는지 확인합니다. 로고에 연결된 이미지가 들어 있다면 SVG 옆에 배치한 뒤 의도적으로 다시 연결하거나, 동등한 vector 요소로 대체하세요.

4. 512×512 PNG fallback 내보내기

File → Export PNG Image를 열고, 내보낼 영역으로 page를 선택한 다음 두 dimensions를 모두 512픽셀로 설정합니다. 배경은 transparent로 유지하고 favicon-512.png으로 내보내세요.

이 고해상도 PNG를 사용하면 converter가 작은 raster size를 만드는 데 필요한 pixel 수가 확보되므로, browser가 아주 작은 원본을 확대하도록 요청하지 않아도 됩니다.

반복적으로 같은 결과를 내보내려면 다음 명령을 실행할 수도 있습니다.

inkscape favicon.svg --export-type=png --export-area-page --export-width=512 --export-height=512 --export-filename=favicon-512.png

이 명령은 정사각형 page bounds를 기준으로 삼아 현재 작업 디렉터리에 512픽셀 PNG를 저장합니다.

5. Inkscape favicon 패키지 만들기

Mzu favicondl을 열어 favicon.svg 또는 favicon-512.png을 업로드하고, multi-size ICO를 생성한 뒤 다운로드합니다. ICO에는 16×16, 32×32, 48×48 이미지를 포함하는 구성을 권장합니다. 또한 180×180 PNG를 apple-touch-icon.png이라는 이름으로 생성하도록 요청하세요.

정확한 packaging 절차를 확인하려면 SVG to ICO guide를 참고하세요. favicon size guide에서는 추가 PNG 및 Apple용 size를 다룹니다.

HTML Standard는 rel='icon'을 사용자 인터페이스에서 페이지를 나타내는 외부 resource로 향하는 link로 정의합니다. 이 정의만으로 하나의 file format을 필수로 요구하지는 않으므로, 호환성을 위해 SVG와 ICO fallback을 함께 권장합니다.

6. 파일과 HTML 배포하기

favicon.ico, favicon.svg, apple-touch-icon.png을 사이트에서 제공할 수 있는 경로에 배치합니다. 다음과 같이 <head> 안에 link를 추가하세요.

<link rel='icon' href='/favicon.ico'>
<link rel='icon' href='/favicon.svg' type='image/svg+xml'>
<link rel='apple-touch-icon' href='/apple-touch-icon.png' sizes='180x180'>

배포 루트와 일치하는 경우에만 루트 기준 경로를 사용합니다. 하위 경로에서 제공되는 애플리케이션이라면 경로를 수정하거나 상대 경로로 변경하세요. ICO는 fallback으로 유지하고, SVG는 크기 조절이 가능한 master 파일로 사용합니다.

7. 실제 서버 응답 확인

사이트를 열고 hard reload를 수행한 뒤, Network 패널에서 각 아이콘 URL을 확인합니다. 요청이 상태 코드 200과 이미지 응답을 반환하는지 확인하세요. 사이트의 HTML 404 페이지가 반환되면 안 됩니다.

/favicon.svg를 직접 열어 SVG가 렌더링되는지 확인합니다. 기존 아이콘이 계속 표시된다면 배포를 변경하기 전에 브라우저가 새 URL을 가져왔는지 먼저 확인하세요.

터미널에서 ICO 응답도 확인할 수 있습니다:

curl -I https://example.com/favicon.ico

URL을 자신의 도메인으로 바꾼 다음 SVG와 PNG 파일에 대해서도 같은 확인을 반복합니다.

흔한 문제

  • 아트워크가 잘려 보입니다. 원본의 넓은 캔버스가 아니라 정사각형 페이지에서 export하세요.
  • 텍스트의 형태가 바뀝니다. 최종 SVG를 저장하기 전에 텍스트를 path로 변환하세요.
  • 연결된 asset이 로드되지 않습니다. 연결된 bitmap을 vector artwork로 교체하거나 안정적인 상대 경로에 패키징하고, 외부 stylesheet 의존성을 제거하세요.
  • 아이콘이 비어 있습니다. 16×16 크기로 확인한 뒤 실루엣, 간격, 대비를 단순화하세요.
  • 기존 아이콘이 계속 표시됩니다. cache를 탓하기 전에 HTML source와 Network 패널을 확인하세요.
  • 아이콘이 늘어나 보입니다. viewBox를 정사각형으로 유지하고 정사각형 PNG를 export하세요. sizes는 artwork의 크기를 조정하지 않습니다.

반복 가능한 워크플로 만들기

이제 반복해서 사용할 수 있는 Inkscape favicon 워크플로가 완성되었습니다. 정사각형 vector master 하나, outlined text, 이식 가능한 SVG, 512픽셀 PNG, ICO fallback, 명시적인 HTML link로 구성됩니다. 향후 export가 일관되도록 master SVG는 변경하지 마세요.
