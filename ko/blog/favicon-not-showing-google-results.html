Google 검색에 파비콘이 표시되지 않을 때 확인할 항목

브라우저 탭에서 파비콘이 정상적으로 보여도 Google 검색 결과에 반드시 표시되는 것은 아닙니다. 두 시스템은 별개이며, Google은 모든 가이드라인을 충족해도 표시를 보장하지 않는다고 명시합니다.

파일을 반복해서 바꾸기 전에 현재 Google 검색 파비콘 공식 문서(2026년 2월 4일 업데이트)에 따라 확인하세요.

1. 홈페이지 선언 확인

Google은 hostname별 홈페이지에서 파비콘 선언을 읽습니다. 다음과 같은 유효한 link가 있어야 합니다.

<link rel='icon' href='/favicon.ico'>

URL은 상대 또는 절대 경로를 사용할 수 있습니다. 루트 상대 경로는 관리가 편할 뿐 순위 조건이 아닙니다. 렌더링된 DOM만 보지 말고 실제 공개 홈페이지 소스에서 유지할 URL을 확인하세요.

2. 크롤링 접근과 응답 확인

Googlebot은 홈페이지를, Googlebot-Image는 아이콘 파일을 크롤링할 수 있어야 합니다. robots.txt, 인증, 보안 규칙이 두 URL을 막지 않는지 확인합니다.

  • 아이콘 URL을 직접 열어 HTML 오류가 아닌 이미지가 반환되는지 확인합니다.
  • 배포할 때마다 바꾸지 말고 URL을 안정적으로 유지합니다.
  • 정사각형 이미지를 사용합니다. 최소는 8×8이며 48×48보다 큰 이미지를 권장합니다.
  • 유효한 형식과 사이트를 대표하는 그림을 사용합니다.

3. 공식 요구사항과 추측 구분

공식 문서에는 3KB 제한, 정확히 48×48 파일을 써야 한다는 조건, manifest 우선의 고정 탐색 순서가 없습니다. 근거 없는 주장에 맞춰 구성을 바꾸지 마세요. 아이콘이 없다는 사실만으로 CDN이나 WAF가 Googlebot을 막았다고 단정하지 말고 실제 응답을 확인해야 합니다.

브라우저 아이콘 자체가 깨졌다면 먼저 일반 파비콘 문제 해결 가이드로 원본 문제를 해결하세요.

4. 재크롤링 요청 후 기다리기

공개 홈페이지를 수정한 뒤 Google Search Console URL 검사에서 홈페이지 색인 생성을 요청합니다. 재크롤링과 처리에는 며칠에서 몇 주가 걸릴 수 있습니다. 이 기간에 URL을 계속 바꾸지 마세요.

검증할 수 있는 것은 표시 자격입니다. 실제 표시 여부는 Google이 결정합니다.
