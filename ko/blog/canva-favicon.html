Canva 파비콘: 내보내기, 변환, 웹사이트에 연결

Canva 디자인은 에디터에서는 선명하게 보이지만, 브라우저 탭에는 여전히 기본 페이지 아이콘이 표시됩니다. 문제는 대개 export와 패키징 단계가 빠졌기 때문입니다. Canva 디자인은 정사각형 이미지와 브라우저에서 바로 사용할 수 있는 파일, HTML 참조로 변환되기 전에는 favicon으로 취급되지 않습니다.

Canva에서 export하기 전에

먼저 다음 항목을 준비하세요.

  • 정사각형 Canva 디자인. 넓은 배너를 crop해 만드는 대신, 별도의 1:1 캔버스를 사용하세요.
  • 깔끔한 PNG 마스터. 이 파일을 이후 생성할 모든 형식의 기준 원본으로 사용합니다.
  • 웹사이트 파일 접근 권한. 에셋을 업로드하고 전역 페이지 템플릿을 편집하려면 권한이 필요합니다.

에셋이 비즈니스 로고 전체라면, 계속하기 전에 가장 잘 알아볼 수 있는 심볼만 분리하세요. 로고에서 favicon을 만드는 workflow에서 이 디자인 단계를 별도로 다룹니다.

Canva favicon 제작 workflow

1. 정사각형 아이콘 준비

캔버스를 1:1로 설정하고 그래픽을 정사각형 배경 위에 두세요. 브라우저 탭 크기에서는 작은 글자와 가는 선이 사라지므로, 간결한 실루엣을 우선하고 한눈에 읽히지 않는 디테일은 제거하세요.

32 × 32 픽셀 크기로 미리 확인하세요. 심볼이 식별하기 어렵다면 export 전에 Canva에서 단순화하세요. 그러면 변환 후 디자인을 다시 손볼 필요가 없습니다.

2. 투명 PNG export

Download 또는 Share > Download을 선택하고 PNG를 고른 다음, 선택한 요소에 해당하는 경우 Transparent background를 활성화하세요. Canva는 디자인 요소에 따라 다른 옵션을 표시할 수 있으므로, 투명 배경 설정이 로고 레이어에 적용되는지 확인하세요.

사용자 지정 크기를 사용할 수 없다면, 가장 해상도가 높은 정사각형 PNG를 다운로드하고 Mzu favicondl에서 비율을 유지한 채 resize하세요. 한쪽 변만 늘어나거나 줄어들도록 resize하지 마세요. 원래 export한 파일을 마스터로 보관하세요.

3. 실용적인 아이콘 패키지 만들기

PNG를 Mzu favicondl에 업로드하고 사이트에 필요한 파일을 생성하세요. 다음과 같은 패키지를 시작점으로 삼으면 좋습니다:

  • 넓은 범위에서 fallback으로 사용할 수 있도록 favicon.ico에 16 × 16, 32 × 32, 48 × 48 레이어를 포함합니다.
  • 직접 적용할 수 있는 raster 아이콘 후보로 favicon-32.png을 준비합니다.
  • 홈 화면 바로가기용 apple-touch-icon-180.png을 준비합니다.
  • 사이트에서 web app manifest를 사용하는 경우 icon-192.png와 icon-512.png도 준비합니다.

Canva project나 design URL을 icon source로 사용하려고 하지 마세요. 브라우저는 사이트에서 제공되는 image file을 필요로 하며, multi-size ICO는 하나의 large PNG보다 더 넓은 범위에서 control할 수 있습니다.

4. 생성한 파일 업로드

생성한 file을 사이트의 public web directory에 배치합니다. root-level에 두면 path를 예측하기 쉽습니다.

  • /favicon.ico
  • /favicon-32.png
  • /apple-touch-icon-180.png
  • /icon-192.png와 /icon-512.png

각 URL을 새 탭에서 열어 image가 반환되는지 확인하세요. HTML error page가 표시되어서는 안 됩니다. 파일명의 대소문자도 확인해야 합니다. case-sensitive server에서는 /Favicon.ico와 /favicon.ico가 서로 다른 path로 취급될 수 있습니다.

5. HTML reference 추가

다음 element를 document의 <head> 안에 붙여 넣고, 사용하는 이름이 다르면 조정합니다. manifest를 만들지 않았다면 마지막 줄은 생략합니다.

<link rel='icon' href='/favicon.ico'>
<link rel='icon' type='image/png' sizes='32x32' href='/favicon-32.png'>
<link rel='apple-touch-icon' sizes='180x180' href='/apple-touch-icon-180.png'>
<link rel='manifest' href='/site.webmanifest'>

HTML Standard의 icon link-type 정의는 브라우저가 이러한 resource를 찾는 방식을 설명합니다. CMS를 사용한다면 tag를 공통 site template에 넣어 모든 page에 동일한 reference가 적용되도록 유지하세요. framework-specific markup은 HTML favicon 전체 가이드에서 확인하세요.

6. 실제 결과 확인

새 탭에서 홈페이지를 다시 로드한 다음 하위 페이지와 북마크를 열어 보세요. 브라우저의 Network 패널을 사용해 각 아이콘 URL이 성공적으로 응답하는지 확인합니다. 이전 아이콘이 계속 남아 있다면 hard reload를 시도해 보세요. 같은 URL에서 파일을 교체한 경우에는 favicon-v2.ico처럼 새로운 이름으로 게시하고 태그도 갱신해야 합니다.

모바일에서는 브라우저 탭과 ‘홈 화면에 추가’ 절차를 따로 확인해야 합니다. 브라우저 탭과 ‘홈 화면에 추가’ 기능은 서로 다른 리소스를 요청할 수 있으므로, 데스크톱 탭이 정상이라고 해서 모바일 바로가기를 올바르게 설정했다고 볼 수는 없습니다.

Canva favicon에서 흔히 겪는 문제

  • 마크 주변에 흰색 정사각형이 생김: PNG가 flatten되었거나 transparency가 활성화되지 않은 경우입니다. 다시 export한 다음 checkerboard 배경 위에 놓고 canvas를 확인하세요.
  • 탭 아이콘이 흐리거나 답답해 보임: 16–32 픽셀에서는 사라지는 세부 요소가 디자인에 포함되어 있습니다. 파일을 생성하기 전에 Canva에서 디자인을 단순화하세요.
  • 이전 아이콘이 계속 나타남: 브라우저가 기존 파일을 cache한 경우입니다. 배포 후 새 파일 이름 또는 버전 번호를 포함한 URL을 사용하세요.
  • 아이콘이 특정 페이지에서만 작동함: 태그를 global head나 layout이 아닌 개별 페이지 template에 추가했을 수 있습니다.
  • 아이콘 URL에 직접 접근하면 404가 반환됨: 파일이 게시 디렉터리 외부에 업로드되었거나 build 과정에서 누락되었거나, 대소문자가 일치하지 않는 경로로 참조된 경우입니다.

결론

깔끔한 Canva favicon은 정사각형 디자인, 투명 PNG, 변환된 아이콘 파일, 올바른 HTML, 실제 URL 확인으로 이어지는 간단한 파이프라인입니다. PNG master를 보관하고 파일 이름을 문서화하며, 브랜드 마크가 변경될 때마다 이 단계를 반복하세요. 준비되었다면 Mzu favicondl이 변환 단계를 처리해 줍니다. 덕분에 웹사이트에는 크기가 지나치게 큰 Canva export 파일 대신 사용할 수 있는 ICO 및 PNG asset이 전달됩니다.
