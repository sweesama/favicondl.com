VitePress 파비콘 설정: 단계별 가이드

VitePress 사이트를 배포한 뒤 브라우저 탭에 여전히 기본 VitePress 로고가 보이는 경험을 해보셨다면, 이는 흔한 일입니다. 많은 개발자가 public 폴더에 favicon.ico를 넣기만 하면 충분하다고 생각하지만, VitePress에서 아이콘을 제대로 연결하려면 추가 설정이 필요합니다. 이 가이드에서는 파일 배치부터 결과 확인까지 VitePress 사이트에 사용자 지정 favicon을 설정하는 정확한 단계를 안내합니다.

사전 준비

시작하기 전에 다음이 준비되어 있는지 확인합니다.

  • VitePress 프로젝트가 설정되어 있어야 합니다(버전 1.x 이상).
  • favicon 파일이 준비되어 있어야 합니다. ICO, PNG, SVG 중 하나를 사용할 수 있습니다. 파일을 만들어야 한다면 Mzu favicondl을 사용해 여러 크기의 favicon을 생성해 보세요.
  • VitePress 프로젝트의 config.js 또는 config.ts 파일에 대한 기본적인 이해가 필요합니다.

1단계: public 디렉터리에 favicon 파일 배치하기

VitePress는 내부적으로 Vite를 사용하므로 정적 자산은 프로젝트 루트의 public 디렉터리에 두어야 합니다. public에 있는 파일은 루트 경로로 제공되며 빌드 출력에 그대로 복사됩니다. 예를 들어 public에 favicon.ico를 두면 빌드 후 /favicon.ico에서 접근할 수 있습니다.

public 폴더가 없다면 생성하고 favicon 파일을 그 안에 넣습니다. PNG나 SVG 파일을 사용해도 되며, 파일 이름만 기억해 두면 됩니다.

your-project/
├── docs/
│   └── .vitepress/
│       └── config.js
├── public/
│   └── favicon.ico
└── package.json

참고: public 디렉터리는 VitePress 프로젝트 루트(package.json이 있는 위치)를 기준으로 합니다. docs 폴더를 사용하는 기본 구조라면 public 폴더는 docs 안이 아니라 프로젝트 루트에 있어야 합니다.

2단계: VitePress 설정에서 favicon 구성하기

VitePress에서는 설정 파일의 head 옵션을 통해 사이트의 <head> 태그를 정의할 수 있습니다. 여기에 <link rel="icon"> 태그를 추가합니다.

.vitepress/config.js(또는 .ts)를 열고 다음을 추가합니다.

import { defineConfig } from 'vitepress'

export default defineConfig({
  head: [
    ['link', { rel: 'icon', href: '/favicon.ico' }]
  ],
  // other config...
})

SVG favicon을 사용하는 경우 type을 지정할 수 있습니다:

head: [
  ['link', { rel: 'icon', type: 'image/svg+xml', href: '/favicon.svg' }]
]

이 설정은 VitePress가 모든 페이지의 <head>에 link 태그를 삽입하도록 합니다. href는 파일이 루트에서 제공되므로 슬래시(/)로 시작해야 합니다.

Step 3: Verify Your Favicon

설정 후 개발 서버(npm run docs:dev 또는 yarn docs:dev)를 실행하고 브라우저에서 사이트를 엽니다. 탭을 확인하면 favicon이 표시되어야 합니다. 표시되지 않으면 강력 새로고침(Ctrl+F5 또는 Cmd+Shift+R)으로 캐시를 우회해 보세요.

프로덕션의 경우 사이트를 빌드(npm run docs:build)하고 .vitepress/dist에 생성된 HTML을 검사합니다. <head> 섹션에서 <link rel="icon"> 태그를 찾아보세요.

Common Pitfalls

  • 잘못된 파일 경로: favicon을 프로젝트 루트의 public 대신 docs/public에 두면 복사되지 않습니다. 항상 루트 public 디렉터리를 사용하세요.
  • 선행 슬래시 누락: href: 'favicon.ico'(슬래시 없음)를 사용하면 중첩 라우트에서 문제가 발생할 수 있습니다. 항상 /favicon.ico를 사용하세요.
  • 브라우저 캐싱: 브라우저는 favicon을 적극적으로 캐시합니다. 업데이트 후 캐시를 지우거나 다른 파일명(예: favicon-v2.ico)을 사용하여 새로고침을 강제하세요. 캐시 문제에 대한 자세한 내용은 favicon not showing 체크리스트를 참고하세요.
  • SVG 지원: SVG favicon은 널리 지원되지만 일부 구형 브라우저에서는 표시되지 않을 수 있습니다. PNG 또는 ICO 대체 파일을 제공하는 것을 고려하세요. 자세한 내용은 SVG favicon 가이드에서 확인하세요.

Conclusion

VitePress에서 favicon을 설정하는 일은 파일을 어디에 두고 head 태그를 어떻게 구성해야 하는지 알기만 하면 간단합니다. 다음 단계를 따르면 브라우저 탭, 북마크, 검색 결과에서 사이트가 전문적인 모습을 갖추게 됩니다. 변경 사항을 적용할 때는 여러 브라우저에서 테스트하고 캐시를 지우는 것을 잊지 마세요. 완전한 favicon 솔루션을 원한다면 Mzu favicondl을 사용해 필요한 모든 크기와 형식을 생성하는 것을 고려해 보세요.
