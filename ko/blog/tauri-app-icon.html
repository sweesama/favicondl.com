Tauri 앱 아이콘: Windows, macOS, Linux 설정 가이드

Tauri 앱을 만들었는데 작업 표시줄에 여전히 기본 아이콘이 보이나요? 아니면 출시를 앞두고 독 아이콘이 일반 플레이스홀더라는 걸 깨달았나요? 파일을 어디에 두고 설정에서 어떻게 참조하는지만 알면 Tauri 앱 아이콘을 제대로 설정하는 일은 간단합니다. 이 가이드에서는 Tauri의 내장 아이콘 생성기와 tauri.conf.json 설정을 사용해 Windows, macOS, Linux에서 정확한 단계를 안내합니다.

사전 준비

시작하기 전에 다음을 확인하세요:

  • 이미 설정된 Tauri 프로젝트(v1 또는 v2).
  • Node.js와 npm 설치(또는 선호하는 패키지 관리자).
  • 정사각형 소스 이미지, 이상적으로는 투명 배경의 1024×1024 PNG. SVG도 작동하지만 생성기에는 PNG가 더 안전합니다.

고품질 소스 아이콘이 필요하다면 기존 로고나 favicon에서 Mzu favicondl을 사용해 만들 수 있습니다. 여러 크기의 깔끔한 PNG로 내보내 줍니다.

1단계: 아이콘 세트 생성

Tauri는 단일 소스 이미지를 받아 모든 플랫폼별 형식을 생성하는 CLI 명령을 제공합니다. Windows용 .ico, macOS용 .icns, Linux 및 모바일용 다양한 PNG입니다. 프로젝트 루트에서 다음을 실행하세요:

npm run tauri icon path/to/your-icon.png

Tauri v1을 사용 중이라면 명령은 역시 npm run tauri icon이지만 package.json 스크립트를 확인하세요. 생성기는 기본적으로 src-tauri/icons/에 파일을 씁니다. 32x32.png, 128x128.png, icon.icns, icon.ico 같은 파일이 보일 것입니다.

팁: 소스 이미지는 투명 배경과 명확한 실루엣을 가져야 합니다. 텍스트나 세밀한 디테일은 피하세요. 16×16이나 32×32에서는 살아남지 못합니다. 디자인 가이드는 favicon 디자인 팁을 참고하세요(동일한 원칙이 앱 아이콘에도 적용됩니다).

2단계: tauri.conf.json 설정

src-tauri/tauri.conf.json을 열고 bundle 섹션을 찾으세요. icon 아래에 생성된 아이콘의 경로를 나열합니다. Tauri v2는 v1과 구조가 약간 다르지만 개념은 같습니다.

Tauri v2의 경우:

{
  "bundle": {
    "icon": [
      "icons/32x32.png",
      "icons/128x128.png",
      "icons/128x128@2x.png",
      "icons/icon.icns",
      "icons/icon.ico"
    ]
  }
}

Tauri v1에서는 icon 배열이 tauri.bundle 아래에 위치합니다.

{
  "tauri": {
    "bundle": {
      "icon": [
        "icons/32x32.png",
        "icons/128x128.png",
        "icons/icon.icns",
        "icons/icon.ico"
      ]
    }
  }
}

경로가 src-tauri/를 기준으로 상대 경로인지 확인하세요. 아이콘을 다른 곳으로 옮겼다면 경로도 그에 맞게 수정해야 합니다.

3단계: 플랫폼별 동작 확인

각 OS는 목록에서 서로 다른 파일을 사용합니다. 중요한 점은 다음과 같습니다.

  • Windows: 실행 파일, 작업 표시줄, 시작 메뉴에 icon.ico를 사용합니다. ICO 파일에는 여러 크기(16, 32, 48, 256)가 포함되어야 합니다. Tauri 생성기가 이를 처리합니다.
  • macOS: Dock과 Finder에 icon.icns를 사용합니다. ICNS 형식은 최대 1024×1024까지 여러 해상도를 포함합니다.
  • Linux: 앱 런처와 창 관리자에 PNG 파일(일반적으로 32x32, 128x128, 128x128@2x)을 사용합니다. 일부 데스크톱 환경은 번들에서 icon.png도 읽습니다.

모바일(iOS/Android)용으로 빌드하는 경우 생성기가 적절한 에셋도 만들지만, 이 가이드의 범위를 벗어납니다.

4단계: 재빌드 및 테스트

설정을 업데이트한 후 앱을 다시 빌드하세요.

npm run tauri build

그런 다음 빌드된 실행 파일을 설치하거나 실행하세요. 작업 표시줄(Windows), Dock(macOS), 애플리케이션 메뉴(Linux)에서 아이콘이 표시되는지 확인하세요. Windows에서는 이전 아이콘이 남아 있을 경우 아이콘 캐시를 지워야 할 수 있습니다. 이는 알려진 특이 사항입니다. macOS에서는 Dock이 아이콘을 캐시하는 경우가 있는데, 로그아웃했다가 다시 로그인하면 해결됩니다.

흔한 함정

  • 설정의 잘못된 경로: 아이콘 파일이 존재하지 않으면 Tauri는 번들링에 실패합니다. 상대 경로를 다시 확인하세요.
  • ICO 크기 누락: ICO를 직접 만들 경우 16, 32, 48, 256픽셀 레이어를 포함해야 합니다. Tauri 생성기는 이를 올바르게 처리합니다.
  • 투명 배경 문제: Windows에서는 완전히 투명한 영역이 일부 상황에서 검게 보일 수 있습니다. 아티팩트가 보이면 단색 배경을 사용하세요.
  • 재빌드 누락: 아이콘을 변경하려면 전체 재빌드가 필요합니다. 핫 리로드는 네이티브 아이콘을 업데이트하지 않습니다.
  • macOS ICNS 형식: ICNS 대신 PNG를 제공하면 macOS가 이를 무시할 수 있습니다. 항상 생성된 icon.icns를 사용하세요.

결론

Tauri 앱 아이콘 설정은 세 단계로 이루어집니다: tauri icon으로 아이콘 세트를 생성하고, tauri.conf.json에서 파일을 참조한 뒤, 재빌드합니다. 내장 생성기를 사용하면 ICO와 ICNS 파일을 수동으로 만들 필요가 없습니다. 소스 이미지는 단순하고 정사각형으로 유지하고, 각 대상 플랫폼에서 아이콘을 확인하세요. 아이콘 형식과 모범 사례에 대해 더 알아보려면 favicon 모범 사례를 살펴보세요. 많은 원칙이 앱 아이콘에도 적용됩니다.
