Ghost CMS 파비콘 변경 방법: 2026년 프로 개발자 가이드

Ghost로 새 퍼블리케이션을 시작했다면, 브라우저 탭에 기본 하얀색 유령 아이콘이 떠 있을 겁니다. 귀엽긴 하지만, '방금 막 설치했어요'라고 광고하는 것과 같죠. 무거운 플러그인과 씨름해야 하는 WordPress 파비콘 설정과 달리, Ghost는 기본 아이콘 업데이트가 매우 깔끔합니다. 하지만 고급 설정은 철저히 숨겨져 있죠.

Stripe나 Toss의 기술 블로그가 탭을 어떻게 관리하는지 살펴보세요. 그들은 사용자의 OS가 라이트 모드든 다크 모드든 완벽하게 적응하는 선명하고 확장 가능한 SVG를 사용합니다. 반면 Ghost의 기본 관리자 패널은 정적인 PNG만 요구합니다. 2026년에 걸맞은 프로페셔널한 설정을 원한다면, 기본 UI를 우회하는 것을 항상 추천합니다.

기본 UI 방법부터 프로 수준의 코드 삽입까지, ghost cms favicon을 완벽하게 수정하는 방법을 정확히 알려드립니다.

Ghost CMS 파비콘 마스터하기

방법 1: 관리자 UI를 통한 빠른 수정

당장 오늘 사이트를 오픈해야 하고 다크 모드는 신경 쓰지 않는다면, 내장된 설정을 사용하세요.

  1. Ghost 관리자 대시보드에 로그인합니다.
  2. Settings > Design > Brand로 이동합니다.
  3. 'Publication icon' 업로드 필드를 찾습니다.
  4. 정사각형 PNG를 업로드합니다 (Ghost는 최소 60x60px를 권장하지만, 실제로는 512x512px를 사용해야 합니다).
  5. 'Save'를 클릭하고 사이트를 새로고침합니다.

방법 2: 프로 테마 코드 삽입 (권장)

문제는 관리자 UI가 고급 메타데이터를 제거한다는 것입니다. 색상이 변하는 SVG를 원한다면 사이트의 head에 직접 코드를 주입해야 합니다.

  1. 먼저 Mzu favicondl을 사용하여 모던 아이콘을 생성합니다.
  2. SVG 및 Apple Touch 아이콘을 서버나 빠른 CDN에 업로드하고 URL을 복사합니다.
  3. Ghost 관리자의 Settings > Code Injection으로 이동합니다.
  4. 'Site Header' 상자에 다음 2026년 모던 스택을 붙여넣습니다:
<link rel='icon' href='https://your-cdn.com/favicon.svg' type='image/svg+xml'>
<link rel='apple-touch-icon' href='https://your-cdn.com/apple-touch-icon.png'>

이렇게 하면 기본 PNG를 덮어쓰고 고해상도 디스플레이에서 선명한 벡터 그래픽을 제공합니다.

Ghost 특유의 주의사항

  • 강력한 캐싱: Ghost는 캐싱이 매우 강력합니다. 아이콘을 업데이트했는데 보이지 않는다면 여러분의 잘못이 아닙니다. 브라우저에서 파비콘 캐시 지우기를 강제로 실행해야 합니다.
  • 파일 크기 제한: UI를 통해 2MB짜리 거대한 로고를 업로드하지 마세요. 초기 렌더링 속도가 느려집니다.

오늘 당장 그 기본 유령 아이콘을 없애버리세요. 첫 탭에서부터 브랜딩이 확고할 때 독자들은 여러분의 퍼블리케이션을 훨씬 더 신뢰하게 될 것입니다.
