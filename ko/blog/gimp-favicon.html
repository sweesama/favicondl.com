GIMP로 멀티사이즈 favicon ICO 만들기

48픽셀 크기로 GIMP에서 내보낸 이미지는 모니터에서는 선명해 보여도 브라우저 탭에서는 흐릿한 정사각형이 될 수 있습니다. 해결책은 GIMP에서 16, 32, 48픽셀 크기의 별도 버전을 준비한 다음, 이를 하나의 multi-size favicon.ico로 패키징하는 것입니다. 이 GIMP favicon ICO 작업 흐름을 따르면 확장자만 변경한 PNG에 의존하지 않고 예측 가능한 파일을 만들 수 있습니다.

필수 준비 사항

  • GIMP에서 File > New, Image > Scale Image, File > Export As 명령을 사용합니다.
  • 정사각형 로고 또는 심볼을 준비합니다. 512 × 512픽셀 크기의 마스터 이미지를 사용하면 축소하기 전에 디자인을 단순화할 여유가 생깁니다.
  • 최종 패키징 단계에서 ImageMagick을 선택적으로 설치할 수 있습니다. 대신 브라우저에서 PNG 내보내기 파일을 변환하는 Mzu favicondl을 사용할 수도 있습니다.

favicon ICO를 단계별로 만들기

  1. 투명 배경의 마스터 이미지 만들기

    File > New를 선택하고 두 크기를 512 × 512로 설정한 다음 Fill with Transparency를 선택합니다. 로고를 가져오거나 GIMP에서 직접 마크를 그리세요. 작은 크기에서도 여백이 보이도록 주요 실루엣은 가운데 정사각형 안에 유지합니다.

    favicon은 로고 크기만 줄인 이미지가 아닙니다. 내보내기 전에 작은 글자, 가는 선, 그라디언트를 줄이는 것이 좋습니다. 크고 선명한 단일 형태가 일반적으로 더 잘 보입니다.

  2. 마스터 이미지에서 각 크기 만들기

    File > Duplicate로 마스터 이미지를 복제한 다음 Image > Scale Image를 선택합니다. 너비와 높이를 연결한 상태로 복제본 하나를 16 × 16, 다른 하나를 32 × 32, 나머지 하나를 48 × 48로 조정합니다. 각 복제본은 512픽셀 원본에서 크기를 줄여야 합니다. 16픽셀 버전을 확대하면 가장자리가 더 부드러워질 뿐입니다.

  3. 16픽셀 버전 다듬기

    16픽셀 복제본을 열고 View > Show Pixel Grid를 활성화합니다. 확대한 뒤 인접 픽셀과 합쳐져 흐려지는 세부를 제거하거나 마크의 정렬을 조정하세요. 32픽셀에서도 같은 과정을 반복하십시오. 32픽셀에서는 더 많은 디테일이 유지되지만, 약한 1픽셀 선은 여전히 사라질 수 있습니다.

  4. alpha 투명도 유지하기

    가져온 레이어에 alpha channel이 없다면 해당 레이어를 선택하고 Layer > Transparency > Add Alpha Channel을 선택합니다. 배경을 흰색으로 채우지 말고 투명하게 유지하세요. PNG 내보내기는 이러한 투명도를 보존하므로 ICO 인코더에 깨끗한 원본 이미지를 제공합니다.

  5. PNG 파일 세 개 내보내기

    File > Export As를 선택하고 icon-16.png를 입력한 다음 Export를 클릭합니다. 같은 방식으로 icon-32.png와 icon-48.png를 내보내되, 세 파일을 한 폴더에 보관하세요. PNG는 정확한 크기와 alpha channel을 보존하기 때문에 ICO 패키징용 소스로 사용하기 적합합니다.

  6. ICO 내보내기 또는 패키징하기

    GIMP의 ICO 내보내기를 사용하려면 48픽셀 복제본을 선택하고 File > Export As를 선택한 다음 favicon.ico를 입력하고 내보내기 옵션을 확인하세요. 크기 목록이 표시되면 16, 32, 48픽셀을 선택합니다. 목록이 표시되지 않으면 현재 캔버스만 포함될 수 있으므로 PNG 세 개를 직접 패키징해야 합니다.

    PNG 파일이 있는 폴더에서 다음 명령을 실행합니다.

    magick -background none icon-16.png icon-32.png icon-48.png favicon.ico

    명령이 convert로 제공되는 시스템에서는 magick 대신 convert를 사용하세요. 결과에는 세 가지 크기의 이미지가 담긴 하나의 ICO가 생성됩니다.

  7. 내장된 크기 확인하기

    ImageMagick을 설치했다면 magick identify favicon.ico를 실행하고 출력에 16x16, 32x32, 48x48 항목이 표시되는지 확인합니다. 누락된 크기가 있다면 해당 PNG를 GIMP에서 점검하고 패키징 명령을 다시 실행하세요. 또한 각 PNG를 크게 확대해 아이콘에 흰색 배경이나 새로 생긴 흐림진 가장자리가 없는지 확인합니다.

  8. ICO 배포하기

    favicon.ico를 사이트의 public 루트 디렉터리에 복사한 다음 문서의 <head>에서 다음과 같이 연결합니다.

    <link rel='icon' href='/favicon.ico' sizes='16x16 32x32 48x48'>

    HTML 표준은 아이콘 리소스를 연결하기 위해 rel='icon'을 정의합니다. 사이트가 하위 경로에 있다면 URL을 조정하십시오. 전체 마크업과 모바일 아이콘 변형은 웹사이트에 favicon 추가하는 방법을 참고하세요.

GIMP favicon ICO에서 흔히 겪는 문제

  • 한 가지 해상도만 포함되어 있습니다. 파일명으로 판단하지 말고 ICO 컨테이너를 확인하십시오. 16, 32, 48픽셀 세트는 브라우저를 위한 실용적인 기본 기준이며, favicon 크기 가이드에서는 다른 형식이 어떤 용도로 쓰이는지 설명합니다.
  • 작은 아이콘이 뭉개져 보입니다. 크기만 줄이는 것이 아니라 원본 그림을 단순화하십시오. 48픽셀에서는 괜찮아 보이는 세밀한 텍스트와 1픽셀 단위 디테일도 16픽셀에서는 뭉개질 수 있습니다.
  • 투명도가 사라집니다. 내보내기 전에 alpha channel을 추가하고, 흰색 또는 테마 색 배경으로 이미지를 합쳐 alpha channel을 없애지 마십시오.
  • 운영 중인 사이트에 기존 아이콘이 계속 남습니다. /favicon.ico가 HTML 오류 페이지가 아니라 ICO 파일을 반환하는지 확인하십시오. 이전 파일이 계속 캐시된다면 /favicon.ico?v=2처럼 버전이 지정된 URL로 배포하십시오.

결과를 예측 가능하게 만들기

원본 그림 준비와 컨테이너 패키징을 분리하십시오. GIMP으로 작은 크기별 렌더링을 직접 제어할 수 있으며, 패키징 단계에서는 favicon.ico에 어떤 해상도가 포함되는지 확실히 보장할 수 있습니다.

브라우저 기반 변환기를 사용하려면 GIMP에서 PNG로 내보낸 파일을 Mzu favicondl에 넣고, 사이트에 추가하기 전에 다운로드한 ICO를 확인하십시오.
