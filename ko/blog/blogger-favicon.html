블로그 favicon 설정 가이드: 5단계로 끝내기

로고를 업로드한 뒤에도 Blogspot 탭에 기본 Blogger 아이콘이 계속 표시된다면, 문제는 보통 업로드 단계와 실제 페이지에 반영되는 단계 사이에 있습니다. 이 가이드에서는 blogger favicon을 설정하고, 브라우저가 실제로 어떤 파일을 받는지 확인하며, Layout 패널만으로 해결되지 않을 때 theme HTML을 사용하는 방법을 설명합니다.

가장 빠른 방법은 Blogger의 Layout 화면을 이용하는 것으로, 몇 번의 클릭이면 됩니다. SVG를 사용하거나 아이콘 URL을 정확히 지정해야 하거나, theme에 이미 있는 충돌하는 선언을 교체해야 한다면 HTML 방식으로 진행하세요.

사전 준비: 시작하기 전에 필요한 항목

Blogger 블로그의 관리자 권한, 정사각형 이미지, 공개 페이지를 확인할 수 있는 도구가 필요합니다. HTML을 직접 편집하는 방식을 사용할 때는 각 아이콘 파일에 접근할 수 있는 공개 HTTPS URL을 준비하세요.

  • Admin access: Blogger 대시보드에 로그인해 관리하는 블로그를 여세요. Layout 또는 Themes controls에 접근하려면 편집기 권한이 필요합니다.
  • 정사각형 PNG: 512 × 512 원본을 사용하면 더 작은 파일을 내보낼 여유가 생깁니다. 다만 16 × 16 크기에서도 표시 형태가 선명한지 확인하세요. 플랫폼 크기 가이드에서 각 사용처에 중요한 크기를 확인할 수 있습니다.
  • 간단한 표시 이미지: 강한 실루엣과 적은 디테일을 권장합니다. 전체 워드마크를 축소하면 탭이 많은 환경에서는 읽기 어렵기 때문입니다.
  • 공개 asset URL: theme HTML을 사용할 경우 SVG, PNG 또는 ICO 파일을 HTTPS로 직접 응답하는 서비스에 호스팅하세요.

5단계로 Blogger favicon 추가하기

  1. Blogger의 Layout 화면을 엽니다. 로그인한 뒤 블로그를 선택하고, 대시보드 탐색 메뉴에서 Layout을 선택하여 Favicon 섹션까지 내려갑니다. 그 옆의 Edit을 클릭합니다. Favicon 섹션이 없다면 아래의 테마 HTML 방식으로 진행합니다.
  2. 아이콘을 업로드하고 저장합니다. 파일 선택기에서 PNG를 고른 뒤 미리보기를 확인하고 저장합니다. 탭에 축소 표시될 때 중요한 가장자리가 사라지지 않도록 원본 이미지는 정사각형으로 유지하세요.
  3. 공개 블로그를 엽니다. 저장한 뒤 새 탭에서 공개 홈페이지를 불러옵니다. 관리자 미리보기는 방문자에게 실제로 제공되는 화면을 그대로 나타내지 않으므로, 확인에는 공개 도메인을 사용하세요.
  4. 아이콘 요청을 확인합니다. 브라우저 개발자 도구를 열고 Network 탭을 선택한 다음 페이지를 새로고침합니다. favicon 또는 업로드한 파일 이름으로 필터링합니다. 일치하는 요청을 열어 요청이 성공했으며 HTML 오류 페이지가 아니라 이미지 파일을 반환하는지 확인합니다.
  5. 아이콘 선언 목록을 확인합니다. Console 탭을 열고 다음 코드를 실행합니다.
document.querySelectorAll(`link[rel~='icon']`).forEach((link) => {
  console.log(link.href, link.type, link.sizes.value);
});

이 출력에는 라이브 페이지가 노출하는 아이콘 후보가 모두 표시됩니다. 각 항목의 URL을 열어 업로드한 아이콘 이미지를 가리키는지 확인하세요.

테마 HTML에 명시적인 아이콘 링크 추가하기

Layout 패널을 사용할 수 없거나 자체 에셋을 호스팅하거나 SVG와 raster fallback을 함께 추가하려는 경우 이 방법을 사용합니다. Blogger에서 Themes를 열고 Customize 옆의 화살표를 누른 뒤 Edit HTML을 선택해, 닫는 &lt;/head&gt; 태그 바로 앞에 링크를 붙여 넣습니다.

먼저 현재 테마 마크업을 로컬에 복사해 저장하세요. HTML Standard는 rel='icon'을 통해 아이콘 관계를 정의하므로, 각 선언은 브라우저가 가져올 수 있는 리소스를 가리켜야 합니다.

&lt;link rel='icon' type='image/svg+xml' href='https://assets.example.com/favicon.svg'&gt;
&lt;link rel='icon' type='image/png' sizes='32x32' href='https://assets.example.com/favicon-32.png'&gt;
&lt;link rel='icon' href='https://assets.example.com/favicon.ico'&gt;

샘플 URL은 직접 접근할 수 있는 공개 HTTPS 주소로 교체하세요. 파일이 존재하지 않는 선언 줄은 삭제하고, 다른 아트워크를 가리키는 기존 사용자 정의 favicon 선언도 제거하세요. 테마를 저장한 뒤 공개 도메인을 새로고침하고 Console에서 다시 확인합니다.

Blogger favicon에서 자주 발생하는 문제

  • Favicon 설정 패널이 없는 경우: 이미지 위젯을 추가하는 대신 테마 편집기에서 명시적인 link tag를 사용하세요. asset URL은 HTML 페이지가 아니라 favicon 파일을 직접 반환해야 합니다.
  • 기존 favicon이 그대로 남는 경우: 파일을 다시 변경하기 전에 브라우저의 시크릿 창에서 실제 페이지를 테스트하세요. markup과 response가 올바르다면 나머지 cache 및 routing 상태는 favicon 문제 해결 체크리스트에서 확인할 수 있습니다.
  • 404 또는 HTML response가 반환되는 경우: 정확한 경로, 대소문자, 호스트 설정을 확인하세요. post page를 가리키는 favicon link는 이미지를 제공하지 않습니다.
  • 충돌하는 선언이 있는 경우: 이전 link가 방문자를 다른 파일로 연결할 수 있습니다. Console snippet을 다시 실행하고 의도한 favicon 스택 하나만 유지하세요.
  • 이미지가 잘 보이지 않는 경우: 디자인을 단순화하고 선명한 소형 PNG로 내보내세요. SVG가 렌더링되지 않는다면 그 옆에 PNG 또는 ICO fallback을 함께 두세요.

결과를 확인하고 적용하세요

안정적인 Blogger favicon은 두 가지를 충족해야 합니다. 실제 페이지의 head에 의도한 favicon이 노출되고, 해당 URL이 실제 이미지 파일을 반환해야 합니다. 두 조건을 모두 통과하면 방문자가 받는 페이지에 favicon이 올바르게 연결된 것입니다.
