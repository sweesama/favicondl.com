Squarespace Favicon이 Google에 표시되지 않습니까? 해결책

몇 주 전에 브랜드 아이콘을 업로드했는데, Google 검색 결과에는 Squarespace favicon이 나타나지 않는 상황입니다. 브라우저 탭을 확인하면 정상적으로 보이지만, Google 검색 결과를 보면 브랜드 아이콘이 있어야 할 자리가 비어 있습니다. 이러한 불일치는 Squarespace 사용자들에게 익히 알려진 문제입니다.

지연의 원인은 대체로 Google이 favicon을 크롤링하고 캐싱하는 방식과 Squarespace가 이를 서빙하는 방식 간의 차이에서 비롯됩니다. Squarespace는 정적 자산에 대해 동적 CDN을 사용하며, 이로 인해 Google의 색인 기대치와 불일치가 발생합니다.

빠른 해결 방법: Google Recrawl 강제 요청

favicon이 브라우저 탭에는 보이지만 Google 검색 결과에 누락된 경우, 가장 빠른 해결책은 Google이 홈페이지를 다시 크롤링하도록 요청하는 것입니다. Google은 favicon을 실시간으로 업데이트하지 않으며, 정기적인 indexing 과정에서 favicon을 수집합니다.

Google Search Console을 사용하여 root domain에 대한 indexing을 요청하세요. URL Inspection 도구에 홈페이지 URL을 입력합니다. 이미 페이지가 indexing되어 있다면, 'Request Indexing' 버튼을 클릭하세요. 이 작업은 Googlebot이 페이지 구조와 연결된 자산을 다시 평가하도록 트리거합니다.

이 작업을 수행하기 전에, Squarespace가 실제로 favicon link tag를 라이브 HTML에 삽입하고 있는지 확인해야 합니다. 게시된 사이트에서 우클릭 후 'View Page Source'를 선택하고, favicon을 검색하세요. static1.squarespace.com URL을 가리키는 tag가 보여야 합니다.

Google이 Squarespace Favicon을 무시하는 이유

recrawl을 요청했는데도 favicon이 여전히 표시되지 않는다면, Google이 favicon을 검증하는 방식을 살펴봐야 합니다. Google은 검색 결과의 favicon에 대해 공식 요구사항을 문서화해 두었습니다. Squarespace의 기본 구현 방식이 이러한 규칙과 충돌하는 경우가 있습니다.

이 플랫폼에서 가장 흔하게 발생하는 근본 원인은 다음과 같습니다:

  • CDN URL 불안정성: Squarespace는 업로드된 자산에 대해 동적 URL을 생성합니다. 사이트 설정에서 favicon을 재업로드하거나 변경하면, 기존 CDN URL이 완전히 바뀝니다. Google은 이전 URL을 캐싱하고 있다가 404를 만나면 아이콘을 검색 결과에서 제거합니다.
  • Root-level favicon.ico 누락: Googlebot은 전통적으로 사이트 root에서 favicon.ico 파일을 확인합니다. Squarespace는 업로드된 아이콘을 root domain에 배치하지 않고, 서브도메인 CDN에서 서빙합니다. Googlebot이 root를 먼저 확인하고 실패하면, CDN link를 indexing하는 데 지연이 발생할 수 있습니다.
  • Crawl budget 지연: Squarespace 사이트가 새로 생성되었거나 트래픽이 낮은 경우, Googlebot이 자주 재방문하지 않아 최근에 업로드한 아이콘을 적시에 발견하지 못할 수 있습니다.
  • 잘못된 파일 크기: Google은 정사각형 favicon을 요구합니다. Squarespace에 직사각형 로고를 업로드하면, 플랫폼이 이를 자르게 됩니다. 잘린 결과물이 48x48 픽셀보다 작으면, Google은 검색 결과용으로 거부합니다.

Squarespace Favicon 설정 확인

다시 크롤링을 요청하기 전에 업로드한 파일이 Google의 기준을 충족하는지 확인해야 합니다. Google은 최소 8x8 픽셀의 정사각형 이미지를 요구하지만, 48x48 픽셀 이상을 권장합니다. 이러한 요구사항에 대한 자세한 내용은 Google 검색 결과에 favicon이 표시되지 않는 문제에 대한 가이드를 참고하세요.

Squarespace에서 Design > Browser Icon으로 이동하여 업로드한 파일을 확인하세요. 투명 배경의 PNG를 업로드했다면, Google 검색 결과 페이지의 흰색 배경에 아이콘이 묻히지 않는지 확인해야 합니다. 어두운 배경이나 선명한 색상의 배경이 가시성에 가장 좋습니다.

현재 아이콘을 추출하여 크기를 확인하려면, Mzu favicondl을 사용하여 웹사이트 favicon 확인 방법을 활용할 수 있습니다. 이 도구는 Squarespace가 실제로 서빙 중인 파일을 가져오므로, 로컬에서 해상도와 포맷을 검사할 수 있습니다.

CDN Caching 함정 해결

Squarespace에서 가장 큰 장애물은 동적 CDN URL입니다. Squarespace 대시보드에서 favicon을 업데이트하면, 플랫폼은 고유 식별자가 포함된 새로운 정적 URL을 할당합니다. 이전 URL은 즉시 응답하지 않게 됩니다.

Google이 이전 favicon URL을 이미 캐싱한 경우, 다음 크롤링 시 해당 URL을 다시 가져오려고 시도합니다. 404 오류가 발생하면, Google은 검색 결과에서 favicon을 완전히 제거합니다. Googlebot이 페이지를 다시 크롤링하지 않는 한, HTML에서 새로운 link tag를 자동으로 검색하지 않습니다.

이 문제를 해결하려면, Google이 HTML 구조가 변경되었음을 인식하도록 해야 합니다. Squarespace에서 browser icon을 업데이트한 후 다음 단계를 수행하세요:

  1. CDN이 새 파일을 전역적으로 전파할 수 있도록 24시간 대기합니다.
  2. 페이지 소스를 검사하여 새 static1.squarespace.com URL이 존재하는지 확인합니다.
  3. Google Search Console에서 root domain의 indexing을 요청합니다.
  4. Googlebot이 새 HTML을 처리하고 새 CDN URL을 캐싱할 때까지 3~7일 대기합니다.

향후 Favicon 누락 방지

아이콘이 Google 검색에 표시되기 시작하면, 그 상태를 유지하고 싶을 것입니다. 성공적으로 설정된 후 favicon이 Google에서 사라지는 가장 흔한 이유는 Squarespace에서 테마를 변경하거나 이미지를 교체했기 때문입니다.

Squarespace에서 browser icon을 변경할 때마다 기존 CDN URL이 끊어집니다. Google은 결국 따라잡지만, 그 사이에 검색 결과에서 브랜드가 불완전하게 보이는 기간이 발생합니다. 부득이한 경우가 아니라면 favicon을 변경하지 마세요.

아이콘을 업데이트해야 한다면, 이전 파일과 동일한 크기를 유지하세요. 정사각형 PNG에서 직사각형으로 갑자기 변경하면 Squarespace가 일시적으로 깨진 link를 서빙할 수 있으며, Googlebot이 이를 캐싱할 수 있습니다.

모든 플랫폼에서 사이트 아이콘을 유지하는 방법에 대한 완전한 체크리스트는 favicon 모범 사례 가이드를 참고하세요. 장기 캐싱에 견디는 정확한 파일 크기와 포맷을 다루고 있습니다.

대기해야 할 때와 행동해야 할 때

Google의 indexing 파이프라인은 느립니다. Squarespace 사이트를 어제 막 게시했다면, favicon이 Google에 즉시 나타나지 않습니다. 초기 크롤링에 며칠이 소요되며, Google이 이미지를 처리하여 SERPs에 표시하는 데 추가 시간이 걸립니다.

사이트가 게시된 지 1주일이 지나지 않았다면, 기다리세요. Search Console의 URL Inspection 도구에서 페이지가 indexing되었는지 확인하세요. 페이지는 indexing되었지만 2주가 지나도 favicon이 여전히 누락되어 있다면, 위의 CDN 확인 단계를 수행하세요.

URL Inspection 도구에서 홈페이지가 전혀 indexing되지 않은 것으로 표시된다면, favicon도 표시되지 않을 것입니다. 이 경우 더 큰 indexing 문제를 먼저 해결해야 합니다. Squarespace 사이트는 설정에서 'Disable search engine indexing'이 활성화되어 있는 경우 Googlebot을 기본적으로 차단할 수 있습니다. Settings > SEO에서 'Hide from search engines' 토글이 꺼져 있는지 확인하세요.

Google에서 favicon 누락 문제를 해결하려면 인내심이 필요합니다. Squarespace의 CDN 아키텍처 특성상 영구적인 root-level favicon.ico 파일을 강제로 배치할 수 없으므로, Googlebot이 HTML link tag를 올바르게 읽도록 하는 데 의존해야 합니다. 소스 코드를 확인하고, recrawl을 요청한 후, 검색 엔진이 새 자산을 처리할 시간을 충분히 주세요.
