Wix 파비콘이 Google 검색 결과에 표시되지 않을 때 해결 방법

Wix favicon이 브라우저 탭에 보인다고 해서 Google 검색 결과에도 반드시 표시되는 것은 아닙니다. 실제 도메인에 올바른 설정이 배포되어 있고 Google이 홈페이지와 아이콘을 크롤링할 수 있어야 하며, 최종 표시는 Google이 결정합니다.

먼저 Wix 기본 favicon 설정을 사용하세요

처음부터 Custom Code를 추가할 필요는 없습니다. Wix 공식 가이드에 따르면 사용자 지정 favicon에는 Premium 플랜, 연결된 도메인, 이미 게시된 사이트가 필요합니다.

  1. 사이트 Dashboard에서 Settings를 엽니다.
  2. Website settings를 선택합니다.
  3. Favicon 아래의 Upload Image에서 파일을 적용합니다.
  4. 시크릿 창으로 실제 도메인을 열어 편집기 미리보기가 아니라 공개 사이트에 반영되었는지 확인합니다.

Wix는 SVG가 아닌 파일에 48×48, 96×96처럼 48픽셀 배수의 정사각형 크기를 안내합니다. 이는 Wix 업로드 규칙이며 Google의 보편적인 최소 크기와는 다릅니다.

Google이 사용할 수 있는 상태인지 확인하세요

Google Search 공식 favicon 문서는 홈페이지에 지원되는 rel 값으로 아이콘을 선언하고 홈페이지와 favicon 파일을 모두 크롤링 가능하게 해야 한다고 설명합니다. Wix 설정은 일반적으로 이 태그를 생성하므로 실제 HTML에서 태그가 빠진 것을 확인하기 전에는 중복 태그를 추가하지 마세요.

Google의 최소 조건은 정사각형 8×8픽셀이며, 48×48보다 큰 이미지를 권장합니다. favicon URL은 안정적으로 유지해야 하고, 모든 조건을 만족해도 표시가 보장되지는 않습니다.

실제 공개 페이지를 점검하세요

  1. 홈페이지 소스에서 rel='icon' 등의 선언을 찾습니다.
  2. 아이콘 URL을 직접 열어 로그인 없이 이미지가 반환되고 404나 HTML 오류 페이지가 아닌지 확인합니다.
  3. robots 설정이 Googlebot 또는 Googlebot-Image를 차단하지 않는지 확인합니다.
  4. 이전 아이콘을 가리키면 Wix에서 다시 업로드하고 실제 도메인 반영을 확인합니다.

기다리기 전에 favicon 검사 가이드로 링크와 파일 상태를 확인할 수도 있습니다.

재크롤링을 요청한 뒤 처리 시간을 기다리세요

실제 홈페이지가 올바르면 Google Search Console의 URL 검사에서 홈페이지 색인 생성을 요청합니다. 이는 즉시 새로 고치는 명령이 아닙니다. Google은 재크롤링과 처리에 며칠에서 몇 주가 걸릴 수 있다고 안내합니다.

  • 편집기 미리보기만으로 판단하지 마세요.
  • 48×48을 Google의 최소 요구사항으로 쓰지 마세요.
  • 시험할 때마다 URL을 바꾸지 마세요.
  • 몇 분 또는 고정 일수 안에 표시된다고 약속하지 마세요.
  • 검사 없이 중복 favicon 태그를 추가하지 마세요.

권장 순서

Wix Website settings에서 업로드하고, 공개 홈페이지와 이미지 URL을 확인하고, Search Console에서 재크롤링을 요청한 뒤 정상 처리 기간을 기다리세요. 모두 정상이라면 올바른 설정을 반복해서 바꾸기보다 계속 모니터링하는 편이 낫습니다.
