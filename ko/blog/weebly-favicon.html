Weebly favicon 추가 및 교체 7단계 가이드

Weebly 사이트를 브라우저 탭에 열었을 때 아직 일반 지구본이나 이전 로고가 표시된다면, 이 가이드를 활용하세요. Weebly favicon을 설정하려면 업로드한 이미지, 게시된 페이지, visitors에게 제공되는 실제 아이콘 URL이 서로 맞아야 합니다. 테마 파일을 직접 수정하지 않고도 기본 설정을 완료할 수 있습니다.

사전 준비

시작하기 전에 다음 세 가지 항목을 준비하세요.

  • Editor 권한: Weebly에서 사이트를 열고 변경 사항을 게시할 수 있어야 합니다.
  • 정사각형 원본 이미지: 업로드용으로는 512 × 512 PNG를 권장합니다. 단순한 도형과 뚜렷한 대비를 사용하면 전체 워드마크보다 작은 크기에서도 잘 보입니다.
  • 실제 사이트 URL: 다른 탭에 열어 두면 editor의 preview와 visitors에게 실제로 제공되는 화면을 구분할 수 있습니다.

Mzu favicondl을 사용하면 artwork를 favicon에 적합한 파일로 자르거나 변환할 수 있습니다. raster size를 선택해야 한다면 favicon size guide에서 플랫폼별 일반적인 사용 사례를 확인하세요.

7단계로 Weebly favicon 추가하기

1. 깨끗한 정사각형 아이콘 준비하기

이미지 editor 또는 favicon converter에서 로고를 열고, 아이콘이 작아 보이게 만드는 여백을 제거하세요. 투명 또는 단색 배경의 정사각형 PNG로 export한 다음 16 × 16 pixels로 확인하세요. 도형이 사라질 정도로 작다면 더 단순하게 정리하세요.

원본 artwork도 보관하세요. PNG를 editor에 업로드하는 데 사용할 수 있으며, 나중에 custom icon stack이 필요하다면 SVG나 여러 크기의 ICO 파일을 생성할 수도 있습니다.

2. Weebly 사이트 설정 열기

Weebly에 로그인해 사이트의 editor를 연 다음 Settings를 선택하고 Site Settings로 이동하세요. Basic을 열어 Favicon 업로드 control을 찾으세요. editor의 다른 위치에 표시된다면 로고나 thumbnail 입력란이 아니라 Favicon이라고 표시된 control을 사용하세요.

control을 찾을 수 없다면 계속 진행하기 전에 사이트 소유자에게 plan과 editor 권한을 확인해 달라고 요청하세요. 이렇게 하면 Weebly의 기본 업로더를 아직 사용할 수 있는 상태에서 별도의 아이콘 시스템이 추가되는 일을 막을 수 있습니다.

3. 이미지 업로드하기

Upload를 선택하고 정사각형 PNG를 선택한 다음 preview가 표시될 때까지 기다리세요. 아이콘이 큰 빈 테두리 안에 들어 있지 않고 프레임을 채우는지 확인한 후 사이트 설정을 저장하세요. 실제 PNG 파일을 사용해야 합니다. 다른 이미지 형식의 파일명만 바꾸면 PNG로 변환되는 것은 아닙니다.

4. 변경 사항 게시

Weebly 편집기에서 Publish를 클릭하고 사이트가 라이브에 반영될 때까지 기다립니다. 새 탭에서 라이브 사이트 주소를 여세요. 편집기의 preview만으로는 방문자가 새 favicon을 가져올 수 있다는 사실을 확인할 수 없습니다.

5. 라이브 favicon 링크 확인

라이브 페이지에서 브라우저 developer tools를 열어 문서의 <head>를 검사합니다. 다음과 같은 favicon declaration을 찾아보세요.

<link rel='icon' type='image/png' href='https://example.com/favicon.png'>

example.com 경로는 placeholder입니다. 기본 업로드를 사용하면 URL은 Weebly가 생성한 주소가 됩니다. rel='icon' 링크는 HTML Standard에 설명된 외부 favicon 참조를 위한 표준 HTML 방식입니다. 이를 통해 브라우저가 요청할 후보를 제공합니다.

6. 필요할 때만 고급 변형 추가

일반적인 browser tab 아이콘에는 기본 업로더만으로 충분합니다. 별도 에셋을 관리하고 있으며 Weebly 요금제에서 advanced site settings의 Head Code 필드를 사용할 수 있다면, 더 명시적인 favicon 구성을 추가할 수 있습니다.

<link rel='icon' href='/favicon.ico' sizes='16x16 32x32 48x48'>
<link rel='icon' type='image/png' href='/favicon-32.png' sizes='32x32'>
<link rel='icon' type='image/svg+xml' href='/favicon.svg'>
<link rel='apple-touch-icon' href='/apple-touch-icon.png'>

모든 예시 경로를 실제로 접근 가능한 URL로 바꾸세요. 기본 업로드만으로 충분한 경우에는 이러한 태그를 추가하지 마세요. 또한 새로운 구성을 추가하기 전에 기존 custom 구성을 제거해야 합니다.

7. 응답과 탭 확인

라이브 페이지를 새로 고친 다음 private window로 전환해 브라우저의 Network panel에서 favicon 요청을 확인합니다. 요청 결과는 404 Not Found가 아니라 이미지여야 하며, 탭 또는 bookmark에 업로드한 아이콘이 표시되어야 합니다.

URL을 확인하기 어렵다면 새 탭에 정확한 favicon URL을 붙여넣어 보세요. HTML error page가 아니라 이미지 파일이 나타나야 합니다. 기존 favicon을 교체한 뒤에는 browser caching을 감안하거나 새로 연 private window에서 테스트하십시오.

일반적인 실수

  • 편집기에서는 변경했지만 사이트를 게시하지 않은 상태입니다. 다시 게시한 다음, 게시되지 않은 미리보기 대신 실제 라이브 사이트 주소를 불러오세요.
  • 기존 아이콘이 아직 캐시된 상태입니다. 시크릿 창에서 테스트하고 페이지를 hard-reload하세요. 라이브 페이지의 HTML과 이미지가 정상이라면 favicon 문제 해결 체크리스트를 따르세요.
  • 아이콘 URL이 404를 반환합니다. 개발자 도구에서 href를 확인한 뒤 직접 열어 보세요. 파일이 /favicon.ico에 있다고 가정하지 말고, 라이브 페이지에 표시된 실제 URL을 사용하세요.
  • 아이콘 태그가 여러 개 있어 설정 과정을 디버그하기 어렵습니다. 오래된 사용자 정의 코드나 중복 업로드를 제거한 다음, 의도적으로 추가한 선언 한 세트만 유지하세요.
  • 아이콘의 형태가 지나치게 복잡합니다. 로고의 주요 심볼을 기준으로 다시 제작하고, 작은 텍스트를 제거한 뒤 16-pixel 크기로 렌더링되는 모습을 확인하세요.
  • Favicon 필드가 없습니다. 사이트 소유자가 사이트 설정에 접근할 수 있고, 사용자의 계정에 사이트 변경 권한이 있는지 확인하세요.

최종 확인

Weebly favicon 설정이 완료된 상태는 편집기에 의도한 아이콘이 표시되고, 사이트가 게시되었으며, 라이브 페이지의 head에 유효한 아이콘 링크가 포함되어 있고, 해당 URL을 요청하면 이미지 파일이 반환되는 경우입니다. 다음번 교체 때 크기나 경로 문제가 다시 발생하지 않도록 정사각형 원본 PNG와 생성된 variant를 함께 보관하세요.
