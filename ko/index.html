왜 Mzu favicondl인가요?

간단하고, 빠르고, 안정적인 파비콘 가져오기.

초고속

최적화된 서비스로 밀리초 만에 파비콘을 가져옵니다.

다양한 크기

홈에서 32/128px 가져오기. 도구에서 16~512px 생성.

개발자 친화적

바로 연동할 수 있는 복사용 URL 템플릿과 HTML 코드 조각.

가장 간단한 파비콘 다운로더 & 추출기

Mzu favicondl은 모든 웹사이트의 파비콘을 즉시 추출하고 다운로드할 수 있는 무료 온라인 도구입니다. 도메인 이름 또는 URL을 입력하고, 원하는 아이콘 크기를 선택하기만 하면 됩니다. 가입 불필요, 설치 불필요, 제한 없음.

링크 미리보기를 만드는 웹 개발자든, 브랜드 자료를 모으는 디자이너든, 그저 어떤 사이트의 아이콘이 궁금한 분이든, 이 파비콘 추출기가 모두 해결해 드립니다. 16×16부터 512×512픽셀까지 지원하며, 다운로드할 때마다 바로 복사해 쓸 수 있는 HTML 코드와 직접 URL이 함께 제공되어 프로젝트에 쉽게 넣을 수 있습니다. 파비콘("favorite icon"의 줄임말)은 브라우저 탭, 북마크, 검색 결과에 표시되는 작은 아이콘으로, 브랜드 인지도와 사용자 경험에 중요한 역할을 합니다.

파비콘 표준에 대해 더 알아보려면 MDN Web Docs를 참고하세요.

고품질 파비콘이란?

고품질 파비콘은 예전의 16x16 ICO 형식에 머물지 않습니다. 최신 애플리케이션, 소셜 미디어 링크 미리보기, AI 에이전트에는 180px, 256px, 512px 같은 고해상도 아이콘이 필요하며, 이는 주로 SVG 벡터, 웹 앱 매니페스트, Apple touch icon에서 얻습니다. Mzu favicondl은 가능하면 오래된 기본 파비콘보다 이런 고품질 소스를 우선합니다.

AI 에이전트와 개발자를 위한 연동 가이드

스크립트, 도구, 워크플로에 파비콘 가져오기를 연동할 수 있는 복사용 예제입니다.

cURL 
curl -L "https://favicondl.com/api/favicon?domain=github.com&size=32&format=redirect"
JavaScript (Fetch) 
async function getFavicon(domain, size = 128) {
  const url = `https://favicondl.com/api/favicon?domain=${domain}&size=${size}`;
  const response = await fetch(url);
  const blob = await response.blob();
  return URL.createObjectURL(blob);
}
Python (Requests) 
import requests

url = "https://favicondl.com/api/favicon?domain=stripe.com&size=256"
response = requests.get(url, allow_redirects=True)
with open("icon.png", "wb") as f:
    f.write(response.content)

모든 웹사이트의 파비콘을 다운로드하는 방법

  1. 도메인이나 URL을 입력합니다. 이 페이지 맨 위 입력란에 github.com 같은 도메인을 입력하거나 페이지 주소를 그대로 붙여 넣으세요. https://와 www.는 생략해도 됩니다.
  2. 크기를 고릅니다. 16, 32, 48, 64, 128 px 중에서 선택할 수 있습니다. 미리보기에는 찾은 아이콘 중 가장 좋은 것이 표시되고, 그 원본 크기도 함께 나옵니다. 선택한 크기로 내보내기는 기본으로 켜져 있으며 PNG를 선택한 크기에 정확히 맞춥니다. 끄면 원본 해상도 그대로 저장됩니다. 고른 32나 64 등이 사이트가 올린 아이콘보다 크면, 확대되어 흐려 보일 수 있다는 짧은 안내가 나옵니다.
  3. 다운로드하거나 복사합니다. 다운로드를 누르면 PNG로 저장되고, 바로 쓸 수 있는 <link> HTML 태그나 원본 파일의 직접 URL을 복사할 수도 있습니다.

이게 전부입니다. 계정도, 브라우저 확장 프로그램도, 업로드도 필요 없습니다. PNG가 아닌 원본 .ico나 .svg 파일이 필요하다면 결과에 표시되는 직접 URL을 열어 저장하세요.

파비콘 추출기가 찾는 아이콘

아이콘을 하나만 두는 웹사이트는 드뭅니다. 일반적인 사이트에는 전통적인 favicon.ico, PNG 몇 개, iPhone용 Apple touch icon, Android용 웹 앱 매니페스트가 있습니다. favicondl의 파비콘 추출기는 일반 브라우저처럼 홈페이지를 불러오고(www에서 기본 도메인으로 가는 리디렉션 등도 따라갑니다), 페이지 HTML의 모든 <link rel="…icon…"> 태그를 읽고, 연결된 매니페스트를 열어 그 안의 아이콘을 모으며, 잘 알려진 경로인 /favicon.ico와 /apple-touch-icon.png도 확인합니다. 각 파일은 실제로 내려받아 정말 이미지인지 확인하고, 실제 픽셀 크기를 측정합니다.

아이콘 종류선언 위치일반적인 크기용도
ICO 파비콘/favicon.ico 또는 rel="icon" / rel="shortcut icon"16×16, 32×32, 48×48 (한 파일에 여러 크기가 들어 있는 경우가 많음)브라우저 탭, 북마크, 구형 브라우저

SVG 파비콘rel="icon" type="image/svg+xml"확대·축소 가능한 벡터어떤 크기에서도 선명하고 다크 모드에 맞출 수 있음
Apple touch iconrel="apple-touch-icon" 또는 /apple-touch-icon.png180×180iPhone·iPad 홈 화면 바로가기
매니페스트 아이콘rel="manifest" (site.webmanifest, manifest.json)192×192, 512×512Android 홈 화면과 설치된 웹 앱

사이트에서 이 중 아무것도 찾을 수 없으면(자동 요청을 차단하거나 JavaScript로만 아이콘을 불러오는 경우 등) Google의 공개 파비콘 서비스로 대체하므로, 크기는 작더라도 쓸 수 있는 이미지는 받을 수 있습니다. 어떤 크기가 어디에 쓰이는지는 파비콘 크기 가이드에서 자세히 설명합니다.

가장 높은 해상도의 아이콘을 받는 방법

추출기는 찾은 아이콘의 순위를 매겨 가장 선명한 것을 먼저 돌려줍니다. 확대해도 깨지지 않는 풀컬러 SVG가 1순위입니다. 그다음은 실제로 측정한 크기가 가장 큰 정사각형 이미지로, 보통 512px나 192px 매니페스트 아이콘 또는 180px Apple touch icon입니다. 전통적인 ICO 파일은 너비가 16~32픽셀에 불과한 경우가 많아 대개 마지막입니다. Safari의 단색 mask 아이콘도 낮은 순위입니다. 찾은 다른 크기도 함께 보여 주므로 다른 것을 골라도 됩니다.

  • 원본 크기를 유지하세요. 선택한 크기로 내보내기를 끄면 다운로드한 PNG가 원본 파일의 해상도를 그대로 유지합니다.
  • 확대하면 흐려 보일 수 있습니다. 16px 아이콘을 32px나 128px로 키워도 디테일은 늘지 않습니다. 내보내기 크기가 원본보다 크면 미리보기가 알려 줍니다. API의 size는 그 크기의 정사각형(16, 32, 64, 128, 256, 512)을 그대로 반환하고, 래스터를 키운 경우 upscaled가 true입니다.
  • 아이콘 출처를 확인하세요. API JSON의 source는 아이콘이 사이트 자체(html, manifest, direct)에서 왔는지, 대체 서비스(google_s2 또는 duckduckgo)에서 왔는지 알려 줍니다. nativeWidth와 nativeHeight는 원본 픽셀이며 SVG는 null입니다. size를 생략하면 원본 파일입니다.
  • 아이콘이 아니라 로고가 필요하신가요? 파비콘은 원래 아주 작게 보이도록 만든 것입니다. 인쇄물이나 마케팅에는 해당 회사의 공식 보도 자료 키트나 브랜드 페이지를 이용하세요.

파비콘 일괄 다운로드

한 줄에 하나씩 도메인을 최대 100개까지 붙여 넣고, 모든 파비콘을 ZIP 하나로 또는 개별 이미지로 받으세요. 파일 이름은 도메인이나 번호로 지정할 수 있습니다.

무료 파비콘 API

GET 요청 한 번으로 URL만 넣으면 어떤 사이트의 아이콘이든 가져옵니다. API 키도 가입도 필요 없으며, 이미지로 리디렉션하거나 아이콘 URL과 출처가 담긴 JSON을 돌려줍니다.

자주 묻는 질문

웹사이트의 파비콘을 다운로드해도 괜찮나요?

파비콘은 공개된 파일이라 사이트를 열 때마다 모든 브라우저가 내려받습니다. 저장하는 것도 기술적으로는 다르지 않습니다. 다만 아이콘은 대개 운영자의 로고나 상표의 일부입니다. 링크가 어느 사이트로 연결되는지 보여 주는 용도(북마크, 대시보드, 링크 미리보기 등)로 쓰는 것은 흔한 일이지만, 자신의 브랜드로 쓰는 것은 안 됩니다. 확실하지 않다면 해당 회사의 브랜드 가이드라인을 확인하세요. 이는 일반적인 정보이며 법률 자문이 아닙니다.

다운로드한 파비콘이 흐릿한 이유는 무엇인가요?

대개 사이트가 작은 아이콘만 제공하거나, 내보낼 때 이미지가 확대된 경우입니다. 선택한 크기로 내보내기를 끄면 원본 해상도가 유지됩니다. 16px이나 32px ICO만 있다면 어떤 도구로도 없는 디테일을 만들어 낼 수 없습니다.

파비콘을 한꺼번에 다운로드할 수 있나요?

네. 파비콘 일괄 다운로드 도구는 한 번에 최대 100개 도메인을 처리하며, 결과를 ZIP 파일 하나로 또는 개별 이미지로 받을 수 있습니다.

무료 파비콘 API가 있나요?

있습니다. https://favicondl.com/api/extract?url=github.com은 찾은 아이콘 중 가장 좋은 것으로 바로 리디렉션하므로 <img> 태그에 그대로 쓸 수 있습니다. &format=json을 붙이면 아이콘 URL과 출처를 대신 돌려줍니다. 키나 계정은 필요 없으며, 결과는 사용하는 쪽에서 캐시해 주세요. 자세한 내용은 API 문서를 참고하세요.

favicon grabber, fetcher, extractor는 어떻게 다른가요?

실질적인 차이는 없습니다. "favicon grabber", "favicon fetcher", "favicon finder", "favicon extractor"는 같은 종류의 도구를 부르는 다른 이름으로, 웹사이트를 입력하면 그 사이트의 아이콘을 찾아 내려받아 줍니다. 이 파비콘 다운로더는 이 모든 기능을 합니다.

왜 어떤 사이트는 지구본 모양의 기본 아이콘이 나오거나 파비콘이 없나요?

자동 요청을 차단하거나, 로그인 또는 봇 확인 뒤에 있거나, 페이지가 로드된 뒤 JavaScript로 아이콘을 추가하거나, 아예 파비콘이 없는 사이트가 있기 때문입니다. 이런 경우 Google 파비콘 서비스로 대체하는데, 작은 이미지나 기본 지구본 아이콘이 나올 수 있습니다.

어떤 파일 형식으로 받게 되나요?

다운로드 버튼은 어디서나 쓸 수 있는 PNG로 저장합니다. 원래 형식 그대로가 필요하다면, 결과에 나오는 직접 URL이 웹사이트의 원본 파일(ICO, PNG, SVG, WebP 등)을 가리킵니다.

localhost나 비공개 사이트에서도 되나요?

안 됩니다. 추출기는 저희 서버에서 실행되므로 공개 웹사이트에만 접근할 수 있습니다. localhost, 사내 네트워크, 로그인이 필요한 페이지는 볼 수 없으며, 이미지 프록시도 사설 주소는 거부합니다.

제 이미지를 파비콘으로 만들 수 있나요?

네. 도구 페이지의 이미지→파비콘 도구는 로고를 여러 크기의 PNG와 ICO 파일로 변환하고, 웹 매니페스트와 사이트에 붙여 넣을 HTML 태그까지 함께 ZIP으로 묶어 줍니다. 이미지는 브라우저 안에서 처리되며 업로드되지 않습니다.

제 사이트에는 어떤 크기의 파비콘이 필요한가요?

대부분의 사이트는 브라우저용 SVG 또는 32×32 PNG, 180×180 Apple touch icon, 그리고 192×192와 512×512 매니페스트 아이콘이면 충분합니다. 각각은 파비콘 크기 가이드에서 설명합니다.

더 많은 도구가 필요하신가요?

이미지를 파비콘으로 변환하고 일괄 처리하거나 PNG to ICO 변환.
