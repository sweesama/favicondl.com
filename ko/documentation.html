무료 파비콘 API

GET 요청 한 번으로 URL만 넣으면 모든 웹사이트의 파비콘을 가져옵니다. API 키도, 가입도 필요 없습니다.

빠른 시작

favicondl 파비콘 API는 GET 요청 한 번으로 어떤 도메인이나 URL이든 그 사이트의 파비콘으로 바꿔 줍니다. API 키, 계정, SDK가 모두 필요 없습니다. size(16–512, 흔히 16, 32, 64, 128, 256, 512)를 넘기면 정확히 그 한 변의 정사각형 PNG가 옵니다.

<img src="https://favicondl.com/api/extract?url=github.com&size=32" width="32" height="32" alt="GitHub 파비콘">

size를 생략하면 원본 파일입니다. 더 작은 래스터는 확대되어 흐려 보일 수 있습니다. SVG는 요청한 크기로 래스터화합니다. 이미지 응답의 X-Favicon-Native-Size와 X-Favicon-Upscaled가 확대 여부를 알려 줍니다.

JSON을 요청하면 어떤 파일을 찾았고 어디서 가져왔는지 확인할 수 있습니다.

iconUrl은 웹사이트의 원본 파일입니다. 받는 이미지는 proxyUrl입니다. size를 생략하면 원본이고, size를 주면(예: &size=32) 정확히 그 크기의 정사각형 PNG입니다. Access-Control-Allow-Origin: *가 붙습니다.

width와 height는 측정한 원본입니다(SVG는 null). size가 있으면 outputWidth와 outputHeight가 그 값과 같고, nativeWidth / nativeHeight는 원본 픽셀이며, 래스터를 키운 경우에만 upscaled가 true입니다. 그때 PNG는 흐려 보일 수 있습니다. candidates는 검증된 다른 아이콘을 최대 8개 담습니다. Google이나 DuckDuckGo로 대체되면 비어 있습니다.

API가 아이콘을 고르는 방식

  1. 홈페이지를 일반 브라우저처럼 요청하고 리디렉션(www ↔ 기본 도메인 포함)을 따라갑니다. 아이콘 관련 <link>를 모두 읽습니다: icon, shortcut icon, apple-touch-icon, apple-touch-icon-precomposed, mask-icon. 상대 경로와 프로토콜 상대 경로(//cdn…)는 최종 페이지 URL이나 <base> 태그를 기준으로 해석합니다(source: "html").
  2. 웹 앱 매니페스트: 페이지에 연결된 매니페스트를 열어 아이콘 목록을 읽습니다. 192px, 512px 아이콘은 대개 여기에 있습니다(source: "manifest").
  3. 잘 알려진 경로인 /favicon.ico와 /apple-touch-icon.png도 시도합니다(source: "direct").
  4. 모든 후보를 내려받아 확인합니다: 내용이 정말 이미지(PNG, ICO, SVG, WebP, JPEG, GIF 등)인지 확인하고, 파일 이름을 믿는 대신 실제 픽셀 크기를 측정합니다.
  5. Google 파비콘 서비스, 그다음 DuckDuckGo는 사이트의 아이콘을 하나도 쓸 수 없을 때만, 요청한 size로 사용합니다(source: "google_s2" 또는 "duckduckgo").

검증된 후보는 가장 선명한 파일이 선택되도록 순위를 매깁니다. 풀컬러 SVG가 먼저이고, 그다음이 가장 큰 정사각형 PNG/ICO/WebP입니다. Safari의 단색 mask-icon과 maskable로만 표시된 매니페스트 아이콘은 일반 파비콘과 모양이 달라 낮은 순위를 줍니다. 고른 원본은 요청한 size(16–512, 예: 32)로 맞춥니다. size를 생략하면 원본 파일입니다. 축소는 Lanczos, 확대는 고품질 리샘플링이고, 정사각형이 아니면 투명하게 채우며, SVG는 요청 크기로 래스터화합니다. 확대한 래스터는 흐려 보일 수 있으며, 응답은 그것을 선명한 원본이라고 하지 않습니다.

google_s2가 나왔다면 그 사이트에 저희가 접근할 수 있는 아이콘이 없거나 요청이 차단된 것입니다(예: 봇 확인 페이지). 사이트 하나만 확인한다면 홈페이지의 파비콘 다운로더가 브라우저에서 직접 몇 가지 출처를 더 시도하고, 찾은 모든 크기를 보여 주므로 그중에서 고를 수 있습니다.

개요

Mzu favicondl은 복사해서 쓸 수 있는 파비콘 URL 템플릿과 파비콘 추출 UI를 제공합니다. 자체 추출 API가 웹사이트가 실제로 게시한 아이콘을 찾아내고, 이미지 프록시를 통해 브라우저 코드에서도 내려받을 수 있습니다.

인증

이 프로젝트는 무료 파비콘 서비스 URL 템플릿을 사용하며, 인증이나 API 키가 필요하지 않습니다.

엔드포인트

GET FaviconDL Extract API

도메인이나 URL에서 쓸 수 있는 파비콘을 찾아 다운로드

기본 URL:

https://favicondl.com/api/extract

전체 예시:

https://favicondl.com/api/extract?url=example.com&size=128

파라미터

파라미터 이름 유형 필수 기본값 설명
url string 예 - 대상 도메인 또는 URL (예: example.com)
size number 아니오 없음 (원본 파일) 정확한 출력 크기(16–512, 예: 16, 32, 64, 128, 256, 512). 그 한 변의 정사각형 PNG를 반환합니다. 범위 밖은 16–512로 맞춥니다. size를 생략하면 원본 파일입니다. 더 작은 래스터는 확대되어 흐려 보일 수 있고, SVG는 요청 크기로 래스터화합니다.
format string 아니오 redirect 메타데이터가 필요하면 json을 지정하고, 생략하면 다운로드 가능한 이미지로 리디렉션합니다

파라미터 상세:

url

도메인과 전체 웹사이트 URL을 모두 지원합니다:

  • • example.com
  • • www.example.com
  • • https://example.com/docs
  • • sub.example.com
size

16~512픽셀의 정확한 정사각형 PNG. 생략하면 원본 파일입니다. 자주 쓰는 값:

  • • 16 - 16x16
  • • 32 - 32x32
  • • 64 - 64x64
  • • 128 - 128x128
  • • 256 - 256x256
  • • 512 - 512x512

사용 예시

JavaScript (Fetch)

JavaScript 
async function getFavicon(url, size = 128) {
  const endpoint = new URL('https://favicondl.com/api/extract');
  endpoint.searchParams.set('url', url);
  endpoint.searchParams.set('size', String(size));
  const response = await fetch(endpoint);
  if (!response.ok) throw new Error(`Favicon request failed: ${response.status}`);
  return await response.blob();
}

const icon = await getFavicon('example.com', 128);
const imageUrl = URL.createObjectURL(icon);
document.querySelector('#favicon-preview').src = imageUrl;

Python (Requests)

Python 
import requests

def get_favicon(url: str, size: int = 128) -> bytes:
    response = requests.get(
        "https://favicondl.com/api/extract",
        params={"url": url, "size": size},
        timeout=15,
    )
    response.raise_for_status()
    return response.content

icon_bytes = get_favicon("example.com", 128)
with open("example-favicon", "wb") as output:
    output.write(icon_bytes)

PHP (cURL)

PHP 
<?php
function getFavicon(string $url, int $size = 128): string {
    $endpoint = 'https://favicondl.com/api/extract?url=' . urlencode($url) . '&size=' . $size;
    $context = stream_context_create(['http' => ['follow_location' => 1, 'timeout' => 15]]);
    $icon = file_get_contents($endpoint, false, $context);
    if ($icon === false) {
        throw new RuntimeException('Favicon request failed');
    }
    return $icon;
}

file_put_contents('example-favicon', getFavicon('example.com', 128));
?>

오류

오류 시 HTTP 상태 코드와 ok가 false이고 오류 메시지가 담긴 짧은 JSON을 반환합니다.

HTTP 상태 코드 오류 메시지 설명 해결 방법
400 Missing url url 또는 domain 매개변수가 전송되지 않았습니다 요청에 ?url=example.com을 추가하세요
400 Invalid format format이 json도 redirect도 아닙니다 format=json을 사용하거나 생략하여 리디렉션을 받으세요
400 Invalid domain 값을 호스트 이름으로 해석할 수 없습니다 example.com 같은 도메인이나 전체 https:// URL을 보내세요
405 Method not allowed GET 요청만 지원됩니다 GET 요청을 보내세요
502 Favicon extraction failed 추출기가 아이콘을 반환하지 못했습니다 나중에 다시 시도하세요
415 Target is not an image /api/proxy 전용: 해당 URL이 실제 이미지 데이터를 반환하지 않았습니다 /api/extract가 반환한 iconUrl 또는 candidates[].url을 사용하세요

OpenAPI spec and MCP server

  • OpenAPI 3 spec: https://favicondl.com/openapi.yaml — import it into Postman, Insomnia or a client generator.
  • MCP server: favicondl MCP (registry name io.github.sweesama/favicondl) exposes an extract_favicon tool so Claude, Cursor and other MCP clients can fetch icons.

  • • API 키가 없으며 공개된 고정 할당량도 없습니다

  • • 아이콘은 직접 캐시하고 대량 크롤링은 피해 주세요
