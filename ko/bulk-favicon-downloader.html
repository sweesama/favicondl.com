파비콘을 한꺼번에 다운로드하는 방법

  1. 목록을 붙여 넣습니다.위 입력란에 한 줄에 하나씩, 한 번에 최대 100개까지 도메인을 입력합니다. 도메인만(github.com) 넣어도, 전체 URL을 넣어도 됩니다. 프로토콜, www., 경로는 자동으로 제거됩니다. 점이 없는 줄은 건너뜁니다.
  2. 옵션을 고릅니다.크기를 고르고, ZIP과 개별 파일 중 하나를 선택한 뒤, 파일 이름을 도메인(github.com-favicon.png)으로 할지 목록 순서(001-github.com-favicon.png)로 할지 정합니다.
  3. 시작하고 다운로드합니다.시작을 누르세요. 최대 6개 사이트를 동시에 조회하며 진행률 표시줄로 진행 상황을 보여 줍니다. 미리보기를 확인한 다음 아래의 다운로드 버튼(ZIP 또는 전체 파일)을 누르세요.

옵션별 설명

옵션선택지의미
크기표준(16/32) 또는 대형(64+)대형은 더 큰 아이콘을 요청합니다. 사이트가 자체 아이콘을 제공하면 그 파일을 받게 되므로, 크기 옵션은 주로 Google 파비콘 서비스로 대체될 때 영향을 줍니다.
출력ZIP 또는 개별 파일ZIP은 모든 아이콘을 한 번의 다운로드로 묶습니다. 개별 파일은 하나씩 저장되며, 일부 브라우저는 여러 파일 다운로드를 먼저 허용하라고 묻습니다.
이름 지정도메인별 또는 번호별번호별로 하면 목록 순서가 유지되어 스프레드시트의 행과 아이콘을 맞춰 볼 때 편리합니다.

아이콘은 어디서 가져오나요

각 도메인은 단일 사이트 파비콘 다운로더와 같은 추출 과정을 거칩니다. 홈페이지의 <link rel="icon">, Apple touch icon 태그와 웹 앱 매니페스트를 읽고, /favicon.ico와 /apple-touch-icon.png 같은 잘 알려진 파일도 시도하며, 각 파일이 정말 이미지인지 확인한 뒤 작은 ICO 파일보다 SVG와 큰 PNG 아이콘을 우선합니다.

자동 요청을 차단하거나 아이콘이 없는 사이트는 Google의 공개 파비콘 서비스로 대체하므로, 목록의 모든 줄에 이미지가 붙습니다. 다운로드 전에 미리보기에서 각 결과를 보여 주므로 기본 아이콘이 나온 것을 쉽게 찾을 수 있습니다.

주요 활용 사례

  • 링크 모음과 자료 목록: 소개하는 도구나 사이트마다 옆에 아이콘을 붙입니다.
  • 대시보드와 사내 도구: 각 행, 연동, 알림이 어느 서비스의 것인지 보여 줍니다.
  • 북마크·탭 관리 도구: 정해진 사이트들의 아이콘을 미리 불러옵니다.
  • 경쟁사·시장 조사: 회사 목록 스프레드시트 옆에 브랜드 아이콘을 넣습니다.

브라우저 대신 코드로 처리하고 싶으신가요? 무료 파비콘 API는 요청 하나에 도메인 하나씩 같은 아이콘을 돌려주며 API 키가 필요 없습니다.

자주 묻는 질문

한 번에 몇 개 사이트까지 다운로드할 수 있나요?

한 번에 최대 100개 도메인입니다. 목록이 더 길면 100개씩 나눠서 진행하세요.

파비콘 일괄 다운로드는 무료인가요?

네. 계정, API 키, 결제가 모두 필요 없습니다. 실제로 필요한 목록만 처리해 주세요.

왜 어떤 아이콘은 지구본 모양의 기본 아이콘인가요?

그 사이트에 파비콘이 없거나 조회를 차단해서 Google 대체 서비스의 결과가 나온 것입니다. 해당 도메인은 단일 사이트 파비콘 다운로더로 다시 시도해 보세요. 브라우저에서 몇 가지 출처를 더 시도합니다.

CSV 파일을 업로드할 수 있나요?

직접 업로드는 안 됩니다. 스프레드시트에서 도메인 열을 복사해 입력란에 붙여 넣으면 한 줄이 도메인 하나가 됩니다.

다운로드한 파비콘을 사용해도 되나요?

파비콘은 대개 회사 로고나 상표의 일부입니다. 해당 사이트로 가는 링크 옆에 표시하는 것은 흔한 일이지만, 자신의 브랜드로 쓰는 것은 안 됩니다. 확실하지 않다면 각 브랜드의 가이드라인을 확인하세요.
