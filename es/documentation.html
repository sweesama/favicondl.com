Inicio rápido

La API de favicons de favicondl convierte cualquier dominio o URL en su favicon con una sola petición GET. Sin clave de API, sin cuenta y sin SDK. Úsala directamente en una etiqueta <img>:

<img src="https://favicondl.com/api/extract?url=github.com" width="32" height="32" alt="Favicon de GitHub">

O pide JSON para ver qué archivo se encontró y de dónde procede:

curl "https://favicondl.com/api/extract?url=github.com&format=json"

iconUrl es el archivo original del sitio web. proxyUrl sirve la misma imagen a través de nuestro proxy con Access-Control-Allow-Origin: *, para que puedas dibujarla en un canvas o pedirla con fetch desde el navegador.

format, width y height describen el archivo elegido tal como lo medimos (width/height son null en los SVG). candidates enumera hasta 8 iconos verificados más del mismo sitio (otros tamaños y formatos) para que puedas elegir otro; la lista de arriba está recortada. Queda vacía cuando hemos tenido que recurrir a Google o DuckDuckGo.

Cómo elige la API el icono

  1. La página de inicio se solicita como lo haría un navegador normal, siguiendo las redirecciones (incluido www ↔ dominio sin www). Se leen todos los <link> de iconos: icon, shortcut icon, apple-touch-icon, apple-touch-icon-precomposed y mask-icon. Los enlaces relativos y los relativos al protocolo (//cdn…) se resuelven respecto a la URL final de la página o a su etiqueta <base> (source: "html").
  2. El manifiesto de la aplicación web enlazado desde la página se abre para leer su lista de iconos, que suele ser donde están los de 192 y 512 px (source: "manifest").
  3. Las rutas habituales /favicon.ico y /apple-touch-icon.png también se prueban (source: "direct").
  4. Cada candidato se descarga y se comprueba: los bytes deben ser realmente una imagen (PNG, ICO, SVG, WebP, JPEG, GIF…) y medimos su tamaño real en píxeles en lugar de fiarnos del nombre del archivo.
  5. El servicio de favicons de Google y, después, DuckDuckGo solo se usan si nada del propio sitio funciona, con el size que pidas (source: "google_s2" o "duckduckgo").

Los candidatos verificados se ordenan para que gane el archivo más nítido: primero un SVG a todo color y después el PNG/ICO/WebP cuadrado más grande. El mask-icon monocromo de Safari y los iconos del manifiesto marcados solo como maskable quedan más abajo porque no se parecen al favicon normal. Los iconos encontrados en el sitio se devuelven en su tamaño original; el parámetro size solo afecta a los servicios de respaldo.

Si obtienes google_s2, el sitio no tiene ningún icono al que podamos llegar o ha bloqueado nuestra petición (por ejemplo, con una página de verificación anti-bots). Para un solo sitio, el descargador de favicons de nuestra página de inicio prueba además algunas fuentes extra directamente desde tu navegador y muestra todos los tamaños encontrados para que elijas uno.

Descripción general

Mzu favicondl ofrece plantillas de URL de favicon listas para copiar y una interfaz para extraer favicons. Su propia API de extracción encuentra los iconos reales que publica un sitio web, y un proxy de imágenes permite descargarlos desde código del navegador.

Autenticación

Este proyecto utiliza plantillas de URL de servicios de favicon gratuitos, no se requiere autenticación ni API Key.

Nota: Aunque no requerimos API Key, por favor usa el servicio de manera razonable para evitar solicitudes excesivas.

Endpoints

GET FaviconDL Extract API

Encuentra y descarga un favicon utilizable para un dominio o una URL

URL base:

https://favicondl.com/api/extract

Ejemplo completo:

https://favicondl.com/api/extract?url=example.com&size=128

Parámetros

Nombre del parámetro Tipo Requerido Valor predeterminado Descripción
url string Sí - El dominio o la URL de destino, p. ej. example.com
size number No 128 Tamaño de respaldo en píxeles (16–512). Solo se usa cuando recurrimos al servicio de favicons de Google; los iconos encontrados en el propio sitio se devuelven en su tamaño original.
format string No redirect Usa json para obtener metadatos; omítelo para recibir una redirección a la imagen descargable

Detalles de parámetros:

url

Admite dominios y URL completas de sitios web:

  • • example.com
  • • www.example.com
  • • https://example.com/docs
  • • sub.example.com
size

Tamaño de respaldo para el servicio de favicons de Google, de 16 a 512 píxeles:

  • • 16 - 16x16
  • • 32 - 32x32
  • • 128 - 128x128
  • • 512 - 512x512

Respuesta de error

Respuesta de error 
{
  "ok": false,
  "error": "Missing url"

Nota: Cuando se usa format=redirect, la API redirige directamente a la URL del favicon sin devolver una respuesta JSON.

Ejemplos

JavaScript (Fetch)

JavaScript 
async function getFavicon(url, size = 128) {
  const endpoint = new URL('https://favicondl.com/api/extract');
  endpoint.searchParams.set('url', url);
  endpoint.searchParams.set('size', String(size));
  const response = await fetch(endpoint);
  if (!response.ok) throw new Error(`Favicon request failed: ${response.status}`);
  return await response.blob();
}

const icon = await getFavicon('example.com', 128);
const imageUrl = URL.createObjectURL(icon);
document.querySelector('#favicon-preview').src = imageUrl;

Python (Requests)

Python 
import requests

def get_favicon(url: str, size: int = 128) -> bytes:
    response = requests.get(
        "https://favicondl.com/api/extract",
        params={"url": url, "size": size},
        timeout=15,
    )
    response.raise_for_status()
    return response.content

icon_bytes = get_favicon("example.com", 128)
with open("example-favicon", "wb") as output:
    output.write(icon_bytes)

PHP (cURL)

PHP 
<?php
function getFavicon(string $url, int $size = 128): string {
    $endpoint = 'https://favicondl.com/api/extract?url=' . urlencode($url) . '&size=' . $size;
    $context = stream_context_create(['http' => ['follow_location' => 1, 'timeout' => 15]]);
    $icon = file_get_contents($endpoint, false, $context);
    if ($icon === false) {
        throw new RuntimeException('Favicon request failed');
    }
    return $icon;
}

file_put_contents('example-favicon', getFavicon('example.com', 128));
?>

Errores

Los errores devuelven un código de estado HTTP y un JSON breve con ok en false y un mensaje de error.

Código de estado HTTP Mensaje de error Descripción Solución
400 Missing url No se envió el parámetro url ni domain Añade ?url=example.com a la solicitud
400 Invalid format format no es json ni redirect Usa format=json u omítelo para obtener una redirección
400 Invalid domain El valor no se pudo interpretar como un nombre de host Envía un dominio como example.com o una URL https:// completa
405 Method not allowed Solo se admiten solicitudes GET Envía una solicitud GET
502 Favicon extraction failed El extractor no pudo devolver un icono Inténtalo más tarde
415 Target is not an image Solo en /api/proxy: la URL no devolvió datos de imagen reales Usa un iconUrl o candidates[].url devuelto por /api/extract

OpenAPI spec and MCP server

  • OpenAPI 3 spec: https://favicondl.com/openapi.yaml — import it into Postman, Insomnia or a client generator.
  • MCP server: favicondl MCP (registry name io.github.sweesama/favicondl) exposes an extract_favicon tool so Claude, Cursor and other MCP clients can fetch icons.

Límites de uso

Gratis

Sin registro necesario, completamente gratis para usar todas las funciones

Uso razonable

  • • No hay API key ni una cuota fija publicada
  • • Los iconos encontrados en el sitio se guardan en caché en el edge 24 horas; los resultados de Google/DuckDuckGo, 10 minutos
  • • Guarda en caché los iconos por tu cuenta y evita el rastreo masivo

Uso comercial

No hay plan de pago ni SLA. Para un uso intensivo o crítico, guarda los iconos que necesites en tu propio almacenamiento.
