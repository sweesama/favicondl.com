Cómo añadir un favicon a Blogger en 5 pasos

Si la pestaña de tu Blogspot todavía muestra el icono predeterminado de Blogger después de subir un logotipo, el problema suele estar entre la carga del archivo y su publicación en la página. Esta guía te muestra cómo configurar un favicon de Blogger, comprobar qué archivo recibe tu navegador y recurrir al HTML del theme cuando el panel Layout no sea suficiente.

La vía más rápida pasa por la pantalla Layout de Blogger y solo requiere unos clics. Recurre a la opción de HTML si necesitas un SVG, controlar la URL exacta del icono o sustituir declaraciones conflictivas que ya estén en el theme.

Requisitos previos: lo que necesitas antes de empezar

Necesitas acceso de administrador al blog de Blogger, una imagen cuadrada y una forma de inspeccionar la página pública. Para la ruta manual de HTML, utiliza una URL HTTPS accesible públicamente para cada archivo de icono.

  • Acceso de administrador: Inicia sesión en el panel de control de Blogger y abre el blog que administras. Necesitas acceso de editor para llegar a los controles Layout o Themes.
  • Un PNG cuadrado: Un archivo maestro de 512 × 512 te deja margen para exportar archivos más pequeños, pero comprueba cómo se ve la marca a 16 × 16. La guía de tamaños por plataforma explica qué tamaños importan para cada destino.
  • Una marca sencilla: Opta por una silueta clara y detalles limitados; un logotipo textual completo en miniatura rara vez sigue siendo legible en una pestaña con muchos elementos.
  • Una URL pública para los recursos: Si usas HTML del theme, aloja los archivos SVG, PNG o ICO en un servicio que los entregue directamente por HTTPS.

Añade tu favicon de Blogger en cinco pasos

  1. Abre la pantalla Layout de Blogger. Inicia sesión, selecciona el blog, elige Layout en la navegación del dashboard y desplázate hasta la sección Favicon. Haz clic en Edit, a su lado. Si la sección no aparece, utiliza el método de HTML del tema que se explica más abajo.
  2. Sube y guarda el icono. Elige el PNG en el selector de archivos, revisa la vista previa y guarda el icono. Mantén el diseño en formato cuadrado para que la versión pequeña de la pestaña no pierda elementos importantes.
  3. Abre el blog público. Después de guardar, carga la página de inicio pública en una pestaña nueva. Para verificarlo, utiliza el dominio público en lugar de la vista previa del panel de administración, que no representa lo que reciben los visitantes.
  4. Comprueba la solicitud del icono. Abre las herramientas de desarrollo del navegador, selecciona Network, recarga la página y filtra por favicon o por el nombre del archivo que subiste. Abre la solicitud correspondiente y comprueba que se completa con éxito y devuelve el archivo de imagen en lugar de una página de error HTML.
  5. Enumera las declaraciones del icono. Abre la pestaña Console y ejecuta este fragmento:
document.querySelectorAll(`link[rel~='icon']`).forEach((link) => {
  console.log(link.href, link.type, link.sizes.value);
});

La salida muestra cada candidato de icono que expone la página pública. Abre su URL y comprueba que apunta al diseño que subiste.

Añade enlaces explícitos al icono en el HTML del tema

Utiliza esta vía cuando el panel Layout no esté disponible, cuando alojes tus propios recursos o cuando quieras un SVG junto con fallbacks en formato raster. En Blogger, abre Themes, utiliza la flecha situada junto a Customize, selecciona Edit HTML y pega los enlaces antes de la etiqueta de cierre &lt;/head&gt;.

Guarda primero una copia local del markup actual del tema. El HTML Standard define una relación de icono mediante rel='icon', por lo que cada declaración debe apuntar a un recurso que el navegador pueda descargar.

&lt;link rel='icon' type='image/svg+xml' href='https://assets.example.com/favicon.svg'&gt;
&lt;link rel='icon' type='image/png' sizes='32x32' href='https://assets.example.com/favicon-32.png'&gt;
&lt;link rel='icon' href='https://assets.example.com/favicon.ico'&gt;

Sustituye las URLs de ejemplo por direcciones HTTPS directas y accesibles públicamente. Elimina cualquier línea cuyo archivo no exista y quita las declaraciones antiguas de iconos personalizados que apunten a otras imágenes. Guarda el tema, recarga el dominio público y vuelve a ejecutar la comprobación en Console.

Problemas habituales con el favicon de Blogger

  • No hay panel de favicon: Utiliza el editor de temas y una etiqueta link explícita en lugar de añadir un widget de imagen. La URL del recurso debe devolver directamente el archivo del icono, no una página HTML.
  • El icono antiguo sigue apareciendo: Prueba la página en vivo en una ventana privada antes de volver a cambiar el archivo. Si el markup y la respuesta son correctos, consulta la lista de comprobaciones para diagnosticar un favicon que no aparece para revisar la caché y el enrutamiento.
  • Una respuesta 404 o HTML: Comprueba la ruta exacta, las mayúsculas y minúsculas y la configuración del host. Un enlace de favicon que apunta a una página de una entrada no proporcionará una imagen.
  • Declaraciones conflictivas: Un enlace antiguo puede dirigir a los visitantes a un archivo diferente. Vuelve a ejecutar el fragmento de código de Console y conserva un único stack de iconos intencionado.
  • Arte ilegible: Simplifica la marca y exporta un PNG pequeño y nítido. Si un SVG no se renderiza, conserva un fallback en PNG o ICO junto a él.

Confirma el resultado y ponlo en marcha

Un favicon de Blogger fiable debe superar dos comprobaciones: el head de la página en vivo debe exponer el icono previsto y su URL debe devolver la imagen real. Cuando ambas comprobaciones pasan, la subida queda conectada a la página que reciben los visitantes.
