Cómo descargar un Favicon de cualquier sitio web

¿Necesitas obtener el favicon de un sitio web para un proyecto, presentación o análisis competitivo? Aquí tienes 3 métodos confiables, desde el más simple hasta el más potente.

Método 1: El truco de la barra de direcciones del navegador

El enfoque más simple: solo escribe una URL directamente en tu navegador:

https://www.google.com/s2/favicons?domain=example.com&sz=64

Esto utiliza el servicio público de favicon de Google para obtener el icono. Puedes cambiar el parámetro sz para obtener diferentes tamaños (16, 32, 64, 128, 256).

Ventajas: No necesitas herramientas, funciona en cualquier navegador.
Desventajas: Tamaños limitados, a veces devuelve iconos de baja calidad o predeterminados. No permite descargas por lotes.

Método 2: Revisa el código fuente HTML del sitio web

Cada sitio web declara sus favicons en la sección <head> de su HTML. Así es como puedes encontrarlos:

  1. Abre el sitio web objetivo en tu navegador.
  2. Haz clic derecho y selecciona "Ver código fuente de la página" (o presiona Ctrl+U).
  3. Busca rel="icon" o rel="shortcut icon".
  4. Copia el valor href — esa es la URL del favicon.
  5. Abre la URL en una nueva pestaña y guarda la imagen.

Podrías encontrar múltiples declaraciones de favicon que apuntan a diferentes tamaños y formatos. Patrones comunes:

<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">

Ventajas: Obtiene los iconos exactos que el sitio realmente utiliza.
Desventajas: Manual, consume tiempo. Algunos sitios usan rutas complejas o URLs de CDN que son difíciles de encontrar.

Método 4 (Extra): Usando la línea de comandos

Para los desarrolladores que prefieren la terminal, puedes usar curl:

# Download via Google's favicon API
curl -o favicon.png "https://www.google.com/s2/favicons?domain=github.com&sz=128"

# Or download directly from the website
curl -o favicon.ico "https://github.com/favicon.ico"

Preguntas frecuentes

¿Es legal descargar favicons?

Los favicons son servidos públicamente por los sitios web y están destinados a ser mostrados por los navegadores. Descargarlos para uso personal, investigación o referencia generalmente está bien. Sin embargo, usar el favicon de otra persona como tu propio icono de marca podría generar problemas de marca registrada.

¿Por qué el favicon que descargué está borroso?

Muchos sitios web solo proporcionan un favicon de 16×16 o 32×32 píxeles. Intenta buscar el Apple Touch Icon (180×180) o el Android Chrome icon (192×192 o 512×512) para una mayor calidad. Mzu favicondl obtiene automáticamente múltiples tamaños para que puedas elegir el mejor.
