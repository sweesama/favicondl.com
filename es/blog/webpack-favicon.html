Configuración de favicon con Webpack: guía paso a paso

Si alguna vez has creado un proyecto con Webpack y has visto que la pestaña del navegador muestra un globo genérico o un cuadrado en blanco, no eres el único. Webpack no gestiona los favicons de forma nativa: tendrás que conectarlo tú. La buena noticia es que solo necesitas unas líneas de configuración cuando sabes dónde colocar el archivo y cómo insertar el link tag.

En esta guía te explicamos cómo añadir un favicon a un proyecto de Webpack, desde colocar el archivo hasta comprobarlo en el navegador. Veremos tanto el enfoque sencillo de copia como el método con HtmlWebpackPlugin, además de las trampas que hacen tropezar a la mayoría de los desarrolladores.

Requisitos previos

Deberías tener un proyecto de Webpack funcionando con webpack y webpack-cli instalados. Si utilizas html-webpack-plugin para generar tu HTML, mejor todavía: lo usaremos en el enfoque recomendado. También necesitarás un archivo favicon (ICO, PNG o SVG) listo para usar. Si no tienes uno, puedes generar un ICO de varios tamaños con nuestra guía.

Paso 1: Coloca el favicon en tu proyecto

Crea una carpeta para los assets estáticos si aún no tienes una. Una convención habitual es src/assets/ o public/. Coloca allí tu archivo favicon; puedes llamarlo favicon.ico para lograr la máxima compatibilidad con los navegadores. También puedes usar favicon.png o favicon.svg; los navegadores modernos admiten SVG, pero necesita un fallback para los más antiguos (consulta SVG con fallback PNG).

En esta guía, supondremos que el archivo está en src/assets/favicon.ico.

Paso 2: Configura Webpack para copiar el favicon

Webpack debe conocer el archivo para que termine en el directorio de salida de tu build. La forma más sencilla de hacerlo es utilizar copy-webpack-plugin. Instálalo:

npm install --save-dev copy-webpack-plugin

Después, añádelo a tu webpack.config.js:

const CopyPlugin = require('copy-webpack-plugin');

module.exports = {
  // ... other config
  plugins: [
    new CopyPlugin({
      patterns: [
        { from: 'src/assets/favicon.ico', to: 'favicon.ico' }
      ]
    })
  ]
};

Esto copia el favicon a la raíz de tu directorio de salida (p. ej., dist/favicon.ico). Los navegadores solicitan automáticamente /favicon.ico si no hay una etiqueta link, por lo que esto puede ser suficiente; sin embargo, las etiquetas link explícitas son mejores porque te ofrecen más control y permiten usar formatos que no sean ICO.

Paso 3: Inyecta la etiqueta link con HtmlWebpackPlugin

Si usas html-webpack-plugin, puedes añadir el enlace al favicon directamente en tu plantilla HTML. En tu plantilla index.html (normalmente en src/), añade esto dentro de <head>:

<link rel='icon' href='favicon.ico' type='image/x-icon'>

Como el archivo se copia a la raíz de salida, la ruta relativa favicon.ico se resuelve correctamente. Si sirves el sitio desde un subdirectorio, utiliza una ruta absoluta como /favicon.ico o configura publicPath en Webpack.

Para los favicons SVG, utiliza:

<link rel='icon' href='favicon.svg' type='image/svg+xml'>

Y para los PNG:

<link rel='icon' href='favicon.png' type='image/png'>

El atributo rel='icon' está definido en el estándar HTML como la forma de especificar el icono de un sitio. Los navegadores lo utilizan para elegir el icono más adecuado para las pestañas, los marcadores y el historial.

Paso 4: Compila y verifica

Ejecuta tu comando de compilación (p. ej., npm run build). Comprueba que favicon.ico aparezca en la carpeta de salida. Después, sirve la compilación localmente (p. ej., con npx serve dist) y ábrela en un navegador. La pestaña debería mostrar tu icono. Si no lo hace, haz una recarga forzada (Ctrl+Shift+R o Cmd+Shift+R) para omitir la caché.

También puedes inspeccionar el código fuente de la página para confirmar que la etiqueta link está presente y que la ruta es correcta.

Problemas habituales

  • Ruta de salida incorrecta: Si usas CopyPlugin con una ruta to que incluya una subcarpeta, la etiqueta link debe coincidir con ella. Por ejemplo, to: 'assets/favicon.ico' requiere href='assets/favicon.ico'.
  • Archivo ausente en producción: Algunas configuraciones solo copian los assets durante el desarrollo. Asegúrate de que CopyPlugin se ejecute en todos los modos.
  • Problemas de caché: Los navegadores guardan los favicons en caché de forma agresiva. Usa una query string como favicon.ico?v=2 al actualizarlo, o configura cache busting en tu build (consulta las buenas prácticas de cache busting).
  • SVG sin fallback: Los navegadores más antiguos ignoran los favicons SVG. Incluye siempre un fallback ICO o PNG.
  • Archivo no está en la raíz: Si no usas una etiqueta link y dependes de la solicitud predeterminada de /favicon.ico, el archivo debe estar en la raíz del directorio que sirves.

Conclusión

Añadir un favicon a un proyecto Webpack es sencillo una vez que conoces los dos elementos clave: copiar el archivo a la salida y referenciarlo en tu HTML. Usa copy-webpack-plugin para mover el asset y añade una etiqueta link rel='icon' en tu template. Eso es todo: tus pestañas se verán pulidas y profesionales.
