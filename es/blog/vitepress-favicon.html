Favicon de VitePress: Guía paso a paso

Si alguna vez has desplegado un sitio VitePress y te has dado cuenta de que la pestaña del navegador sigue mostrando el logotipo predeterminado de VitePress, no estás solo. Muchos desarrolladores asumen que basta con colocar un favicon.ico en la carpeta public, pero VitePress requiere un poco más de configuración para enlazar correctamente tu icono. Esta guía te explica los pasos exactos para establecer un favicon personalizado en tu sitio VitePress, desde la colocación del archivo hasta la verificación del resultado.

Requisitos previos

Antes de empezar, asegúrate de tener:

  • Un proyecto VitePress configurado (versión 1.x o posterior).
  • Un archivo favicon listo. Puedes usar ICO, PNG o SVG. Si necesitas crear uno, prueba Mzu favicondl para generar un favicon de varios tamaños.
  • Familiaridad básica con el archivo config.js o config.ts en tu proyecto VitePress.

Paso 1: Coloca tu archivo favicon en el directorio public

VitePress usa Vite internamente, por lo que los recursos estáticos deben ir en el directorio public en la raíz de tu proyecto. Los archivos en public se sirven en la ruta raíz y se copian a la salida de compilación sin cambios. Por ejemplo, si colocas favicon.ico en public, será accesible en /favicon.ico después de la compilación.

Crea la carpeta public si no existe y coloca tu archivo favicon dentro. También puedes usar un archivo PNG o SVG; solo recuerda el nombre del archivo.

your-project/
├── docs/
│   └── .vitepress/
│       └── config.js
├── public/
│   └── favicon.ico
└── package.json

Nota: El directorio public es relativo a la raíz de tu proyecto VitePress (donde está package.json). Si usas la estructura predeterminada con una carpeta docs, la carpeta public debe estar en la raíz del proyecto, no dentro de docs.

Paso 2: Configura el favicon en la configuración de VitePress

VitePress te permite definir las etiquetas <head> para tu sitio mediante la opción head en tu archivo de configuración. Aquí es donde agregas la etiqueta <link rel="icon">.

Abre tu .vitepress/config.js (o .ts) y agrega lo siguiente:

import { defineConfig } from 'vitepress'

export default defineConfig({
  head: [
    ['link', { rel: 'icon', href: '/favicon.ico' }]
  ],
  // other config...
})

Si usas un favicon SVG, puedes especificar el tipo:

head: [
  ['link', { rel: 'icon', type: 'image/svg+xml', href: '/favicon.svg' }]
]

Esto le indica a VitePress que inyecte la etiqueta link en el <head> de cada página. El href debe comenzar con una barra (/) porque el archivo se sirve desde la raíz.

Paso 3: Verifica tu favicon

Después de configurar, ejecuta tu servidor de desarrollo (npm run docs:dev o yarn docs:dev) y abre tu sitio en un navegador. Revisa la pestaña: tu favicon debería aparecer. Si no es así, prueba una recarga forzada (Ctrl+F5 o Cmd+Shift+R) para saltar la caché.

Para producción, compila tu sitio (npm run docs:build) e inspecciona el HTML generado en .vitepress/dist. Busca tu etiqueta <link rel="icon"> en la sección <head>.

Errores comunes

  • Ruta de archivo incorrecta: Si colocas el favicon en docs/public en lugar de la raíz del proyecto public, no se copiará. Usa siempre el directorio raíz public.
  • Falta la barra inicial: Usar href: 'favicon.ico' (sin barra) puede causar problemas en rutas anidadas. Usa siempre /favicon.ico.
  • Caché del navegador: Los navegadores almacenan en caché los favicons de forma agresiva. Después de actualizar, borra la caché o usa un nombre de archivo diferente (por ejemplo, favicon-v2.ico) para forzar una actualización. Para más información sobre problemas de caché, consulta nuestra lista de verificación para favicons que no se muestran.
  • Soporte de SVG: Aunque los favicons SVG son ampliamente compatibles, algunos navegadores antiguos pueden no mostrarlos. Considera proporcionar un fallback PNG o ICO. Aprende más en nuestra guía de favicons SVG.

Conclusión

Configurar un favicon en VitePress es sencillo una vez que sabes dónde colocar el archivo y cómo configurar las etiquetas head. Siguiendo estos pasos, te aseguras de que tu sitio tenga un aspecto profesional en las pestañas del navegador, los marcadores y los resultados de búsqueda. Recuerda probar en diferentes navegadores y borrar la caché cuando hagas cambios.
