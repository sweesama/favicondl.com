Configuración del icono de Apple en Next.js: Guía 2026 para App Router

Si alguna vez has abierto tu sitio Next.js en un iPhone y has visto un cuadrado gris en blanco al añadirlo a la pantalla de inicio, te falta el icono táctil de Apple. El favicon de la pestaña del navegador puede verse bien, pero iOS usa un archivo separado, y Next.js tiene una forma específica de servirlo.

Esta guía explica la configuración del icono de Apple en Next.js usando el sistema de metadatos basado en archivos del App Router. Sin rutas API personalizadas, sin etiquetas <link> manuales en _document.tsx — solo coloca un archivo en la carpeta correcta y listo.

Requisitos previos

Antes de empezar, asegúrate de tener:

  • Un proyecto Next.js que use el App Router (versión 13.2 o posterior).
  • Un archivo de imagen para tu icono. Apple recomienda un PNG de 180×180 para el icono táctil, pero hablaremos de eso en un momento.
  • Familiaridad básica con el directorio app/ de tu proyecto.

Paso 1: Prepara el icono táctil de Apple

El icono táctil de Apple es un archivo PNG que iOS usa cuando un usuario añade tu sitio a la pantalla de inicio. El tamaño recomendado es de 180×180 píxeles, pero también puedes proporcionar uno de 167×167 para iPad Pro y 152×152 para iPads más antiguos. Sin embargo, iOS escalará automáticamente un icono de 180×180, así que solo necesitas un archivo.

Si no tienes un icono listo, puedes generar uno a partir de tu logo usando una herramienta como Mzu favicondl. Puede exportar un PNG de 180×180 con la transparencia y el relleno correctos.

Paso 2: Coloca el archivo en el directorio app

En el App Router de Next.js, puedes añadir apple-icon.png (o apple-icon.jpg) directamente en tu directorio app/. Next.js lo detecta automáticamente y lo sirve en la raíz de tu sitio. El archivo debe colocarse en la misma carpeta que tu layout.tsx — típicamente app/.

Aquí tienes un ejemplo de estructura de carpetas:

app/
├── layout.tsx
├── page.tsx
├── apple-icon.png
└── icon.png

Eso es todo. Next.js generará automáticamente la etiqueta <link rel='apple-touch-icon'> adecuada en el head de tus páginas. No necesitas escribir ningún HTML manualmente.

Paso 3: Verifica el HTML generado

Para confirmar que el icono se está sirviendo, ejecuta tu servidor de desarrollo e inspecciona el código fuente de la página. Deberías ver una línea como esta:

<link rel='apple-touch-icon' href='/apple-icon.png' sizes='180x180' type='image/png'/>

Si no la ves, verifica que el archivo se llame exactamente apple-icon.png y que esté en el directorio correcto. Next.js distingue entre mayúsculas y minúsculas en Linux y macOS.

Paso 4: Usa la API de metadatos para más control

Si necesitas especificar varios iconos o quieres configurarlos programáticamente, puedes usar la exportación metadata en tu layout. Esto es útil si tienes diferentes iconos para diferentes rutas o quieres añadir un icono maskable para Android.

Aquí tienes un ejemplo en app/layout.tsx:

import type { Metadata } from 'next';

export const metadata: Metadata = {
  icons: {
    apple: [
      { url: '/apple-icon.png', sizes: '180x180', type: 'image/png' },
    ],
  },
};

Este enfoque te da control total sobre los atributos rel, sizes y type. También puedes usarlo para añadir un icono maskable para PWAs de Android, aunque eso es un tema aparte.

Errores comunes

Aquí tienes algunos problemas con los que podrías encontrarte:

  • Archivo no encontrado: Verifica el nombre del archivo. Debe ser apple-icon.png o apple-icon.jpg. Next.js no reconocerá apple-touch-icon.png.
  • Problemas de caché: iOS almacena en caché los iconos de forma agresiva. Si has cambiado el icono y no ves la actualización, intenta limpiar la caché de Safari o usa otro dispositivo.
  • Tamaño incorrecto: Apple recomienda 180×180, pero si usas un tamaño diferente, iOS lo escalará. El escalado puede causar borrosidad, así que sigue el tamaño recomendado.
  • Transparencia: iOS no admite transparencia en los iconos táctiles de Apple. Si tu PNG tiene áreas transparentes, aparecerán en negro. Asegúrate de que tu icono tenga un fondo sólido.

Conclusión

Configurar el icono táctil de Apple en Next.js es sencillo una vez que conoces la convención basada en archivos. Coloca un PNG del tamaño adecuado en tu carpeta app/, y Next.js se encarga del resto. Para escenarios más avanzados, la API de metadatos te da control programático.
