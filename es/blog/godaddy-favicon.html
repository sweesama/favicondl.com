Favicon en GoDaddy Website Builder: guía paso a paso

Si tu sitio de GoDaddy sigue mostrando el icono predeterminado en una pestaña del navegador, puede que el reemplazo no se haya aplicado en la vista previa o que el navegador esté reutilizando un icono antiguo. Un favicon de GoDaddy Website Builder es el icono que muestra el navegador para todo el sitio, no una imagen insertada en una sección de la página. Súbelo en el editor, publica el sitio y comprueba qué entrega el HTML publicado.

Requisitos previos

Necesitas acceso para editar y publicar el sitio de GoDaddy, además de una imagen fuente cuadrada. PNG es un formato práctico para la carga; un archivo de 512×512 px te dará margen para simplificar el diseño antes de exportarlo. Mantén la marca reconocible a 16×16 px, porque los trazos finos y el texto con demasiado detalle suelen desaparecer.

  • Tu acceso a GoDaddy y al sitio en Website Builder
  • Un archivo fuente cuadrado en PNG o SVG con un fondo limpio
  • La URL del dominio en producción y un navegador con Developer Tools

Puedes preparar las variantes finales en PNG, ICO y SVG con Mzu favicondl. El uploader integrado es la opción más sencilla; los formatos adicionales solo son útiles si necesitas una alternativa manual.

Añade un favicon de GoDaddy Website Builder paso a paso

1. Abre el sitio en Website Builder

Inicia sesión en GoDaddy, abre Websites and Shop y selecciona el dominio conectado con tu sitio de Website Builder. Elige Edit Website para entrar al editor. Si el editor ya está abierto, continúa al siguiente paso.

2. Abre el ajuste del favicon

Abre el panel de ajustes generales del editor y busca Favicon. Según el diseño actual del editor, el control puede aparecer en Settings o como Website icon. Elige el control de nivel de sitio, no un bloque de imagen dentro de una sección ni el campo normal del logo.

3. Prepara y selecciona la imagen

Selecciona Upload, Replace o Select image, según el botón que aparezca. Elige tu PNG cuadrado y recórtalo para que la marca ocupe el marco sin deformarse. Deja un poco de espacio alrededor del símbolo en lugar de ampliar el logo completo hasta los bordes.

Previsualiza el resultado al tamaño real de una pestaña del navegador. Si el diseño tiene demasiado detalle, vuelve al archivo fuente y simplifícalo; ampliar una imagen rasterizada pequeña solo hará que el desenfoque resulte más evidente.

4. Aplica el favicon

Confirma la vista previa y selecciona Aplicar, Guardar o el botón de confirmación equivalente. Comprueba que la vista previa del editor ya muestre tu símbolo. Algunas versiones del editor actualizan la vista previa de inmediato, mientras que otras solo muestran el cambio después de la publicación.

5. Publica el cambio

Selecciona Publicar en la barra de herramientas superior del editor y espera la confirmación de publicación. Abre el dominio activo, no el lienzo del editor, en una pestaña nueva. Un cambio sin publicar puede verse correcto en el editor mientras que los visitantes siguen recibiendo los archivos anteriores del sitio.

6. Verifica la solicitud del icono activo

Abre el código fuente de la página activa e inspecciona el <head> del documento para buscar un enlace al icono. La especificación HTML para rel='icon' define esta relación de enlace para un icono que representa la página. Un resultado nativo puede tener este aspecto:

<link rel='icon' href='/favicon.ico'>

En las Developer Tools del navegador, abre el panel Network, recarga la página activa y busca la solicitud del icono. Confirma que devuelve una respuesta correcta y que apunta al archivo que subiste. Si el HTML activo no contiene ningún enlace al icono, vuelve al paso 2 en lugar de añadir una etiqueta duplicada.

7. Usa un fallback manual solo cuando sea necesario

Si el control nativo no admite el ICO o SVG que prefieres, añade un fallback solo si el editor ofrece un campo de HTML personalizado o del head del documento. Sube cada archivo a una URL pública estable y, después, referencia esas URLs exactas en el head. No presupongas que existe una ruta como /favicon.ico hasta que hayas subido allí el archivo.

<link rel='icon' href='/favicon.ico'>
<link rel='icon' type='image/png' sizes='32x32' href='/favicon-32x32.png'>
<link rel='icon' type='image/svg+xml' href='/favicon.svg'>
<link rel='apple-touch-icon' sizes='180x180' href='/apple-touch-icon.png'>

Replace cada ruta de ejemplo por una URL real publicada y elimina las etiquetas de iconos duplicadas que ya haya generado Website Builder. Si tu plan o editor no ofrece ningún control del head, utiliza el cargador nativo.

Problemas habituales

La vista previa cambia, pero el sitio activo no

Publica el sitio y prueba su URL pública. Los iconos de las pestañas del navegador pueden seguir en la caché, así que usa una ventana privada o los pasos de How to Clear Favicon Cache antes de volver a cambiar la imagen.

El navegador solicita un archivo que no existe

Compara la URL del icono en el <head> publicado con el panel Network. Un 404 suele significar que el archivo se subió a una ruta distinta, que la URL está desactualizada o que el markup manual apunta a una ubicación que no existe. Consulta la lista de verificación más completa de Favicon Not Showing si la etiqueta nativa está presente pero no aparece ningún icono.

El icono aparece recortado, estirado o invisible

Sube una imagen de origen cuadrada y mantén el símbolo dentro del área segura central. Si la transparencia hace que la marca desaparezca sobre el fondo de una pestaña, exporta una versión con fondo sólido y compárala a 16×16 px.

La pestaña sigue mostrando la marca anterior

Revisa el markup publicado antes de suponer que GoDaddy no guardó los cambios. Si apunta al archivo nuevo, limpia la caché del favicon; si apunta al archivo antiguo, vuelve a publicar y comprueba que ninguna plantilla obsoleta ni ningún enlace duplicado al icono esté sustituyendo el archivo subido.

Termina con una comprobación en la página publicada

La configuración estará completa cuando la página publicada incluya una solicitud de icono completada con éxito y la pestaña del navegador muestre la marca prevista. Repite la comprobación en otro navegador o dispositivo, porque la caché y el comportamiento de selección del icono pueden variar. Así tendrás un proceso repetible para cada futura renovación de marca de GoDaddy.
