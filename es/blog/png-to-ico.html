PNG a ICO: conversor gratis de favicon multi-tamaño

Convierte PNG a ICO cuando necesitas un favicon.ico con varias capas, no un PNG renombrado. Un PNG es un solo bitmap. Un ICO es un contenedor: el navegador o Windows elige una capa. Las medidas de cada superficie están en la guía de tamaño de favicon.

Cómo convertir PNG a ICO

  1. Parte de un PNG cuadrado. 256×256 basta para un favicon; 512×512 es mejor si también exportas los iconos del manifiesto. Reducir se mantiene nítido. Ampliar un archivo de 16 o 32 px, no.
  2. Abre Herramientas. En Imagen a favicon, descargar ICO escribe 16×16, 32×32 y 48×48 en un solo favicon.ico. El ZIP añade los PNG que dejes marcados (16, 32, 180, 192 y 512 por defecto), el manifiesto y el HTML.
  3. O usa el conversor de formato de esa misma página: elige ICO y deja marcados 16, 32 y 48. Marca 64, 128 o 256 solo si el archivo es un icono de aplicación de Windows.
  4. Publica favicon.ico en la raíz y enlázalo desde la página de inicio.

Qué medidas incluir en el ICO

Para el favicon de una web, el archivo lleva estas tres capas:

  • 16×16 — pestaña en una pantalla normal.
  • 32×32 — pestaña en una pantalla de alta densidad.
  • 48×48 — acceso directo de Windows.
  • 64, 128 y 256 — solo para un icono de aplicación de Windows. Engordan el favicon.ico de un sitio sin mejorar la pestaña.

180×180, 192×192 y 512×512 se quedan como PNG aparte: son el apple-touch-icon y los iconos del manifiesto.

El formato ICO sigue siendo el respaldo que los navegadores piden en /favicon.ico aunque la página no tenga una etiqueta link.

Por qué ICO sigue siendo importante en 2026

  • Soporte universal en navegadores — ICO funciona en todos los navegadores, incluyendo versiones muy antiguas de IE.
  • Contenedor de múltiples tamaños — Un solo archivo ICO puede contener múltiples tamaños de imagen (16×16, 32×32, 48×48, 64×64, 128×128 y 256×256); el navegador elige el mejor.
  • Integración con Windows — Los accesos directos del escritorio de Windows y los pines de la barra de tareas utilizan el formato ICO.
  • Respaldo automático — Los navegadores buscan /favicon.ico en la raíz de cada sitio web por defecto.

Método 2: Línea de comandos con ImageMagick

Para los desarrolladores que prefieren la terminal, ImageMagick es el estándar de oro:

# Install ImageMagick
# macOS: brew install imagemagick
# Ubuntu: sudo apt install imagemagick
# Windows: choco install imagemagick

# Convert PNG to ICO (single size)
magick convert input.png -resize 32x32 favicon.ico

# Favicon.ico: 16, 32 y 48
magick convert input.png -define icon:auto-resize=16,32,48 favicon.ico

# Opcional: icono de aplicación de Windows, no el favicon de una web
magick convert input.png -define icon:auto-resize=16,32,48,64,128,256 favicon.ico

Para un sitio, publica el archivo de tres medidas como /favicon.ico. El de seis medidas es un icono de aplicación de Windows: 256×256 es un icono grande, no un recurso de la pestaña.

Método 3: Usando FFmpeg

Si ya tienes FFmpeg instalado:

ffmpeg -i input.png -vf scale=32:32 favicon.ico

Método 4: Script de Python

Con la librería Pillow. La lista es el conjunto del favicon. Añade 64, 128 y 256 solo para un icono de aplicación de Windows:

from PIL import Image

img = Image.open('input.png')
img.save('favicon.ico', format='ICO', sizes=[(16, 16), (32, 32), (48, 48)])

Mejor práctica: Usa ambos

El enfoque recomendado es proporcionar ambos formatos:

<!-- ICO as fallback -->
<link rel="icon" type="image/x-icon" href="/favicon.ico">

<!-- PNG for modern browsers (crisper rendering) -->
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
<link rel="icon" type="image/png" sizes="16x16" href="/favicon-16x16.png">

Los navegadores modernos preferirán el PNG. Los navegadores más antiguos y los accesos directos de Windows usarán el ICO. Así obtendrás lo mejor de ambos mundos.

Consejos para obtener los mejores resultados

  • Empieza con una imagen cuadrada — Las imágenes no cuadradas se estirarán o recortarán.
  • Usa al menos 512×512 como entrada — Reducir el tamaño produce mejores resultados que aumentarlo.
  • Mantenlo simple — A 16px, los detalles finos desaparecen. Las formas audaces y el alto contraste funcionan mejor.
  • Usa fondos transparentes — Los fondos sólidos se ven anticuados en las pestañas de los navegadores modernos.
  • Prueba a tamaño real — Reduce tu icono a 16×16 píxeles y verifica la legibilidad.
