Cómo añadir o cambiar el favicon de Weebly: 7 pasos

Si tu sitio de Weebly todavía muestra un globo genérico o el logotipo anterior en una pestaña del navegador, esta guía del favicon de Weebly explica las tres cosas que deben coincidir: la imagen subida, la página publicada y la URL del icono en producción. Puedes completar la configuración habitual sin editar ningún archivo del tema.

Requisitos previos

Antes de empezar, reúne estos tres elementos:

  • Acceso al editor: Debes poder abrir el sitio en Weebly y publicar cambios.
  • Una imagen de origen cuadrada: Un PNG de 512 × 512 es una recomendación práctica para la subida. Las formas simples y el contraste definido funcionan mejor que un logotipo textual completo.
  • La URL del sitio publicado: Tenla abierta en otra pestaña para distinguir la vista previa del editor de lo que ven los visitantes.

Añade un favicon de Weebly en 7 pasos

1. Prepara un icono limpio y cuadrado

Abre tu logotipo en un editor de imágenes o un conversor de favicon y elimina el espacio sobrante que hace que la marca parezca demasiado pequeña. Exporta un PNG cuadrado con un fondo transparente o sólido y compruébalo a 16 × 16 píxeles; si la forma desaparece, simplifícala.

Conserva también el diseño original. Puedes usar el PNG para la subida al editor y generar archivos SVG o ICO de varios tamaños más adelante si necesitas un conjunto personalizado.

2. Abre los ajustes del sitio en Weebly

Inicia sesión en Weebly, abre el editor del sitio y selecciona Settings; después, Site Settings. Entra en Basic y busca el control de subida de Favicon. Si aparece en otra parte del editor, usa el control etiquetado como Favicon en lugar de un campo de logotipo o miniatura.

Si no ves el control, pide al propietario del sitio que compruebe tu plan y tus permisos en el editor antes de continuar. Así evitas añadir un segundo sistema de iconos mientras la herramienta de subida nativa todavía está disponible.

3. Sube la imagen

Selecciona Upload, elige tu PNG cuadrado y espera a que aparezca la vista previa. Confirma que la marca llena el encuadre en lugar de quedar dentro de un borde vacío grande y, después, guarda los ajustes del sitio. Usa un PNG real; cambiar el nombre de una imagen guardada en otro formato no la convierte.

4. Publica el cambio

Haz clic en Publish en el editor de Weebly y espera a que el sitio esté en línea. Abre la dirección del sitio en una pestaña nueva; la vista previa del editor, por sí sola, no demuestra que los visitantes puedan obtener el nuevo icono.

5. Inspecciona el enlace del icono en la página publicada

En la página publicada, abre las herramientas de desarrollo del navegador e inspecciona el <head> del documento. Busca una declaración de icono parecida a esta:

<link rel='icon' type='image/png' href='https://example.com/favicon.png'>

La ruta example.com es un marcador de posición; cuando utilizas la herramienta de carga nativa, la URL es la que generó Weebly. El enlace rel='icon' es el mecanismo estándar de HTML para referenciar un icono externo, tal como se explica en el HTML Standard. Este enlace proporciona al navegador un candidato que puede solicitar.

6. Añade variantes avanzadas solo si las necesitas

La herramienta de carga nativa es suficiente para el icono habitual de una pestaña del navegador. Si gestionas archivos separados y tu plan de Weebly ofrece un campo Head Code en la configuración avanzada del sitio, puedes añadir un stack más explícito.

<link rel='icon' href='/favicon.ico' sizes='16x16 32x32 48x48'>
<link rel='icon' type='image/png' href='/favicon-32.png' sizes='32x32'>
<link rel='icon' type='image/svg+xml' href='/favicon.svg'>
<link rel='apple-touch-icon' href='/apple-touch-icon.png'>

Sustituye cada ruta de ejemplo por una URL real y accesible públicamente. No añadas estas etiquetas cuando la carga nativa ya cubra tus necesidades y retira cualquier stack personalizado anterior antes de añadir otro.

7. Verifica la respuesta y la pestaña

Recarga la página publicada, cambia a una ventana privada e inspecciona el panel Network del navegador para localizar la solicitud del icono. La solicitud debería devolver la imagen en lugar de 404 Not Found, y la pestaña o el marcador debe mostrar la marca que has subido.

Si te cuesta inspeccionar la URL, pega la URL exacta del icono en una pestaña nueva. Deberías recibir el archivo de imagen, no una página de error HTML. Después de sustituir un icono existente, ten en cuenta la caché del navegador o prueba en una ventana privada nueva.

Problemas habituales

  • El editor ha cambiado, pero el sitio no se ha publicado. Vuelve a publicar y luego carga la dirección del sitio publicado, no una vista previa sin publicar.
  • El icono antiguo sigue almacenado en caché. Prueba en una ventana de incógnito y haz una recarga forzada. Si el markup y la imagen del sitio publicado son correctos, sigue la lista para solucionar problemas con el favicon.
  • La URL del icono devuelve un error 404. Inspecciona el href en las herramientas de desarrollo y ábrela directamente. No supongas que el archivo está en /favicon.ico; utiliza la URL real del sitio publicado.
  • Varias etiquetas de icono dificultan la configuración. Elimina el código personalizado obsoleto o las cargas duplicadas y conserva un único conjunto deliberado de declaraciones.
  • La marca tiene demasiado detalle. Reconstruye el icono a partir del símbolo principal del logotipo, elimina el texto diminuto y comprueba su apariencia a 16 píxeles.
  • Falta el campo Favicon. Confirma que la persona propietaria del sitio puede acceder a la configuración del sitio y que tu cuenta tiene permiso para modificarlo.

Comprobación final

Un favicon de Weebly está completo cuando el editor muestra el icono previsto, el sitio se ha publicado, el head del sitio publicado contiene un enlace válido al icono y esa URL devuelve el archivo de imagen. Conserva juntos el PNG de origen cuadrado y las variantes generadas para que la próxima sustitución no vuelva a introducir problemas de tamaño o de ruta.
