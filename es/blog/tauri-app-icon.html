Icono de Tauri: Configura para Windows, macOS y Linux

Has creado una app con Tauri, pero el icono predeterminado sigue apareciendo en la barra de tareas. O quizás estás a punto de lanzarla y te das cuenta de que el icono del dock es un marcador de posición genérico. Configurar un icono de app Tauri adecuado es sencillo una vez que sabes dónde van los archivos y cómo los referencia la configuración. Esta guía te explica los pasos exactos para Windows, macOS y Linux, usando el generador de iconos integrado de Tauri y la configuración de tauri.conf.json.

Requisitos previos

Antes de empezar, asegúrate de tener:

  • Un proyecto Tauri (v1 o v2) ya configurado.
  • Node.js y npm instalados (o tu gestor de paquetes preferido).
  • Una imagen fuente cuadrada, preferiblemente PNG de 1024×1024 con transparencia. SVG también funciona, pero PNG es más seguro para el generador.

Si necesitas un icono fuente de alta calidad, puedes crear uno a partir de tu logo o favicon existente usando Mzu favicondl — exporta PNGs limpios en varios tamaños.

Paso 1: Genera el conjunto de iconos

Tauri proporciona un comando CLI que toma una única imagen fuente y produce todos los formatos específicos de cada plataforma: .ico para Windows, .icns para macOS y varios PNGs para Linux y móvil. Ejecuta esto desde la raíz de tu proyecto:

npm run tauri icon path/to/your-icon.png

Si usas Tauri v1, el comando también es npm run tauri icon, pero revisa los scripts de tu package.json. El generador escribe los archivos en src-tauri/icons/ por defecto. Verás archivos como 32x32.png, 128x128.png, icon.icns e icon.ico.

Consejo: La imagen fuente debe tener fondo transparente y una silueta clara. Evita texto o detalles finos — no sobrevivirán a 16×16 o 32×32. Para orientación sobre diseño, consulta nuestros consejos de diseño de favicon (los mismos principios se aplican a los iconos de app).

Paso 2: Configura tauri.conf.json

Abre src-tauri/tauri.conf.json y localiza la sección bundle. En icon, enumera las rutas a los iconos generados. Tauri v2 usa una estructura ligeramente diferente a v1, pero el concepto es el mismo.

Para Tauri v2:

{
  "bundle": {
    "icon": [
      "icons/32x32.png",
      "icons/128x128.png",
      "icons/128x128@2x.png",
      "icons/icon.icns",
      "icons/icon.ico"
    ]
  }
}

Para Tauri v1, el array icon se encuentra bajo tauri.bundle:

{
  "tauri": {
    "bundle": {
      "icon": [
        "icons/32x32.png",
        "icons/128x128.png",
        "icons/icon.icns",
        "icons/icon.ico"
      ]
    }
  }
}

Asegúrate de que las rutas sean relativas a src-tauri/. Si moviste los iconos a otro lugar, actualiza las rutas en consecuencia.

Paso 3: Verifica el comportamiento específico de cada plataforma

Cada sistema operativo utiliza un archivo diferente de la lista. Esto es lo que importa:

  • Windows: Usa icon.ico para el ejecutable, la barra de tareas y el menú Inicio. El ICO debe contener múltiples tamaños (16, 32, 48, 256). El generador de Tauri se encarga de esto.
  • macOS: Usa icon.icns para el dock y Finder. El formato ICNS incluye múltiples resoluciones hasta 1024×1024.
  • Linux: Usa los PNG (típicamente 32x32, 128x128, 128x128@2x) para el lanzador de aplicaciones y el gestor de ventanas. Algunos entornos de escritorio también leen icon.png del bundle.

Si estás compilando para móvil (iOS/Android), el generador también crea los recursos apropiados, pero eso está fuera del alcance de esta guía.

Paso 4: Recompila y prueba

Después de actualizar la configuración, recompila tu aplicación:

npm run tauri build

Luego instala o ejecuta el ejecutable compilado. Revisa la barra de tareas (Windows), el dock (macOS) o el menú de aplicaciones (Linux) para confirmar que el icono aparece. En Windows, es posible que necesites borrar la caché de iconos si el icono antiguo persiste — una peculiaridad conocida. En macOS, a veces el dock almacena en caché los iconos; cerrar sesión y volver a iniciarla lo resuelve.

Errores comunes

  • Ruta incorrecta en la configuración: Tauri fallará al empaquetar si el archivo de icono no existe. Verifica dos veces las rutas relativas.
  • Tamaños ICO faltantes: Si creas manualmente un ICO, asegúrate de que incluya capas de 16, 32, 48 y 256 píxeles. El generador de Tauri lo hace correctamente.
  • Problemas con fondos transparentes: En Windows, las áreas totalmente transparentes pueden aparecer en negro en algunos contextos. Usa un fondo sólido si ves artefactos.
  • Olvidar reconstruir: Cambiar el icono requiere una reconstrucción completa; la recarga en caliente no actualizará el icono nativo.
  • Formato ICNS en macOS: Si proporcionas un PNG en lugar de ICNS, macOS puede ignorarlo. Usa siempre el icon.icns generado.

Conclusión

Establecer un icono de aplicación Tauri es un proceso de tres pasos: genera el conjunto de iconos con tauri icon, haz referencia a los archivos en tauri.conf.json y reconstruye. El generador integrado te evita crear manualmente archivos ICO e ICNS. Mantén tu imagen de origen simple y cuadrada, y verifica el icono en cada plataforma de destino.
