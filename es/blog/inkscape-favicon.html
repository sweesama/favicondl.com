Favicon en Inkscape: crea y exporta un icono nítido

Si tu diseño de Inkscape se ve bien en el lienzo, pero queda recortado y borroso en una pestaña del navegador, el problema suele estar en el documento, no en el formato de exportación. Un favicon de Inkscape necesita un dibujo cuadrado, trazados portables y un pequeño conjunto de archivos preparados para la web.

Requisitos previos

Necesitas Inkscape y un logotipo SVG existente. Si la ilustración está situada en una página ancha, crea un documento cuadrado nuevo, copia y escala la marca de forma proporcional y conserva ese archivo como maestro editable. Un símbolo reconocible dará un mejor resultado a 16×16 píxeles que un wordmark completo.

Por ejemplo, si el archivo de origen es un wordmark de 1200×400, no fuerces ese rectángulo para encajarlo en el favicon. Selecciona solo el símbolo, pégalo en el documento cuadrado y escálalo de forma proporcional. Así crearás un maestro compacto que podrás exportar repetidamente sin alterar la ilustración original.

  • Usa un artboard de 128×128 píxeles como tamaño práctico para el diseño.
  • Mantén la marca centrada, con un poco de espacio transparente alrededor.
  • Elimina los detalles que no puedan seguir siendo distinguibles a tamaños pequeños.

1. Configura un lienzo cuadrado y un viewBox

Abre File → Document Properties, establece las unidades en píxeles y asigna al documento un ancho y una altura iguales. El tamaño de 128×128 es una recomendación, no un requisito del navegador; 64×64 también funciona. Para un documento de 128×128, comprueba que el viewBox indique 0 0 128 128.

Usa Object → Align and Distribute, elige Page como referencia y centra la ilustración horizontal y verticalmente. Comprueba que la vista previa de la página sea cuadrada y que ningún borde quede recortado.

2. Convierte el texto y los efectos frágiles en trazados

Selecciona cada objeto de texto y elige Path → Object to Path. Esto evita que un servidor que no disponga de tu fuente sustituya la forma por otra.

Usa Path → Stroke to Path para los trazos discontinuos o con contorno que sean esenciales. Conserva los degradados, las máscaras y los filtros solo cuando sean necesarios, porque añaden puntos de fallo cuando el SVG se sirve en distintos entornos.

3. Guarda un SVG portable

Elige File → Save As, selecciona Plain SVG y guarda la copia como favicon.svg.

Antes de convertir el SVG, comprueba que las propiedades del documento contengan un viewBox cuadrado y que el diseño no dependa de una fuente externa, una imagen bitmap vinculada o una hoja de estilos. Si el logo contiene una imagen vinculada, colócala junto al SVG y vuelve a enlazarla de forma deliberada, o sustitúyela por un equivalente vectorial.

4. Exporta un PNG de respaldo de 512×512

Usa File → Export PNG Image, elige la página como área de exportación y establece ambas dimensiones en 512 píxeles. Mantén el fondo transparente y exporta favicon-512.png.

Este PNG de alta resolución proporciona al conversor suficientes píxeles para crear imágenes rasterizadas de tamaño pequeño sin pedir al navegador que amplíe una imagen de origen diminuta.

Para obtener exportaciones reproducibles, también puedes ejecutar:

inkscape favicon.svg --export-type=png --export-area-page --export-width=512 --export-height=512 --export-filename=favicon-512.png

El comando utiliza los límites cuadrados de la página y escribe un PNG de 512 píxeles en el directorio de trabajo actual.

5. Crea un paquete de favicon para Inkscape

Abre Mzu favicondl, sube favicon.svg o favicon-512.png, genera un ICO con varios tamaños y descárgalo. Recomendamos un ICO que contenga imágenes de 16×16, 32×32 y 48×48. Solicita también un PNG de 180×180 llamado apple-touch-icon.png.

Si quieres conocer el proceso exacto de empaquetado, consulta la guía para convertir SVG en ICO; la guía sobre tamaños de favicon cubre los tamaños adicionales de PNG y los de Apple.

El HTML Standard define rel='icon' como un enlace a un recurso externo que representa la página en la interfaz de usuario. Esa definición no impone un formato de archivo concreto, por lo que, para la compatibilidad, recomendamos usar SVG junto con un ICO de respaldo.

6. Despliega los archivos y el HTML

Coloca favicon.ico, favicon.svg y apple-touch-icon.png en rutas desde las que tu sitio pueda servir esos archivos. Añade los enlaces dentro de <head>:

<link rel='icon' href='/favicon.ico'>
<link rel='icon' href='/favicon.svg' type='image/svg+xml'>
<link rel='apple-touch-icon' href='/apple-touch-icon.png' sizes='180x180'>

Usa rutas relativas a la raíz solo cuando coincidan con la raíz de despliegue. En una aplicación servida bajo un subpath, actualiza las rutas o hazlas relativas. Conserva el ICO como fallback y el SVG como maestro escalable.

7. Verifica la respuesta en producción

Abre el sitio, haz una hard reload e inspecciona el panel Network para cada URL del icono. Confirma que la solicitud devuelve 200 y una respuesta de imagen, no la página HTML 404 del sitio.

Abre /favicon.svg directamente para confirmar que el SVG se renderiza. Si el icono anterior persiste, comprueba primero que el navegador haya solicitado la nueva URL antes de cambiar el despliegue.

También puedes inspeccionar la respuesta del ICO desde una terminal:

curl -I https://example.com/favicon.ico

Sustituye la URL por tu propio dominio y repite la comprobación con los archivos SVG y PNG.

Problemas habituales

  • El diseño está recortado. Exporta desde una página cuadrada, no desde el lienzo horizontal original.
  • El texto cambia de forma. Convierte el texto en trazados antes de guardar el SVG final.
  • Los recursos vinculados fallan. Sustituye los bitmaps vinculados por diseño vectorial o inclúyelos en una ruta relativa estable y elimina las dependencias de hojas de estilos externas.
  • El icono parece vacío. Inspeciónalo a 16×16 y simplifica la silueta, el espaciado y el contraste.
  • El icono anterior persiste. Revisa el código fuente HTML y el panel Network antes de culpar a la caché.
  • El icono aparece estirado. Mantén el viewBox cuadrado y exporta un PNG cuadrado; sizes no redimensiona el diseño.

Crea un flujo de trabajo repetible

Ahora tienes un flujo de trabajo repetible de favicon de Inkscape: un maestro vectorial cuadrado, texto convertido en trazados, un SVG portable, un PNG de 512 píxeles, un fallback ICO y enlaces HTML explícitos. Mantén el SVG maestro sin cambios para que las exportaciones futuras sigan siendo coherentes.
