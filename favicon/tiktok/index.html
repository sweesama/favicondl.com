TikTok Favicon (favicon.ico)

Logos and favicons belong to their owners and are shown here for reference. This is not an endorsement and it is not a license to use the mark.

TikTok’s website icon is the note-shaped mark tiktok.com serves for its web app. A phone’s installed app icon can be a different asset, so only the downloaded web files are shown.

Checked 12 November 2026 against tiktok.com. HTML came from https://www.tiktok.com/ (HTTP 200). No icon link tags were readable in the HTML. Files below came from a manifest or from a path that returned an image.

A request to the favicon.ico URL https://www.tiktok.com/favicon.ico returned png (32×32, 842 bytes), not an ICO container. Formats that saved: png.

The apple-touch-icon URL is https://www.tiktok.com/apple-touch-icon.png, measured at 400×400 png.

Brand colour #ffffff comes from the manifest theme_color.

Largest measured bitmap: png-512x512-03.png at 512×512 (png, 16070 bytes) from https://sf16-sg.tiktokcdn.com/obj/eden-sg/uvkuhyieh7lpqpbj/pwa/512x512.png.

FAQ

What is the TikTok favicon.ico URL?

The URL https://www.tiktok.com/favicon.ico did not return an ICO container on 12 November 2026. The files that did download are listed in the table.

What are the TikTok favicon dimensions?

The pixel sizes below were read from the files, not from a generic size chart. png-400x400-01.png: 400×400 (PNG IHDR) png-32x32-02.png: 32×32 (PNG IHDR) png-512x512-03.png: 512×512 (PNG IHDR) png-384x384-04.png: 384×384 (PNG IHDR) png-256x256-05.png: 256×256 (PNG IHDR) png-192x192-06.png: 192×192 (PNG IHDR) png-128x128-07.png: 128×128 (PNG IHDR)

What apple-touch-icon does TikTok publish?

Yes. https://www.tiktok.com/apple-touch-icon.png saved as png-400x400-01.png.

What brand colour does the TikTok favicon page record?

#ffffff, from the manifest theme_color.

Which icon files were saved for TikTok?
