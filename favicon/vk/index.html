VK Favicon (favicon.ico)

Logos and favicons belong to their owners and are shown here for reference. This is not an endorsement and it is not a license to use the mark.

VK is the social network at vk.com. The homepage often redirects to a mobile host on the same domain. The icon files are the ones that host, or its icon links, actually returned.

Checked 12 November 2026 against vk.com. HTML came from https://vk.com/ (HTTP 200). Icon link tags: shortcut icon → https://vk.com/images/icons/favicons/fav_logo.ico?8; apple-touch-icon → https://vk.com/images/icons/pwa/apple/default.png?15.

No favicon.ico URL returned an image on 12 November 2026. vk.com did not pass the image check for an .ico path. Formats that did save: png.

The apple-touch-icon URL is https://vk.com/images/icons/pwa/apple/default.png?15, measured at 512×512 png.

Brand colour #ffffff comes from the theme-color meta tag.

How this compares with a normal favicon set

A site you publish yourself usually needs a different set from the one VK happens to ship: 16×16, 32×32 and 48×48 in one favicon.ico, a 180×180 apple-touch icon, and 192×192 plus 512×512 manifest PNGs. That chart is the favicon dimensions guide. Use these saved files as a reference, then build your own with the PNG to favicon converter.
