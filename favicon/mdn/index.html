How this compares with a normal favicon set

A site you publish yourself usually needs a different set from the one MDN Web Docs happens to ship: 16×16, 32×32 and 48×48 in one favicon.ico, a 180×180 apple-touch icon, and 192×192 plus 512×512 manifest PNGs. That chart, including 96×96, maskable icons, Windows tiles and SVG, is the favicon dimensions guide. Use MDN Web Docs’s files as a reference, then build your own with the PNG to favicon converter.

FAQ

What is the MDN Web Docs favicon.ico URL?

The URL https://developer.mozilla.org/favicon.ico did not return an ICO container on 12 November 2026. The files that did download are listed in the table.

What are the MDN Web Docs favicon dimensions?

The pixel sizes below were read from the files, not from a generic size chart. png-192x192-01.png: 192×192 (PNG IHDR) png-48x48-02.png: 48×48 (PNG IHDR) svg-56x56-03.svg: 56×56 (SVG width and height attributes) png-512x512-04.png: 512×512 (PNG IHDR)

What apple-touch-icon does MDN Web Docs publish?

Yes. https://developer.mozilla.org/apple-touch-icon.png saved as png-192x192-01.png.

What brand colour does the MDN Web Docs favicon page record?

#000000, from the manifest theme_color.

Which icon files were saved for MDN Web Docs?

On 12 November 2026 these image files were downloaded for developer.mozilla.org: png-192x192-01.png (png, 2171 bytes, 192×192); png-48x48-02.png (png, 763 bytes, 48×48); svg-56x56-03.svg (svg, 536 bytes, 56×56); png-512x512-04.png (png, 4849 bytes, 512×512).

May I use the MDN Web Docs icon on my own site?

No. Logos and favicons belong to their owners and are shown here for reference so you can see the real format and dimensions. For your own site, make a file with the PNG to favicon converter or download a site you control.
