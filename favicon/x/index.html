How this compares with a normal favicon set

A site you publish yourself usually needs a different set from the one X (Twitter) happens to ship: 16×16, 32×32 and 48×48 in one favicon.ico, a 180×180 apple-touch icon, and 192×192 plus 512×512 manifest PNGs. That chart, including 96×96, maskable icons, Windows tiles and SVG, is the favicon dimensions guide. Use X (Twitter)’s files as a reference, then build your own with the PNG to favicon converter.

FAQ

What is the X (Twitter) favicon.ico URL?

The URL https://x.com/favicon.ico did not return an ICO container on 12 November 2026. The files that did download are listed in the table.

What are the X (Twitter) favicon dimensions?

The pixel sizes below were read from the files, not from a generic size chart. png-1024x1024-01.png: 1024×1024 (PNG IHDR) png-32x32-02.png: 32×32 (PNG IHDR) png-512x512-03.png: 512×512 (PNG IHDR) png-512x512-04.png: 512×512 (PNG IHDR) png-192x192-05.png: 192×192 (PNG IHDR) png-192x192-06.png: 192×192 (PNG IHDR)

What apple-touch-icon does X (Twitter) publish?

Yes. https://x.com/apple-touch-icon.png saved as png-1024x1024-01.png.

What brand colour does the X (Twitter) favicon page record?

#ffffff, from the theme-color meta tag (media query).

Which icon files were saved for X (Twitter)?

May I use the X (Twitter) icon on my own site?
