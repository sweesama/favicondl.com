How this compares with a normal favicon set

A site you publish yourself usually needs a different set from the one Microsoft happens to ship: 16×16, 32×32 and 48×48 in one favicon.ico, a 180×180 apple-touch icon, and 192×192 plus 512×512 manifest PNGs. That chart, including 96×96, maskable icons, Windows tiles and SVG, is the favicon dimensions guide. Use Microsoft’s files as a reference, then build your own with the PNG to favicon converter.
