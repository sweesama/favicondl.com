How to download favicons in bulk

  1. Paste your list. Enter one domain per line in the box above, up to 100 at a time. Plain domains (github.com) and full URLs both work; the protocol, www. and any path are stripped automatically. Lines without a dot are skipped.
  2. Choose your options. Pick a size, choose ZIP or individual files, and decide whether files are named by domain (github.com-favicon.png) or by position in your list (001-github.com-favicon.png).
  3. Start and download. Click Start. Up to six sites are looked up in parallel and a progress bar shows how far along you are. Check the preview grid, then click Download ZIP (or Download all files).

Where the icons come from

Each domain goes through the same favicon extractor as our single-site favicon downloader. It reads the <link rel="icon"> and Apple touch icon tags and the web app manifest on the homepage, tries well-known files such as /favicon.ico and /apple-touch-icon.png, checks that each file really is an image, and prefers SVG and large PNG icons over small ICO files.

If a site blocks automated requests or has no icon, the tool falls back to Google's public favicon service, so every row in your list still gets an image. The preview grid shows each result before you download, so you can spot the generic ones.

Common uses

  • Link directories and resource lists: add an icon next to every tool or site you list.
  • Dashboards and internal tools: show which service each row, integration or alert belongs to.
  • Bookmark and tab managers: pre-load icons for a known set of sites.
  • Competitor and market research: put brand icons beside a spreadsheet of companies.

Need this in code instead of a browser? The free favicon API returns the same icons for one domain per request, with no API key.

Frequently asked questions

How many websites can I download at once?

Up to 100 domains per run. For a longer list, split it into batches of 100.

Is the bulk favicon downloader free?

Yes. There is no account, no API key and no payment. Please keep runs to lists you actually need.

Why do some icons look like a generic globe?

That site either has no favicon or blocked our lookup, so the result came from Google's fallback service. Try the single-site favicon downloader for that domain, which also tries a few extra sources from your browser.

Can I upload a CSV file?

Not directly. Copy the column of domains from your spreadsheet and paste it into the box; each line becomes one domain.

Can I use the downloaded favicons?

Favicons are usually part of a company's logo or trademark. Showing them next to links to those sites is common practice; using them as your own branding is not. Check each brand's guidelines if you are unsure.
