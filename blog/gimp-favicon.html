GIMP Favicon ICO: Create a Crisp Multi-Size Website Favicon

A 48-pixel GIMP export can look sharp on your monitor yet become a muddy square in a browser tab. The fix is to prepare separate 16, 32, and 48 pixel versions in GIMP, then package them as one multi-size favicon.ico. This GIMP favicon ICO workflow gives you predictable files instead of relying on a renamed PNG.

Prerequisites

  • Use GIMP with the File > New, Image > Scale Image, and File > Export As commands.
  • Prepare a square logo or mark. A 512 × 512 pixel master gives you room to simplify the artwork before scaling it down.
  • Optionally install ImageMagick for the final packing step. You can instead use Mzu favicondl to convert the PNG exports in your browser.

Create the favicon ICO step by step

  1. Create a transparent master

    Choose File > New, set both dimensions to 512 × 512, and select Fill with Transparency. Import your logo or draw the mark in GIMP. Keep the main silhouette inside a central square so padding remains visible at small sizes.

    A favicon is not a shrunken logo. Reduce tiny lettering, thin strokes, and gradients before export; a single bold shape will usually stay clearer.

  2. Create each size from the master

    Use File > Duplicate to make a copy of the master, then choose Image > Scale Image. With the width and height linked, scale one copy to 16 × 16, another to 32 × 32, and the third to 48 × 48. Scale each copy from the 512-pixel original; enlarging the 16-pixel version will only make its edges softer.

  3. Retouch the 16-pixel version

    Open the 16-pixel copy and enable View > Show Pixel Grid. Zoom in, then remove details that merge into neighboring pixels or adjust the mark's alignment. Repeat the check at 32 pixels, where more detail can survive but weak one-pixel strokes may still disappear.

  4. Preserve alpha transparency

    If an imported layer has no alpha channel, select it and choose Layer > Transparency > Add Alpha Channel. Leave the background transparent instead of filling it with white. PNG export preserves this transparency, giving the ICO encoder a clean source image.

  5. Export three PNG files

    Choose File > Export As, enter icon-16.png, and click Export. Repeat for icon-32.png and icon-48.png, keeping them in one folder. Use the PNG versions as packaging sources because they preserve the exact dimensions and alpha channel.

  6. Export or pack the ICO

    To try GIMP's ICO exporter, select the 48-pixel copy, choose File > Export As, enter favicon.ico, and inspect the export options. If a size list appears, select 16, 32, and 48 pixels. If no list appears, the export may contain only the current canvas, so package the three PNGs explicitly.

    Run this command from the folder containing the PNG files:

    magick -background none icon-16.png icon-32.png icon-48.png favicon.ico

    On systems where the command is named convert, replace magick with convert. The result is one ICO containing three image sizes.

  7. Verify the embedded sizes

    If you installed ImageMagick, run magick identify favicon.ico and check that the output lists 16x16, 32x32, and 48x48 entries. If a size is missing, inspect that PNG in GIMP and repeat the packing command. Also open each PNG at high zoom to confirm that the icon has no white background or newly blurred edges.

  8. Deploy the ICO

    Copy favicon.ico to your site's public root, then link it from the document <head>:

    <link rel='icon' href='/favicon.ico' sizes='16x16 32x32 48x48'>

    The HTML standard defines rel='icon' for linking an icon resource. If your site lives under a subpath, adjust the URL. For the complete markup and mobile icon variants, see how to add a favicon to your website.

Common GIMP favicon ICO pitfalls

  • Only one resolution is present. Verify the container instead of judging it by its filename. The 16, 32, and 48 pixel set is a practical browser baseline; the favicon size guide explains where other formats belong.
  • The small icon is muddy. Simplify the artwork, not just the scale. Fine text and one-pixel details that look acceptable at 48 pixels can close up at 16 pixels.
  • Transparency disappears. Add an alpha channel before export and avoid flattening onto a white or theme-colored background.
  • The live site keeps the old icon. Confirm that /favicon.ico returns the ICO rather than an HTML error page, then deploy with a versioned URL such as /favicon.ico?v=2 if the old file remains cached.

Make the result predictable

Separate artwork preparation from container packaging. GIMP gives you control over every small-size rendering, while the packing step guarantees which resolutions are inside favicon.ico.
