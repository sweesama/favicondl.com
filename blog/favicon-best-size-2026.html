Favicon Dimensions & Sizes (2026): Complete Size Chart

Favicon dimensions are the pixel sizes each surface uses in 2026. Publish the rows below: the browser tab, the Apple home screen, and Android each read a different file.

ICO, SVG, Windows tiles, and Safari pinned tabs

favicon.ico is a container, not a renamed PNG. Put 16×16, 32×32, and 48×48 in that one file and serve it at /favicon.ico, because browsers still request that path. The browser or operating system picks a layer: 16 for a standard tab, 32 for a high-DPI tab, and 48 for a Windows shortcut. Leave 256×256 artwork in a PNG or an SVG so the ICO stays small. How the container stores PNG or BMP images is covered in favicon file formats.

An SVG favicon has no pixel dimensions. Link it with type="image/svg+xml" and sizes="any". Current Chrome, Firefox, Edge, and Safari draw it in the tab. Google Search lists BMP, GIF, ICO, PNG, JPEG, PPM, and TIFF as favicon formats, and SVG is not on that list, so the home page still needs the ICO or a PNG. Google asks for a square icon of at least 8×8 px and recommends one larger than 48×48 px. 96×96 is only a convenient size in that range. It is not a separate platform file, and the tab, the apple-touch icon, and the manifest still use the rows in the chart.

Windows 8 and Internet Explorer used tile images at 70×70, 144×144, 150×150, 310×150, and 310×310, declared with msapplication meta tags. Current Edge reads the web app manifest, so those tiles sit outside the 2026 set.

Safari pinned tabs can tint a separate single-color SVG, linked with rel="mask-icon". That artwork is one black shape on a transparent background, with viewBox="0 0 16 16". It is not the SVG favicon, and the browser tab does not need it. The line in the snippet below is optional.

Android may mask the launcher icon to a circle, squircle, or rounded square. When the artwork needs padding, publish a separate 512×512 PNG with purpose maskable and keep the mark inside a centered circle whose radius is 2/5 of the side (about 205 px on a 512 px icon). The purpose any icons are still required. The safe zone, the Google rule, and the per-platform markup are in the favicon size by platform guide.

HTML link tags

Paste this into the <head> of the home page. sizes="48x48" on the ICO marks that file as a fixed-size fallback; the file itself still contains 16, 32, and 48. The 192 and 512 PNGs are named by the manifest, not by extra rel="icon" tags.

<link rel="icon" href="/favicon.ico" sizes="48x48">
<link rel="icon" href="/icon.svg" type="image/svg+xml" sizes="any">
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">
<link rel="mask-icon" href="/safari-pinned-tab.svg" color="#000000">
{
  "icons": [
    { "src": "/icon-192.png", "type": "image/png", "sizes": "192x192", "purpose": "any" },
    { "src": "/icon-512.png", "type": "image/png", "sizes": "512x512", "purpose": "any" },
    { "src": "/icon-maskable-512.png", "type": "image/png", "sizes": "512x512", "purpose": "maskable" }
  ]
}

Sizes current platforms scale for you

Current iOS reads the single 180×180 apple-touch icon and scales it. The older home-screen sizes were 57×57, 72×72, 76×76, 114×114, 120×120, 144×144, 152×152, and 167×167. apple-touch-icon-precomposed only stopped a gloss effect that ended with iOS 7. Use an opaque PNG: on older iOS, transparent pixels can turn black.

To see which of these files a live site publishes, paste the domain into the favicon checker.

FAQ

What are the standard favicon dimensions?

The standard favicon dimensions to publish are 16×16, 32×32 and 48×48 inside one favicon.ico, a 32×32 PNG for the tab, a 180×180 apple-touch-icon, and 192×192 plus 512×512 PNGs in the web app manifest. An SVG favicon has no fixed pixel size.

Is there one best favicon size in 2026?

No single pixel size covers every surface. Publish the chart on this page: the ICO layers for the tab, 180×180 for the Apple home screen, and 192×192 plus 512×512 for Android and a PWA. Current iOS scales the 180×180 file, so the older sizes 57, 72, 76, 120, 152 and 167 do not need their own files.

Is the apple-touch-icon still 180×180?

Yes. Publish one opaque 180×180 PNG and reference it with rel="apple-touch-icon". Current iOS scales that file for iPhone and iPad. On older iOS, transparent pixels can turn black, so use a solid background.

What favicon dimensions does the Android manifest use?

192×192 and 512×512, both with purpose set to any. 192×192 is the home-screen icon, equal to 48 dp at 4× density. 512×512 is the install and splash icon. Add a separate 512×512 PNG with purpose maskable when the launcher crops the icon to a circle or squircle.

Does an SVG favicon have pixel dimensions?

No. An SVG favicon scales. Declare it with rel="icon", type="image/svg+xml" and sizes="any". Current Chrome, Firefox, Edge and Safari use it in the tab. Keep the ICO and PNG fallback. Google Search does not list SVG as a favicon format, so the home page still needs an ICO or PNG.

Does favicon.ico need more than one size?

Yes. A .ico file is a container. Put 16×16, 32×32 and 48×48 in that one file: 16 for a standard tab, 32 for a high-DPI tab, and 48 for a Windows desktop shortcut. Keep larger artwork in PNG or SVG so the ICO stays small.
