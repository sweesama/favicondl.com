Favicon Not Showing in Google Search? A Verified Checklist

A favicon can appear correctly in a browser tab and still be absent from Google Search. Those are separate systems. Google decides whether to show a site favicon, and its documentation says that display is not guaranteed even when every guideline is met.

Use the checks below before changing files repeatedly. They follow the current Google Search favicon documentation, last updated February 4, 2026.

1. Check the home page declaration

Google reads the favicon declaration from the home page of each hostname. The page should contain a valid icon link such as:

<link rel='icon' href='/favicon.ico'>

The icon URL may be relative or absolute. A root-relative path is convenient, but it is not a special ranking requirement. Open the live home page source—not only the browser's rendered DOM—and confirm that the declared URL is the one you intend to keep.

2. Verify crawl access and the file response

Google says Googlebot must be able to crawl the home page and Googlebot-Image must be able to crawl the icon file. Check that neither URL is blocked by robots.txt, authentication, or a security rule.

  • Open the icon URL directly and confirm that it returns an image, not an HTML error page.
  • Keep the favicon URL stable instead of changing it on every deployment.
  • Use a square image. Google's minimum is 8×8 pixels and it recommends an image larger than 48×48 pixels.
  • Use a valid favicon format and artwork that represents the site.

3. Separate requirements from guesses

Google does not publish a 3 KB file-size limit, a mandatory 48×48 file, or a fixed manifest-first discovery order in this guidance. Do not rebuild your stack around those claims. Likewise, a missing icon is not proof that a CDN or firewall blocked Googlebot; verify the actual response before changing security settings.

If the browser icon itself is broken, diagnose that first with the general favicon troubleshooting guide. Search-result processing cannot repair an invalid source file.

4. Request recrawling, then allow time

After fixing the live home page, use URL Inspection in Google Search Console to inspect and request indexing for the home page. Google notes that recrawling and processing can take from several days to several weeks. Repeatedly renaming the icon during that period resets the stable signal you are trying to establish.

If the page and file meet the documented rules, the remaining step may simply be waiting. Eligibility is something you can verify; appearance in the result is still Google's choice.
