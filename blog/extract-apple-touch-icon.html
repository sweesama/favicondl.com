How to Extract Apple Touch Icon from Any Website in 2026

You've seen it happen. You open a site on your iPhone, and Safari shows a crisp, branded icon on the home screen. Your own site? A generic screenshot of the page. That's the difference an Apple Touch Icon makes — and if you're building a new project, you probably want to borrow inspiration from the best.

But finding that icon file isn't always straightforward. Unlike a regular favicon that sits at /favicon.ico, Apple Touch Icons hide in <link> tags or manifest.json files. Here's how to extract an Apple Touch Icon from any website — without guessing URLs.

Why Apple Touch Icons Are Harder to Find

Most developers know the standard favicon URL pattern. Apple, however, decided to make things interesting. The icon can be named apple-touch-icon.png, apple-touch-icon-precomposed.png, or live inside a web app manifest. There's no single convention.

Take GitHub. Their Apple Touch Icon isn't at the root. It's served from https://github.githubassets.com/assets/apple-touch-icon-... with a hash in the filename. If you tried guessing /apple-touch-icon.png, you'd get a 404.

The Three Places Apple Touch Icons Hide

Before you start digging, know where to look:

  • HTML <link> tags — The most common location. Look for rel='apple-touch-icon' or rel='apple-touch-icon-precomposed'.
  • Web App Manifest — Some sites define icons in manifest.json under the icons array with sizes like 180x180.
  • Root directory — A few sites still use the legacy /apple-touch-icon.png path, but this is increasingly rare.

Method 1: Extract via Browser DevTools (The Manual Way)

This is the fastest method for a quick look. Open any website, right-click, and select 'Inspect' (or press F12). Navigate to the 'Elements' tab and search for 'apple-touch-icon' using Ctrl+F (Cmd+F on Mac).

You'll see something like this:

<link rel='apple-touch-icon' sizes='180x180' href='/path/to/icon-180.png'>

Copy the href value. If it's a relative path (like /path/to/icon-180.png), prepend the site's domain. Open that URL in a new tab, and you have the icon.

What If the Link Tag Is Missing?

Some sites, especially modern PWAs, skip the HTML tag entirely and rely on the manifest. In that case, look for:

<link rel='manifest' href='/manifest.json'>

Open that JSON file, and search for an object with sizes: '180x180' or sizes: '192x192'. That's your Apple Touch Icon.

Method 2: Use Mzu favicondl (The Smart Way)

If you're extracting icons regularly — maybe you're auditing competitor sites or collecting design references — the manual approach gets old fast. That's where Mzu favicondl comes in.

Paste the website URL into the tool, and it automatically scans all three locations: HTML link tags, manifest.json, and the root directory. It finds every Apple Touch Icon size and presents them as downloadable files. No more hunting through DevTools or guessing paths.

This is especially useful for sites like Apple.com, which serves multiple sizes (152x152, 167x167, 180x180) from different paths. Mzu favicondl pulls them all at once.

Pro Tip: Check for Precomposed Variants

Older iOS versions (pre-iOS 7) used apple-touch-icon-precomposed, which removed the glossy overlay. Modern iOS ignores this attribute, but some legacy sites still serve it. If you're extracting an icon from an older site, check for both rel values. Mzu favicondl handles this automatically, but if you're doing it manually, don't skip the precomposed tag.

Method 3: The Console One-Liner

For the terminal-inclined, here's a quick JavaScript snippet you can run in the DevTools console:

const links = document.querySelectorAll('link[rel*="apple-touch-icon"]);
links.forEach(link => console.log(link.href));

This logs every Apple Touch Icon URL on the page. If nothing appears, the site likely uses a manifest. Run this instead:

fetch('/manifest.json')
  .then(r => r.json())
  .then(m => m.icons.filter(i => i.sizes.includes('180'))
  .forEach(i => console.log(i.src)));

This fetches the manifest and filters for 180x180 icons — the standard Apple Touch size.

What to Do With the Extracted Icon

Once you have the icon file, you can use it as a reference for your own design. But don't just copy it — analyze it. Notice how big brands simplify their logos to a single recognizable shape at 180x180 pixels. Apple uses its silhouette. Google uses the 'G' mark. Stripe uses the 'S'.

방법 3: 콘솔 원라이너

터미널을 좋아하는 분들을 위해, DevTools 콘솔에서 실행할 수 있는 간단한 JavaScript 코드를 준비했습니다:

const links = document.querySelectorAll('link[rel*="apple-touch-icon"]);
links.forEach(link => console.log(link.href));

이 코드는 페이지에 있는 모든 Apple Touch Icon URL을 로그로 출력합니다. 아무것도 나오지 않는다면, 사이트가 매니페스트를 사용하고 있을 가능성이 높습니다. 대신 이 코드를 실행해보세요:

fetch('/manifest.json')
  .then(r => r.json())
  .then(m => m.icons.filter(i => i.sizes.includes('180'))
  .forEach(i => console.log(i.src)));

이 코드는 매니페스트를 가져와서 180x180 아이콘(Apple Touch의 표준 크기)만 필터링하여 출력합니다.

추출한 아이콘으로 무엇을 할까

아이콘 파일을 얻었다면, 자신의 디자인을 위한 레퍼런스로 사용할 수 있습니다. 하지만 그냥 복사하지 말고 분석해보세요. 큰 브랜드들이 180x180 픽셀이라는 작은 공간에서 로고를 어떻게 단순화하는지 주목해보세요. Apple은 실루엣을, Google은 'G' 마크를, Stripe은 'S'를 사용합니다.

En cambio, otras páginas lucen un icono limpio y con marca. Esa es la magia del Apple Touch Icon, y si estás montando un proyecto nuevo, seguro que quieres inspirarte en los mejores.

Pero encontrar ese archivo no es tan fácil como parece. Al contrario que el favicon clásico, que suele estar en /favicon.ico, los Apple Touch Icons se esconden en etiquetas <link> o en el archivo manifest.json. Aquí te cuento cómo extraer un Apple Touch Icon de cualquier web, sin tener que adivinar URLs.

Por qué los Apple Touch Icons son tan escurridizos

La mayoría de los desarrolladores conocemos la URL típica del favicon. Pero Apple, como siempre, quiso complicarlo un poco. El icono puede llamarse apple-touch-icon.png, apple-touch-icon-precomposed.png, o estar metido dentro del manifiesto de la web. No hay una convención única.

Por ejemplo, GitHub. Su Apple Touch Icon no está en la raíz. Lo sirven desde https://github.githubassets.com/assets/apple-touch-icon-... con un hash en el nombre. Si intentas acceder a /apple-touch-icon.png, te llevas un 404.

Los tres escondites del Apple Touch Icon

Antes de ponerte a buscar, ten claro dónde mirar:

  • Etiquetas <link> en el HTML — Es lo más común. Busca rel='apple-touch-icon' o rel='apple-touch-icon-precomposed'.
  • Web App Manifest — Algunas webs definen los iconos en manifest.json, dentro del array icons con sizes como 180x180.
  • Directorio raíz — Algunas páginas aún usan la ruta antigua /apple-touch-icon.png, pero cada vez es más raro.

Método 1: Extraer con las DevTools del navegador (a la vieja usanza)

Es el método más rápido para echar un vistazo. Abre cualquier web, haz clic derecho y selecciona 'Inspeccionar' (o pulsa F12). Ve a la pestaña 'Elementos' y busca 'apple-touch-icon' con Ctrl+F (Cmd+F en Mac).

Te aparecerá algo así:

<link rel='apple-touch-icon' sizes='180x180' href='/ruta/al/icono-180.png'>

Copia el valor de href. Si es una ruta relativa (como /ruta/al/icono-180.png), añádele el dominio de la web. Abre esa URL en una pestaña nueva y ya tienes el icono.

¿Y si no aparece la etiqueta link?

Algunas webs, sobre todo las PWA modernas, se saltan la etiqueta HTML y usan directamente el manifiesto. En ese caso, busca:

<link rel='manifest' href='/manifest.json'>

Abre ese archivo JSON y busca un objeto con sizes: '180x180' o sizes: '192x192'. Ese es tu Apple Touch Icon.

Método 3: El one-liner desde la consola

Para los que viven en el terminal, aquí tienes un snippet de JavaScript que puedes ejecutar en la consola de DevTools:

const links = document.querySelectorAll('link[rel*="apple-touch-icon"]);
links.forEach(link => console.log(link.href));

Esto te muestra todas las URLs de Apple Touch Icon de la página. Si no aparece nada, seguro que la web usa un manifiesto. Prueba con esto:

fetch('/manifest.json')
  .then(r => r.json())
  .then(m => m.icons.filter(i => i.sizes.includes('180'))
  .forEach(i => console.log(i.src)));

Esto obtiene el manifiesto y filtra los iconos de 180x180, que es el tamaño estándar de Apple Touch.
