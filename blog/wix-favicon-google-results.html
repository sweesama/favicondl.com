Fix Wix Favicon Not Showing in Google Search Results – Quick Guide

A Wix favicon can appear correctly in a browser tab and still be absent from Google Search. That does not automatically mean the file is broken: Wix must publish the right icon markup, Google must be able to crawl it, and Google ultimately decides whether to show it.

Use Wix’s built-in favicon setting first

Do not start by adding custom code. Wix provides a dedicated favicon control and documents the exact route in its favicon guide. Wix also says that a Premium plan, a connected domain, and a previously published site are required for a custom favicon.

  1. Open Settings in your site dashboard.
  2. Select Website settings.
  3. Under Favicon, click Upload Image, choose the file, and apply the change.
  4. Open the public homepage in a private browser window and confirm that the new icon is served on the live domain—not only inside the Wix editor.

For Wix, use a square PNG whose dimensions are a multiple of 48 pixels, such as 48×48 or 96×96, or use an SVG. That is Wix’s platform-specific upload guidance, not Google’s universal minimum-size rule.

Check whether Google can use the Wix favicon

Google’s favicon documentation for Search says the homepage must expose an icon through a supported rel value and both the homepage and favicon file must be crawlable. Wix normally generates this markup after you use its favicon setting, so manually adding another rel='icon' tag is unnecessary unless inspection proves the live page is missing one.

Google requires a square image of at least 8×8 pixels and recommends an image larger than 48×48 pixels. It supports one favicon per hostname, requires the icon URL to remain stable, and does not guarantee that an eligible favicon will appear.

Inspect the live page, not the editor preview

  1. View the source of the public homepage and search for rel='icon', rel='shortcut icon', or rel='apple-touch-icon'.
  2. Open the referenced icon URL directly. It should load without a login and return a successful response rather than a 404, access-denied page, or HTML error document.
  3. Confirm that robots rules do not block the homepage or favicon from Googlebot and Googlebot-Image.
  4. If the page still points to the old Wix icon, repeat the dashboard upload and make sure the change is applied to the live domain.

You can also run our favicon checker guide to verify the detected icon links and files before waiting for another crawl.

Request a recrawl, then allow realistic processing time

After the live homepage shows the correct icon, inspect that homepage in Google Search Console and choose Request indexing. This is a request, not an instant refresh command. Google says recrawling and processing can take several days to several weeks, depending on how often its systems refresh the site.

A browser-tab update only proves that your browser found an icon. Search appearance has a separate crawl and processing cycle, so repeatedly replacing the file or changing its URL can delay rather than accelerate the result.

Common mistakes to avoid

  • Using the editor preview as proof. Always check the published custom domain.
  • Treating 48×48 as Google’s minimum. Google’s minimum is 8×8; larger than 48×48 is its recommendation. Wix separately asks for multiples of 48 when the file is not SVG.
  • Changing the URL for every retry. Google explicitly asks for a stable favicon URL.
  • Expecting a guaranteed deadline. Neither Wix nor Google promises that the icon will appear, even when the technical requirements are met.
  • Adding duplicate custom tags without checking. Multiple conflicting favicon declarations can make diagnosis harder.

What a successful fix looks like

The correct sequence is simple: upload through Wix’s Website settings, verify the public homepage and icon URL, request indexing for the homepage, and then wait for Google’s normal processing window. If every check passes but the search result still has no custom icon, there may be nothing else to “force”; continue monitoring rather than repeatedly changing a valid setup.
