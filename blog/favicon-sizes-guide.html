The favicon size to publish is a set, not one number: one favicon.ico with 16×16, 32×32 and 48×48, an optional 96×96 PNG when you want a file larger than 48×48 for Google Search, a 180×180 apple-touch icon, and web-manifest PNGs at 192×192 and 512×512, plus a maskable PNG (usually 512×512). The sizes, then the platform rules

A favicon size is the pixel width and height of one icon, and every file in this set is square: Google Search, iOS, and the web app manifest reject a file that is not. Recommended favicon size

This is the practical default. Publish these files, then use the tables below when you need to know where each size is used.

  • ICO: 16×16, 32×32, and 48×48 in one favicon.ico
  • PNG: 32×32 for the browser tab
  • apple-touch-icon: 180×180, one opaque PNG
  • Manifest: 192×192 and 512×512, with purpose set to any
  • SVG: one file with sizes="any" for the tab in current browsers

Add a maskable PNG, usually 512×512, when the launcher crops the icon. An optional 96×96 PNG is only a convenient square larger than 48×48. It is not a separate platform file.

Favicon.ico size: 16, 32, and 48 in one file

The favicon.ico size people ask for is not a single pixel dimension. A .ico file is a container that can hold several images. The useful set is three layers in that one file: 16×16, 32×32, and 48×48. The browser or operating system reads the container and picks a layer close to the surface it is drawing. It does not scale one bitmap for every case.

  • 16×16 is the standard-DPI browser tab, about 16 CSS pixels.
  • 32×32 is the same tab on a 2× screen, so the icon stays sharp. It is also the PNG size to declare beside the ICO.
  • 48×48 is the layer Windows uses for a desktop shortcut. It is not a Google Search minimum. Google's current rule is a square of at least 8×8 px, with a file larger than 48×48 recommended, and that guidance is in the Google row of the table above.

Leave 256×256 and other large artwork out of the ICO. Those belong in a PNG or an SVG. A huge bitmap inside the ICO makes the file heavy, and the tab never needs it.

To make the file, start from one square PNG and embed 16×16, 32×32, and 48×48 in a single .ico. PNG to ICO walks through the browser converter, ImageMagick, and Python. On the Image to Favicon tool, Download ICO scales the upload to those three sizes and writes them as PNG images inside one favicon.ico. The ZIP from the same tool includes that file. Minimal link tags

Put this set in the <head> of the home page. It covers the tab, iOS, the manifest, and Safari pinned tabs. It leaves out the legacy msapplication tile tags.

<link rel="icon" href="/favicon.ico" sizes="48x48">
<link rel="icon" href="/icon.svg" type="image/svg+xml" sizes="any">
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">
<link rel="mask-icon" href="/safari-pinned-tab.svg" color="#000000">

The 192 and 512 PNGs are not extra rel="icon" tags. The manifest names them:

{
  "icons": [
    { "src": "/icon-192.png", "type": "image/png", "sizes": "192x192", "purpose": "any" },
    { "src": "/icon-512.png", "type": "image/png", "sizes": "512x512", "purpose": "any" },
    { "src": "/icon-maskable-512.png", "type": "image/png", "sizes": "512x512", "purpose": "maskable" }
  ]
}

Use a separate maskable file when the artwork needs padding. An icon whose only purpose is maskable is not a substitute for the any icons. How the mask crops is in maskable icons. The SVG tab icon is in SVG favicons. The pinned-tab file is in Safari pinned tab icons. Windows tile meta tags, if you still ship them, are in Windows tile icons.

What each size is for

ICO, 16 / 32 / 48

Those three sizes are the favicon.ico size set, stored in one file. The tab is drawn at about 16 CSS pixels. A 2× screen needs 32 physical pixels to stay sharp, which is why 32×32 is the PNG to declare and a layer inside the ICO. 48×48 is the Windows desktop shortcut layer. Do not also stuff a 256×256 bitmap into the ICO.

PNG, 32 / 192 / 512

Current browsers prefer the 32×32 PNG for the tab when you declare it next to the ICO. 192×192 is the home-screen icon Android reads from the manifest. 512×512 is the install and splash icon. A single 512×512 PNG scaled down to 16 pixels is a poor tab icon: fine strokes blur, and the file is far larger than a tab needs.

apple-touch-icon, 180×180

Publish one opaque 180×180 PNG. iOS uses it for Add to Home Screen and scales it down. The older sizes (57, 72, 76, 114, 120, 144, 152, 167) do not need their own files. Transparent pixels can turn black on older iOS, so use a solid background. apple-touch-icon-precomposed only stopped a gloss effect that ended with iOS 7.

Manifest 192 and 512, including maskable

web.dev documents 192×192 and 512×512 as the two manifest sizes. maskable means the launcher may crop to a circle, squircle, or rounded square. Keep the mark inside the safe zone: a circle at the center with a radius of 2/5 of the icon's shorter side (about 205 px on a 512 px icon). Pixels outside that circle can be hidden. A maskable icon should use a solid background. Transparent pixels are composited onto a fill the user agent chooses.

SVG favicon and Safari mask-icon

These are two different SVGs. The favicon is drawn with the colors in the file, including a prefers-color-scheme rule if you change that one fill for dark mode. Safari's mask-icon ignores those colors. Apple's pinned tab icon rules are: one layer, 100% black artwork, transparent background, viewBox="0 0 16 16". The color attribute on the link is the only tint.

Google Search

Google shows at most one favicon per hostname. The Search Central favicon guidelines say the image must be square and at least 8×8 px, and they recommend a file larger than 48×48 px. They do not say the favicon must be a multiple of 48px, and they do not set a 48×48 minimum. 48×48 itself meets the 8×8 minimum and misses the “larger than” recommendation. 96×96 and 144×144 are simply convenient sizes that are larger than 48×48. SVG is not a supported search format, so keep an ICO or PNG on the home page even if the tab uses SVG. Meeting the rules does not guarantee the icon appears. The longer note is Google's 48×48 favicon rule.

msapplication tiles

If you still publish Windows 8 / IE tiles, the image sizes are 70×70, 150×150, 310×150, and 310×310, with a 144×144 msapplication-TileImage. Current Edge does not need browserconfig.xml or those meta tags. The manifest icons cover the installed-app icon.

FAQ

What size should a favicon be?

Use a favicon.ico with 16×16, 32×32, and 48×48 layers, a 32×32 PNG, a 180×180 apple-touch-icon, and manifest PNGs at 192×192 and 512×512. Add a maskable PNG, usually 512×512, when the launcher crops the icon. An SVG with sizes="any" covers the tab in current browsers. A separate black SVG is the Safari mask-icon.

How does each platform pick a favicon size?

The tab reads the favicon.ico layers or the 32×32 PNG, iOS reads the 180×180 apple-touch-icon, and Android reads 192×192 and 512×512 from the manifest. The lookup chart of those favicon dimensions is the favicon dimensions chart. This guide explains why that platform reads that file.

Which sizes belong in favicon.ico?

16×16, 32×32, and 48×48, stored together in one favicon.ico. The browser or operating system picks one layer: 16 for a standard tab, 32 for a high-DPI tab, and 48 for a Windows desktop shortcut. Image to Favicon writes those three sizes into one .ico. Keep larger artwork in PNG or SVG so the ICO stays small.

What size is the apple-touch-icon?

180×180 pixels, one opaque PNG, with rel="apple-touch-icon". iOS scales that file. You do not need a file for each older iPhone and iPad size.

Must a Google Search favicon be a multiple of 48px, minimum 48×48?

No. That sentence is the old rule, and it is not in the current guidelines. Google requires a square icon of at least 8×8 px and recommends one larger than 48×48 px. Supported formats are BMP, GIF, ICO, PNG, JPEG, PPM, and TIFF. SVG is not on that list. A 48×48 file meets the minimum and is not larger than 48×48.

Do I still need msapplication tiles?

Only for old Internet Explorer and Windows 8 Start tiles. The sizes are 70×70, 144×144, 150×150, 310×150, and 310×310. Current Edge uses the web app manifest, so those tags are not in the minimal set above.

What is a 96×96 favicon for?

96×96 is not a separate platform requirement. Google's current Search guidelines ask for a square icon of at least 8×8 px and recommend one larger than 48×48 px. 96×96 is a convenient size in that range, as is 144×144. The tab, the apple-touch icon, and the manifest still use 16/32/48, 180, and 192/512.

What size is a maskable icon?

Use a 512×512 PNG, and add 192×192 if you also want a smaller maskable file. Keep the mark inside a centered circle whose radius is 2/5 of the shorter side. Set purpose to maskable on that file. An icon with purpose any is still required. The launcher may crop to a circle, squircle, or rounded square.
