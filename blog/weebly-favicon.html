Weebly Favicon: Add or Replace Your Site Icon Step by Step

If your Weebly site still shows a generic globe or the previous logo in a browser tab, this Weebly favicon guide covers the three things that must align: the uploaded image, the published page, and the live icon URL. You can complete the normal setup without editing a theme file.

Prerequisites

Before you start, gather these three items:

  • Editor access: You must be able to open the site in Weebly and publish changes.
  • A square source image: A 512 × 512 PNG is a practical recommendation for the upload. Simple shapes and strong contrast work better than a full wordmark.
  • The live site URL: Keep it open in another tab so you can distinguish the editor preview from what visitors receive.

Add a Weebly favicon in 7 steps

1. Prepare a clean, square icon

Open your logo in an image editor or favicon converter and remove padding that makes the mark look tiny. Export a square PNG with a transparent or solid background, then check it at 16 × 16 pixels; if the shape disappears, simplify it.

Keep the original artwork too. You can use the PNG for the editor upload and generate SVG or multi-size ICO files later if you need a custom stack.

2. Open Weebly’s site settings

Sign in to Weebly, open the site’s editor, and choose Settings, then Site Settings. Open Basic and locate the Favicon upload control. If it appears elsewhere in your editor, use the control labeled Favicon rather than a logo or thumbnail field.

If you do not see the control, ask the site owner to check your plan and editor permissions before continuing. This avoids adding a second icon system while the native uploader is still available.

3. Upload the image

Select Upload, choose your square PNG, and wait for the preview to appear. Confirm that the mark fills the frame rather than sitting inside a large empty border, then save the site settings. Use a real PNG; renaming another image format does not convert it.

4. Publish the change

Click Publish in the Weebly editor and wait for the site to go live. Open the live site address in a new tab; the editor preview alone does not prove that visitors can fetch the new icon.

5. Inspect the live icon link

On the live page, open browser developer tools and inspect the document’s <head>. Look for an icon declaration similar to:

<link rel='icon' type='image/png' href='https://example.com/favicon.png'>

The example.com path is a placeholder; in a native upload, the URL is the one Weebly generated. The rel='icon' link is the standard HTML mechanism for referencing an external icon, as described in the HTML Standard. It gives the browser a candidate to request.

6. Add advanced variants only if you need them

The native uploader is enough for a normal browser-tab icon. If you manage separate assets and your Weebly plan exposes a Head Code field under advanced site settings, you can add a more explicit stack.

<link rel='icon' href='/favicon.ico' sizes='16x16 32x32 48x48'>
<link rel='icon' type='image/png' href='/favicon-32.png' sizes='32x32'>
<link rel='icon' type='image/svg+xml' href='/favicon.svg'>
<link rel='apple-touch-icon' href='/apple-touch-icon.png'>

Replace every example path with a real, publicly reachable URL. Do not add these tags when the native upload already meets your needs, and remove an older custom stack before adding another one.

7. Verify the response and the tab

Reload the live page, switch to a private window, and inspect the browser’s Network panel for the icon request. The request should return the image rather than 404 Not Found, and the tab or bookmark should display your uploaded mark.

If the URL is hard to inspect, paste the exact icon URL into a new tab. You should receive the image file, not an HTML error page. After replacing an existing icon, allow for browser caching or test in a fresh private window.

Common pitfalls

  • The editor changed, but the site was not published. Publish again, then load the live site address rather than an unpublished preview.
  • The old icon is still cached. Test in a private window and hard-reload the page. If the live markup and image are correct, follow the favicon troubleshooting checklist.
  • The icon URL returns 404. Inspect the href in developer tools and open it directly. Do not assume the file is located at /favicon.ico; use the actual URL from the live page.
  • Multiple icon tags make the setup harder to debug. Remove stale custom code or duplicate uploads, then keep one intentional set of declarations.
  • The mark is too detailed. Rebuild it from the logo’s main symbol, remove tiny text, and check the 16-pixel rendering.
  • The Favicon field is missing. Confirm that the site owner can access site settings and that your account has permission to change the site.

Final check

A Weebly favicon is complete when the editor shows the intended icon, the site has been published, the live head contains a valid icon link, and that URL returns the image file. Keep the square source PNG and generated variants together so the next replacement does not reintroduce sizing or path problems.
